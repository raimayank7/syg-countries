Saint Pierre and Miquelon country code: +508

How to call Saint Pierre and Miquelon from India

  1. Dial 00, the exit code of India. On a mobile phone you can press and hold 0 to type + instead.
  2. Dial 508, the country code of Saint Pierre and Miquelon.
  3. Dial the rest of the number. If the number is written with 0 in front for calls inside Saint Pierre and Miquelon, leave that 0 out.

So a mobile number shaped like +508 5X XX XX is dialled from an Indian landline as 00 508 5X XX XX, and from any mobile phone as +508 5X XX XX. The X marks stand for the digits of the real number.

How to call Saint Pierre and Miquelon from other countries

The steps are the same everywhere: your own country's exit code, then 508, then the number. The exit code is 011 from the United States and Canada, 00 from most of Europe, Africa and Asia, and 0011 from Australia. A mobile phone accepts + in place of any exit code, which is why numbers are best saved as +508 followed by the number.

How to call India from Saint Pierre and Miquelon

Dial 00 (the exit code of Saint Pierre and Miquelon), then 91 for India, then the number. An Indian mobile number has 10 digits. For an Indian landline, dial the STD code without its leading 0, then the number: for example 00 91 11 and the eight-digit number for Delhi. Find an Indian STD code.

Saving a number from Saint Pierre and Miquelon for WhatsApp

WhatsApp needs the full international number: + then 508 then the number, without the trunk prefix 0. Save the contact that way and it will work on WhatsApp from any country. To open a chat without saving the contact, use the WhatsApp link maker.
