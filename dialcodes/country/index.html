Reading the list

The number after + is the country calling code. To call abroad, dial your exit code (00 in India) or +, then this code, then the number. Where a second number follows, such as +1 242, many places share one code and that second number is the area code of the place. How international dialling works.

Checked in November 2026. Codes are assigned by the International Telecommunication Union.
