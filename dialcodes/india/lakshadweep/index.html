How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Bitra that is 04890 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 4890 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits, so a shorter code leaves room for a longer number. The shortest codes in this list: Bitra (04890), Amini (04891), Minicoy (04892), Androth (04893), Agathy (04894).

The codes of Lakshadweep in brief

This page lists 10 places under Lakshadweep, with 10 different codes between them. Every code here has four digits after the 0, so every landline number in the list has six digits. The lowest code is 04890 (Bitra) and the highest is 04899 (Chetlat).

How the codes are numbered

All the codes begin with 48 after the 0. STD codes are given out by region, so neighbours tend to share a first digit. The first digit 4 is also used in Andhra Pradesh and Telangana, Kerala and Tamil Nadu and Puducherry.

Shared codes

In this list every code belongs to one named place, so the code alone tells you the town. Villages around a listed town normally use the code of that town.

Questions about STD codes in Lakshadweep

What is the STD code of Bitra?

The STD code of Bitra is 04890. From outside India, dial +91 4890 and then the landline number.

How many digits does a landline number in Lakshadweep have?

Six digits, because every code in this list has four digits and the two together make ten.

Which places in Lakshadweep have the shortest STD codes?

Bitra (04890), Amini (04891) and Minicoy (04892).
