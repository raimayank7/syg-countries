How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Mokokchung that is 0369 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 369 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits, so a shorter code leaves room for a longer number. The shortest codes in this list: Mokokchung (0369), Kohima (0370), Jalukie (03839), Wokha (03860), Tuengsang (03861).

The codes of Nagaland in brief

This page lists 10 places under Nagaland, with 10 different codes between them. Counted without the leading 0: 2 have a three-digit code, so their landline numbers have seven digits and 8 have a four-digit code, so their landline numbers have six digits. The lowest code is 0369 (Mokokchung) and the highest is 03869 (Mon).

How the codes are numbered

After the 0, the codes begin with 38 (8 places, such as Dimapur), 36 (1 place, such as Mokokchung) and 37 (1 place, such as Kohima). STD codes are given out by region, so neighbours tend to share a first digit. The first digit 3 is also used in Andaman and Nicobar Islands, Arunachal Pradesh, Assam, Bihar and Jharkhand, Manipur, Meghalaya, Mizoram and Rajasthan and 2 more lists.

Shared codes

In this list every code belongs to one named place, so the code alone tells you the town. Villages around a listed town normally use the code of that town.

Questions about STD codes in Nagaland

What is the STD code of Mokokchung?

The STD code of Mokokchung is 0369. From outside India, dial +91 369 and then the landline number.

How many digits does a landline number in Nagaland have?

It depends on the code: seven digits with a three-digit code and six digits with a four-digit code. The code and the number together always make ten digits.

Which places in Nagaland have the shortest STD codes?

Mokokchung (0369), Kohima (0370) and Jalukie (03839).
