How to use these codes

  • From a mobile or a landline in India: dial the STD code with its 0, then the landline number. For Shillong that is 0364 and the number.
  • From another country: dial +91, then the code without the 0, then the number: +91 364 and the number.
  • Mobile numbers have no STD code. Dial the 10 digits as they are.

The STD code and the landline number together always make 10 digits, so a shorter code leaves room for a longer number. The shortest codes in this list: Shillong (0364), Cherrapunjee (03637), Nongpoh (03638), Baghmara (03639), Dadengiri / Phulbari (03650).

The codes of Meghalaya in brief

This page lists 14 places under Meghalaya, with 14 different codes between them. Counted without the leading 0: 1 has a three-digit code, so its landline numbers have seven digits and 13 have a four-digit code, so their landline numbers have six digits. The lowest code is 03637 (Cherrapunjee) and the highest is 03659 (Resubelpara / Mendipathar).

How the codes are numbered

All the codes begin with 36 after the 0. STD codes are given out by region, so neighbours tend to share a first digit. The first digit 3 is also used in Andaman and Nicobar Islands, Arunachal Pradesh, Assam, Bihar and Jharkhand, Manipur, Mizoram, Nagaland and Rajasthan and 2 more lists.

Shared codes

3 rows name of the table two or more places that share one code, written with a slash between the names: Dadengiri and Phulbari (03650), Amlarem and Dawki (03653) and Resubelpara and Mendipathar (03659). The same code is dialled for each of them.

Questions about STD codes in Meghalaya

What is the STD code of Shillong?

The STD code of Shillong is 0364. From outside India, dial +91 364 and then the landline number.

How many digits does a landline number in Meghalaya have?

It depends on the code: seven digits with a three-digit code and six digits with a four-digit code. The code and the number together always make ten digits.

Which places in Meghalaya have the shortest STD codes?

Shillong (0364), Cherrapunjee (03637) and Nongpoh (03638).
