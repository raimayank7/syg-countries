What you can do here

Unicode is the standard that gives every letter, digit, symbol and emoji its own number, called a code point. Version 18.0 defines 172,873 characters in 353 blocks. This site has a page for each of 4,769 of the symbols, punctuation marks, numbers and letters people look up most, with the codes you need for a web page or a program, and a table of every block so you can find the rest.

The quickest way in is the search box above: type a word such as heart or rupee, a code such as U+20B9, or paste the symbol you found somewhere and want to know about. For ready-made sets, such as arrows, stars, currency signs and dashes, use the copy-and-paste lists. To learn how to type a character you cannot find on your keyboard, read how to type special characters.
