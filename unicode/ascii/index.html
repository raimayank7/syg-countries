ASCII table: all 128 characters with decimal, hex and binary codes

The 128 characters of ASCII, with the number of each in decimal, hexadecimal and binary.

ASCII, the American Standard Code for Information Interchange, is the 7-bit character set that almost every later one was built on. Its 128 codes (0 to 127) are the 33 control codes that start with NUL and end with DEL, the space, the digits, the upper and lower case English letters and the common punctuation. In Unicode, the first 128 code points (U+0000 to U+007F) are exactly the ASCII characters, and UTF-8 stores each of them as a single byte with the same value, so a file that contains only ASCII is also a valid UTF-8 file.

Reading the table

The codes 0 to 31 and 127 are control codes: they were made for teleprinters and are shown here by their usual abbreviation. Those still in daily use are TAB (9), LF (10, the line feed that ends a line on Linux and macOS), CR (13, carriage return, which together with LF ends a line on Windows), ESC (27) and DEL (127). The printable characters run from 32 (space) to 126 (the tilde). Capital letters are 65 to 90 and small letters are 97 to 122; they differ by exactly 32, which is a single bit, so a program can change case by flipping bit 5. Digits 0 to 9 are 48 to 57, so the value of a digit character is its code minus 48.

Beyond 127

ASCII stops at 127. The 8-bit extensions that filled the other 128 values (Windows-1252, ISO 8859-1 and the old DOS code pages) differ from each other, which is the confusion Unicode replaced. See the Alt code table for the Windows ones and the guide to Unicode.
