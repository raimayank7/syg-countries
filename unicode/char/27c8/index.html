Reverse Solidus Preceding Subset is Unicode character U+27C8. It is a sign used in mathematics, in the Miscellaneous Mathematical Symbols-A block. Its category is "math symbol". It was added in Unicode 5.0 (2006). Its script property is Common (common means the character is shared by many writing systems rather than belonging to one).

The official name is REVERSE SOLIDUS PRECEDING SUBSET. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same.

What the standard says about it

In the code charts it sits in the group "Miscellaneous symbols".

Properties

It is a mirrored character: in right-to-left text the shape is flipped so that, for example, an opening bracket still opens towards the text.

How to type Reverse Solidus Preceding Subset

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 27C8, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 27C8.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 27c8, then press Enter or Space.
  • Windows 10 and 11: press the Windows key and the full stop (Win + .) to open the emoji and symbol panel and look in its symbols tabs.

Where it sits in Unicode

Reverse Solidus Preceding Subset sits at position 9 of the Miscellaneous Mathematical Symbols-A block, which covers U+27C0 to U+27EF and has 48 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Or With Dot Inside (U+27C7) and the one after it is Superset Preceding Solidus (U+27C9).

Common questions

How do I type Reverse Solidus Preceding Subset?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 27C8 then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type 27C8; on Linux press Ctrl+Shift+U, type 27c8 and press Enter.

What is the HTML code for Reverse Solidus Preceding Subset?

In HTML you can write &#10184; (decimal) or &#x27C8; (hexadecimal) or the named entity &bsolhsub;. In a style sheet the escape is \27C8. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Reverse Solidus Preceding Subset in, and when was it added?

Reverse Solidus Preceding Subset is in the Miscellaneous Mathematical Symbols-A block (U+27C0 to U+27EF). It was added in Unicode 5.0 in 2006.

How many bytes is Reverse Solidus Preceding Subset in UTF-8?

It takes 3 bytes in UTF-8 (E2 9F 88) and 2 bytes in UTF-16. Its code point is U+27C8.
