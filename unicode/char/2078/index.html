Superscript Eight is Unicode character U+2078. It is a number that is not a plain decimal digit, such as a fraction, a superscript or a circled number, in the Superscripts and Subscripts block. Its category is "other number". It was added in Unicode 1.1 (1993), the first version that has an age record, so it has been in the standard from the start. Its script property is Common (common means the character is shared by many writing systems rather than belonging to one).

The official name is SUPERSCRIPT EIGHT. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same. Superscript and subscript characters are separate characters in Unicode, not formatting, so they survive copy and paste into plain text.

What the standard says about it

In the code charts it sits in the group "Superscripts". Its name in Unicode 1.0 was SUPERSCRIPT DIGIT EIGHT. It is listed as compatible with: <super> 0038.

Properties

It is a compatibility form of 8 (U+0038) (a "super" variant), which is why text search and normalisation can treat it as that character. Its numeric value in the standard is 8.

How to type Superscript Eight

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 2078, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 2078.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 2078, then press Enter or Space.

Where it sits in Unicode

Superscript Eight sits at position 9 of the Superscripts and Subscripts block, which covers U+2070 to U+209F and has 46 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Superscript Seven (U+2077) and the one after it is Superscript Nine (U+2079).

Common questions

How do I type Superscript Eight?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 2078 then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type 2078; on Linux press Ctrl+Shift+U, type 2078 and press Enter.

What is the HTML code for Superscript Eight?

In HTML you can write &#8312; (decimal) or &#x2078; (hexadecimal). In a style sheet the escape is \2078. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Superscript Eight in, and when was it added?

Superscript Eight is in the Superscripts and Subscripts block (U+2070 to U+209F). It was added in Unicode 1.1 in 1993.

How many bytes is Superscript Eight in UTF-8?

It takes 3 bytes in UTF-8 (E2 81 B8) and 2 bytes in UTF-16. Its code point is U+2078.
