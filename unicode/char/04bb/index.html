Cyrillic Small Letter Shha is Unicode character U+04BB. It is a small letter of an alphabet, in the Cyrillic block. Its general category in the Unicode standard is "lowercase letter". It was added in Unicode 1.1 (1993), the first version that has an age record, so it has been in the standard from the start. Its script property is Cyrillic.

The official name is CYRILLIC SMALL LETTER SHHA. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same. "Small letter" is Unicode's word for the lower-case form.

What the standard says about it

The standard adds this note: originally derived from Latin "h", but uppercase form 04BA is closer to an inverted che (0427). The standard adds this note: Azerbaijani, Bashkir, . In the code charts it sits in the group "Extended Cyrillic". Its name in Unicode 1.0 was CYRILLIC SMALL LETTER H.

Properties

For upper and lower case, its capital form is Һ (U+04BA).

How to type Cyrillic Small Letter Shha

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 04BB, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 04BB.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 4bb, then press Enter or Space.

Where it sits in Unicode

Cyrillic Small Letter Shha sits at position 188 of the Cyrillic block, which covers U+0400 to U+04FF and has 256 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Cyrillic Capital Letter Shha (U+04BA) and the one after it is Cyrillic Capital Letter Abkhasian Che (U+04BC).

Common questions

How do I type Cyrillic Small Letter Shha?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 04BB then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type 04BB; on Linux press Ctrl+Shift+U, type 4bb and press Enter.

What is the HTML code for Cyrillic Small Letter Shha?

In HTML you can write &#1211; (decimal) or &#x04BB; (hexadecimal). In a style sheet the escape is \04BB. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Cyrillic Small Letter Shha in, and when was it added?

Cyrillic Small Letter Shha is in the Cyrillic block (U+0400 to U+04FF). It was added in Unicode 1.1 in 1993.

How many bytes is Cyrillic Small Letter Shha in UTF-8?

It takes 2 bytes in UTF-8 (D2 BB) and 2 bytes in UTF-16. Its code point is U+04BB.
