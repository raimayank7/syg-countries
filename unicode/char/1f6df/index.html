Ring Buoy is Unicode character U+1F6DF. It is a symbol, pictogram or sign, in the Transport and Map Symbols block. Its category is "symbol (other)". It was added in Unicode 14.0 (2021). Its script property is Common (common means the character is shared by many writing systems rather than belonging to one).

The official name is RING BUOY. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same.

What the standard says about it

In the code charts it sits in the group "Miscellaneous symbols".

Emoji

Ring Buoy is an emoji, and phones and apps draw it as a colour picture by default. To force the plain text style, add the invisible text variation selector U+FE0E after it. You can copy both forms below.

How to type Ring Buoy

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 1F6DF, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type D83D then DEDF.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 1f6df, then press Enter or Space.
  • Windows 10 and 11: press the Windows key and the full stop (Win + .) to open the emoji and symbol panel and look in its symbols tabs.

Where it sits in Unicode

Ring Buoy sits at position 96 of the Transport and Map Symbols block, which covers U+1F680 to U+1F6FF and has 120 characters. The block is in the Supplementary Multilingual Plane (plane 1). In code point order, the one before it is Wheel (U+1F6DE) and the one after it is Hammer And Wrench (U+1F6E0).

Common questions

How do I type Ring Buoy?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 1F6DF then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type its two UTF-16 halves; on Linux press Ctrl+Shift+U, type 1f6df and press Enter.

What is the HTML code for Ring Buoy?

In HTML you can write &#128735; (decimal) or &#x1F6DF; (hexadecimal). In a style sheet the escape is \1F6DF. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Ring Buoy in, and when was it added?

Ring Buoy is in the Transport and Map Symbols block (U+1F680 to U+1F6FF). It was added in Unicode 14.0 in 2021.

How many bytes is Ring Buoy in UTF-8?

It takes 4 bytes in UTF-8 (F0 9F 9B 9F) and 4 bytes in UTF-16. Its code point is U+1F6DF.

Is Ring Buoy an emoji?

Yes. Unicode lists it as an emoji character. It is drawn as a colour picture by default.
