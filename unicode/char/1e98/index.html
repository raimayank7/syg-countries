Latin Small Letter W With Ring Above is Unicode character U+1E98. It is a small letter of an alphabet, in the Latin Extended Additional block. Its general category in the Unicode standard is "lowercase letter". It was added in Unicode 1.1 (1993), the first version that has an age record, so it has been in the standard from the start. Its script property is Latin.

The official name is LATIN SMALL LETTER W WITH RING ABOVE. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same. The name says how the letter is built: the part before with is the base letter and the part after it is the mark added to it. "Small letter" is Unicode's word for the lower-case form.

What the standard says about it

In the code charts it sits in the group "Latin general use extensions".

Properties

It can also be written as a base character plus a mark: w (U+0077) + ̊ (U+030A). Unicode treats the two spellings as the same text.

How to type Latin Small Letter W With Ring Above

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 1E98, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 1E98.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 1e98, then press Enter or Space.

Where it sits in Unicode

Latin Small Letter W With Ring Above sits at position 153 of the Latin Extended Additional block, which covers U+1E00 to U+1EFF and has 256 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Latin Small Letter T With Diaeresis (U+1E97) and the one after it is Latin Small Letter Y With Ring Above (U+1E99).

Common questions

How do I type Latin Small Letter W With Ring Above?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 1E98 then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type 1E98; on Linux press Ctrl+Shift+U, type 1e98 and press Enter.

What is the HTML code for Latin Small Letter W With Ring Above?

In HTML you can write &#7832; (decimal) or &#x1E98; (hexadecimal). In a style sheet the escape is \1E98. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Latin Small Letter W With Ring Above in, and when was it added?

Latin Small Letter W With Ring Above is in the Latin Extended Additional block (U+1E00 to U+1EFF). It was added in Unicode 1.1 in 1993.

How many bytes is Latin Small Letter W With Ring Above in UTF-8?

It takes 3 bytes in UTF-8 (E1 BA 98) and 2 bytes in UTF-16. Its code point is U+1E98.
