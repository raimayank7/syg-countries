Raised Mr Sign is Unicode character U+1F16C. It is a symbol, pictogram or sign, in the Enclosed Alphanumeric Supplement block. Its category is "symbol (other)". It was added in Unicode 12.0 (2019). Its script property is Common (common means the character is shared by many writing systems rather than belonging to one).

The official name is RAISED MR SIGN. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same.

What the standard says about it

Other names listed by Unicode for it: marca registrada. The standard adds this note: used primarily in Spanish and Portuguese speaking communities to indicate a registered trademark. In the code charts it sits in the group "Raised squared Latin sequences". It is listed as compatible with: <super> 004D 0052.

Properties

It is a compatibility form of M (U+004D) + R (U+0052) (a "super" variant), which is why text search and normalisation can treat it as that character.

How to type Raised Mr Sign

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 1F16C, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type D83C then DD6C.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 1f16c, then press Enter or Space.
  • Windows 10 and 11: press the Windows key and the full stop (Win + .) to open the emoji and symbol panel and look in its symbols tabs.

Where it sits in Unicode

Raised Mr Sign sits at position 109 of the Enclosed Alphanumeric Supplement block, which covers U+1F100 to U+1F1FF and has 201 characters. The block is in the Supplementary Multilingual Plane (plane 1). In code point order, the one before it is Raised Md Sign (U+1F16B) and the one after it is Circled Cc (U+1F16D).

Common questions

How do I type Raised Mr Sign?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 1F16C then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type its two UTF-16 halves; on Linux press Ctrl+Shift+U, type 1f16c and press Enter.

What is the HTML code for Raised Mr Sign?

In HTML you can write &#127340; (decimal) or &#x1F16C; (hexadecimal). In a style sheet the escape is \1F16C. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Raised Mr Sign in, and when was it added?

Raised Mr Sign is in the Enclosed Alphanumeric Supplement block (U+1F100 to U+1F1FF). It was added in Unicode 12.0 in 2019.

How many bytes is Raised Mr Sign in UTF-8?

It takes 4 bytes in UTF-8 (F0 9F 85 AC) and 4 bytes in UTF-16. Its code point is U+1F16C.
