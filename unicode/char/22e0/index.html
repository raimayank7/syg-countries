Does Not Precede Or Equal is Unicode character U+22E0. It is a sign used in mathematics, in the Mathematical Operators block. Its category is "math symbol". It was added in Unicode 1.1 (1993), the first version that has an age record, so it has been in the standard from the start. Its script property is Common (common means the character is shared by many writing systems rather than belonging to one).

The official name is DOES NOT PRECEDE OR EQUAL. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same.

What the standard says about it

In the code charts it sits in the group "Relations".

Properties

It can also be written as a base character plus a mark: ≼ (U+227C) + ̸ (U+0338). Unicode treats the two spellings as the same text. It is a mirrored character: in right-to-left text the shape is flipped so that, for example, an opening bracket still opens towards the text.

How to type Does Not Precede Or Equal

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 22E0, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 22E0.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 22e0, then press Enter or Space.
  • Windows 10 and 11: press the Windows key and the full stop (Win + .) to open the emoji and symbol panel and look in its symbols tabs.

Where it sits in Unicode

Does Not Precede Or Equal sits at position 225 of the Mathematical Operators block, which covers U+2200 to U+22FF and has 256 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Equal To Or Succeeds (U+22DF) and the one after it is Does Not Succeed Or Equal (U+22E1).

Common questions

How do I type Does Not Precede Or Equal?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 22E0 then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type 22E0; on Linux press Ctrl+Shift+U, type 22e0 and press Enter.

What is the HTML code for Does Not Precede Or Equal?

In HTML you can write &#8928; (decimal) or &#x22E0; (hexadecimal) or the named entity &NotPrecedesSlantEqual;. In a style sheet the escape is \22E0. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Does Not Precede Or Equal in, and when was it added?

Does Not Precede Or Equal is in the Mathematical Operators block (U+2200 to U+22FF). It was added in Unicode 1.1 in 1993.

How many bytes is Does Not Precede Or Equal in UTF-8?

It takes 3 bytes in UTF-8 (E2 8B A0) and 2 bytes in UTF-16. Its code point is U+22E0.
