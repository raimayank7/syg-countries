Caret is Unicode character U+2038. It is a punctuation mark, in the General Punctuation block. Its category is "punctuation (other)". It was added in Unicode 1.1 (1993), the first version that has an age record, so it has been in the standard from the start. Its script property is Common (common means the character is shared by many writing systems rather than belonging to one).

The official name is CARET. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same.

What the standard says about it

In the code charts it sits in the group "General punctuation".

How to type Caret

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 2038, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 2038.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 2038, then press Enter or Space.

Where it sits in Unicode

Caret sits at position 57 of the General Punctuation block, which covers U+2000 to U+206F and has 111 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Reversed Triple Prime (U+2037) and the one after it is Single Left-Pointing Angle Quotation Mark (U+2039).

Common questions

How do I type Caret?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 2038 then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type 2038; on Linux press Ctrl+Shift+U, type 2038 and press Enter.

What is the HTML code for Caret?

In HTML you can write &#8248; (decimal) or &#x2038; (hexadecimal). In a style sheet the escape is \2038. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Caret in, and when was it added?

Caret is in the General Punctuation block (U+2000 to U+206F). It was added in Unicode 1.1 in 1993.

How many bytes is Caret in UTF-8?

It takes 3 bytes in UTF-8 (E2 80 B8) and 2 bytes in UTF-16. Its code point is U+2038.
