Aktieselskab is Unicode character U+214D. It is a symbol, pictogram or sign, in the Letterlike Symbols block. Its category is "symbol (other)". It was added in Unicode 5.0 (2006). Its script property is Common (common means the character is shared by many writing systems rather than belonging to one).

The official name is AKTIESELSKAB. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same.

What the standard says about it

In the code charts it sits in the group "Additional letterlike symbols".

How to type Aktieselskab

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 214D, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 214D.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 214d, then press Enter or Space.
  • Windows 10 and 11: press the Windows key and the full stop (Win + .) to open the emoji and symbol panel and look in its symbols tabs.

Where it sits in Unicode

Aktieselskab sits at position 78 of the Letterlike Symbols block, which covers U+2100 to U+214F and has 80 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Per Sign (U+214C) and the one after it is Turned Small F (U+214E).

Common questions

How do I type Aktieselskab?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 214D then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type 214D; on Linux press Ctrl+Shift+U, type 214d and press Enter.

What is the HTML code for Aktieselskab?

In HTML you can write &#8525; (decimal) or &#x214D; (hexadecimal). In a style sheet the escape is \214D. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Aktieselskab in, and when was it added?

Aktieselskab is in the Letterlike Symbols block (U+2100 to U+214F). It was added in Unicode 5.0 in 2006.

How many bytes is Aktieselskab in UTF-8?

It takes 3 bytes in UTF-8 (E2 85 8D) and 2 bytes in UTF-16. Its code point is U+214D.
