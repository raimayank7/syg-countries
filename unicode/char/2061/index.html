Function Application

Unicode U+2061. A format character: it changes how text is shown or joined but prints nothing itself.

Function Application is Unicode character U+2061. It is a format character: it changes how text is shown or joined but prints nothing itself, in the General Punctuation block. Its general category in the Unicode standard is "format character". It was added in Unicode 3.2 (2002). Its script property is Common (common means the character is shared by many writing systems rather than belonging to one).

The official name is FUNCTION APPLICATION. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same.

What the standard says about it

The standard adds this note: contiguity operator indicating application of a function. In the code charts it sits in the group "Invisible operators".

How to type Function Application

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 2061, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 2061.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 2061, then press Enter or Space.

Where it sits in Unicode

Function Application sits at position 98 of the General Punctuation block, which covers U+2000 to U+206F and has 111 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Word Joiner (U+2060) and the one after it is Invisible Times (U+2062).

Common questions

How do I type Function Application?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 2061 then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type 2061; on Linux press Ctrl+Shift+U, type 2061 and press Enter.

What is the HTML code for Function Application?

In HTML you can write &#8289; (decimal) or &#x2061; (hexadecimal) or the named entity &af;. In a style sheet the escape is \2061. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Function Application in, and when was it added?

Function Application is in the General Punctuation block (U+2000 to U+206F). It was added in Unicode 3.2 in 2002.

How many bytes is Function Application in UTF-8?

It takes 3 bytes in UTF-8 (E2 81 A1) and 2 bytes in UTF-16. Its code point is U+2061.
