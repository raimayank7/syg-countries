Script Capital M is Unicode character U+2133. It is a capital letter of an alphabet, in the Letterlike Symbols block. Its general category in the Unicode standard is "uppercase letter". It was added in Unicode 1.1 (1993), the first version that has an age record, so it has been in the standard from the start. Its script property is Common (common means the character is shared by many writing systems rather than belonging to one).

The official name is SCRIPT CAPITAL M. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same.

What the standard says about it

Other names listed by Unicode for it: M-matrix (physics); German Mark currency symbol, before WWII. The standard adds this note: when used for the Mark symbol, the range of glyph variation is restricted. In the code charts it sits in the group "Letterlike symbols". Its name in Unicode 1.0 was SCRIPT M. It is listed as compatible with: 2133 FE00 chancery style; 2133 FE01 roundhand style; <font> 004D latin capital letter m.

Properties

It is a compatibility form of M (U+004D) (a "font" variant), which is why text search and normalisation can treat it as that character.

How to type Script Capital M

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 2133, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 2133.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 2133, then press Enter or Space.

Where it sits in Unicode

Script Capital M sits at position 52 of the Letterlike Symbols block, which covers U+2100 to U+214F and has 80 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Turned Capital F (U+2132) and the one after it is Script Small O (U+2134).

Common questions

How do I type Script Capital M?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 2133 then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type 2133; on Linux press Ctrl+Shift+U, type 2133 and press Enter.

What is the HTML code for Script Capital M?

In HTML you can write &#8499; (decimal) or &#x2133; (hexadecimal) or the named entity &Mellintrf;. In a style sheet the escape is \2133. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Script Capital M in, and when was it added?

Script Capital M is in the Letterlike Symbols block (U+2100 to U+214F). It was added in Unicode 1.1 in 1993.

How many bytes is Script Capital M in UTF-8?

It takes 3 bytes in UTF-8 (E2 84 B3) and 2 bytes in UTF-16. Its code point is U+2133.
