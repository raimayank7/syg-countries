Latin Capital Letter Z With Caron is Unicode character U+017D. It is a capital letter of an alphabet, in the Latin Extended-A block. Its general category in the Unicode standard is "uppercase letter". It was added in Unicode 1.1 (1993), the first version that has an age record, so it has been in the standard from the start. Its script property is Latin.

The official name is LATIN CAPITAL LETTER Z WITH CARON. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same. The name says how the letter is built: the part before with is the base letter and the part after it is the mark added to it. "Capital letter" is Unicode's word for the upper-case form.

What the standard says about it

In the code charts it sits in the group "European Latin". Its name in Unicode 1.0 was LATIN CAPITAL LETTER Z HACEK.

Properties

For upper and lower case, its small form is ž (U+017E). It can also be written as a base character plus a mark: Z (U+005A) + ̌ (U+030C). Unicode treats the two spellings as the same text.

How to type Latin Capital Letter Z With Caron

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Windows: hold Alt, type 0142 on the numeric keypad, then release Alt. This works on a PC set up for Western European languages; on another language setting the same number may give a different character, so check the result.
  • Microsoft Word on Windows: type 017D, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 017D.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 17d, then press Enter or Space.

Where it sits in Unicode

Latin Capital Letter Z With Caron sits at position 126 of the Latin Extended-A block, which covers U+0100 to U+017F and has 128 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Latin Small Letter Z With Dot Above (U+017C) and the one after it is Latin Small Letter Z With Caron (U+017E).

Common questions

How do I type Latin Capital Letter Z With Caron?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows hold Alt and type 0142 on the numeric keypad; on a Mac with the Unicode Hex Input keyboard hold Option and type 017D; on Linux press Ctrl+Shift+U, type 17d and press Enter.

What is the HTML code for Latin Capital Letter Z With Caron?

In HTML you can write &#381; (decimal) or &#x017D; (hexadecimal) or the named entity &Zcaron;. In a style sheet the escape is \017D. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Latin Capital Letter Z With Caron in, and when was it added?

Latin Capital Letter Z With Caron is in the Latin Extended-A block (U+0100 to U+017F). It was added in Unicode 1.1 in 1993.

How many bytes is Latin Capital Letter Z With Caron in UTF-8?

It takes 2 bytes in UTF-8 (C5 BD) and 2 bytes in UTF-16. Its code point is U+017D.
