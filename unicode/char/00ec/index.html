Latin Small Letter I With Grave is Unicode character U+00EC. It is a small letter of an alphabet, in the Latin-1 Supplement block. Its general category in the Unicode standard is "lowercase letter". It was added in Unicode 1.1 (1993), the first version that has an age record, so it has been in the standard from the start. Its script property is Latin.

The official name is LATIN SMALL LETTER I WITH GRAVE. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same. The name says how the letter is built: the part before with is the base letter and the part after it is the mark added to it. "Small letter" is Unicode's word for the lower-case form.

What the standard says about it

The standard adds this note: Italian, Malagasy. In the code charts it sits in the group "Lowercase letters". Its name in Unicode 1.0 was LATIN SMALL LETTER I GRAVE.

Properties

For upper and lower case, its capital form is Ì (U+00CC). It can also be written as a base character plus a mark: i (U+0069) + ̀ (U+0300). Unicode treats the two spellings as the same text.

How to type Latin Small Letter I With Grave

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Windows: hold Alt, type 0236 on the numeric keypad, then release Alt. This works on a PC set up for Western European languages; on another language setting the same number may give a different character, so check the result.
  • Microsoft Word on Windows: type 00EC, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 00EC.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type ec, then press Enter or Space.

Where it sits in Unicode

Latin Small Letter I With Grave sits at position 109 of the Latin-1 Supplement block, which covers U+0080 to U+00FF and has 128 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Latin Small Letter E With Diaeresis (U+00EB) and the one after it is Latin Small Letter I With Acute (U+00ED).

Common questions

How do I type Latin Small Letter I With Grave?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows hold Alt and type 0236 on the numeric keypad; on a Mac with the Unicode Hex Input keyboard hold Option and type 00EC; on Linux press Ctrl+Shift+U, type ec and press Enter.

What is the HTML code for Latin Small Letter I With Grave?

In HTML you can write &#236; (decimal) or &#x00EC; (hexadecimal) or the named entity &igrave;. In a style sheet the escape is \00EC. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Latin Small Letter I With Grave in, and when was it added?

Latin Small Letter I With Grave is in the Latin-1 Supplement block (U+0080 to U+00FF). It was added in Unicode 1.1 in 1993.

How many bytes is Latin Small Letter I With Grave in UTF-8?

It takes 2 bytes in UTF-8 (C3 AC) and 2 bytes in UTF-16. Its code point is U+00EC.
