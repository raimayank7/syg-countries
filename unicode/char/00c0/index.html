Latin Capital Letter A With Grave is Unicode character U+00C0. It is a capital letter of an alphabet, in the Latin-1 Supplement block. Its general category in the Unicode standard is "uppercase letter". It was added in Unicode 1.1 (1993), the first version that has an age record, so it has been in the standard from the start. Its script property is Latin.

The official name is LATIN CAPITAL LETTER A WITH GRAVE. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same. The name says how the letter is built: the part before with is the base letter and the part after it is the mark added to it. "Capital letter" is Unicode's word for the upper-case form.

What the standard says about it

In the code charts it sits in the group "Uppercase letters". Its name in Unicode 1.0 was LATIN CAPITAL LETTER A GRAVE.

Properties

For upper and lower case, its small form is à (U+00E0). It can also be written as a base character plus a mark: A (U+0041) + ̀ (U+0300). Unicode treats the two spellings as the same text.

How to type Latin Capital Letter A With Grave

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Windows: hold Alt, type 0192 on the numeric keypad, then release Alt. This works on a PC set up for Western European languages; on another language setting the same number may give a different character, so check the result.
  • Microsoft Word on Windows: type 00C0, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 00C0.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type c0, then press Enter or Space.

Where it sits in Unicode

Latin Capital Letter A With Grave sits at position 65 of the Latin-1 Supplement block, which covers U+0080 to U+00FF and has 128 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Inverted Question Mark (U+00BF) and the one after it is Latin Capital Letter A With Acute (U+00C1).

Common questions

How do I type Latin Capital Letter A With Grave?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows hold Alt and type 0192 on the numeric keypad; on a Mac with the Unicode Hex Input keyboard hold Option and type 00C0; on Linux press Ctrl+Shift+U, type c0 and press Enter.

What is the HTML code for Latin Capital Letter A With Grave?

In HTML you can write &#192; (decimal) or &#x00C0; (hexadecimal) or the named entity &Agrave;. In a style sheet the escape is \00C0. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Latin Capital Letter A With Grave in, and when was it added?

Latin Capital Letter A With Grave is in the Latin-1 Supplement block (U+0080 to U+00FF). It was added in Unicode 1.1 in 1993.

How many bytes is Latin Capital Letter A With Grave in UTF-8?

It takes 2 bytes in UTF-8 (C3 80) and 2 bytes in UTF-16. Its code point is U+00C0.
