Unicode U+230A. A bracket that opens a piece of text.

Left Floor is Unicode character U+230A. It is a bracket that opens a piece of text, in the Miscellaneous Technical block. Its category is "opening bracket". It was added in Unicode 1.1 (1993), the first version that has an age record, so it has been in the standard from the start. Its script property is Common (common means the character is shared by many writing systems rather than belonging to one).

The official name is LEFT FLOOR. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same.

What the standard says about it

Other names listed by Unicode for it: APL downstile. In the code charts it sits in the group "Ceilings and floors".

Properties

It is a mirrored character: in right-to-left text the shape is flipped so that, for example, an opening bracket still opens towards the text.

How to type Left Floor

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 230A, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 230A.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 230a, then press Enter or Space.

Where it sits in Unicode

Left Floor sits at position 11 of the Miscellaneous Technical block, which covers U+2300 to U+23FF and has 256 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Right Ceiling (U+2309) and the one after it is Right Floor (U+230B).

Common questions

How do I type Left Floor?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 230A then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type 230A; on Linux press Ctrl+Shift+U, type 230a and press Enter.

What is the HTML code for Left Floor?

In HTML you can write &#8970; (decimal) or &#x230A; (hexadecimal) or the named entity &LeftFloor;. In a style sheet the escape is \230A. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Left Floor in, and when was it added?

Left Floor is in the Miscellaneous Technical block (U+2300 to U+23FF). It was added in Unicode 1.1 in 1993.

How many bytes is Left Floor in UTF-8?

It takes 3 bytes in UTF-8 (E2 8C 8A) and 2 bytes in UTF-16. Its code point is U+230A.
