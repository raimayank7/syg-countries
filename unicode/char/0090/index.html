Device Control String

Device Control String is Unicode character U+0090. It is a control code that starts an action in a terminal or a text stream and prints nothing, in the Latin-1 Supplement block. Its general category in the Unicode standard is "control character". It was added in Unicode 1.1 (1993), the first version that has an age record, so it has been in the standard from the start. Its script property is Common (common means the character is shared by many writing systems rather than belonging to one).

The official name is DEVICE CONTROL STRING. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same.

What the standard says about it

Other names listed by Unicode for it: DEVICE CONTROL STRING. In the code charts it sits in the group "C1 controls". Its name in Unicode 1.0 was DEVICE CONTROL STRING.

How to type Device Control String

  • This is a control code, so there is nothing to paste. Programs write it with an escape such as \u0090.
  • Microsoft Word on Windows: type 0090, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 0090.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 90, then press Enter or Space.

Where it sits in Unicode

Device Control String sits at position 17 of the Latin-1 Supplement block, which covers U+0080 to U+00FF and has 128 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Single Shift Three (U+008F) and the one after it is Private Use One (U+0091).

Common questions

How do I type Device Control String?

It is a control code and is not meant to be typed. Programs write it as \u0090.

What is the HTML code for Device Control String?

In HTML you can write &#144; (decimal) or &#x0090; (hexadecimal). In a style sheet the escape is \0090. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Device Control String in, and when was it added?

Device Control String is in the Latin-1 Supplement block (U+0080 to U+00FF). It was added in Unicode 1.1 in 1993.

How many bytes is Device Control String in UTF-8?

It takes 2 bytes in UTF-8 (C2 90) and 2 bytes in UTF-16. Its code point is U+0090.
