Rightwards Harpoon With Barb Down From Bar is Unicode character U+295F. It is a sign used in mathematics, in the Supplemental Arrows-B block. Its category is "math symbol". It was added in Unicode 3.2 (2002). Its script property is Common (common means the character is shared by many writing systems rather than belonging to one).

The official name is RIGHTWARDS HARPOON WITH BARB DOWN FROM BAR. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same.

What the standard says about it

In the code charts it sits in the group "Modified harpoons".

How to type Rightwards Harpoon With Barb Down From Bar

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 295F, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 295F.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 295f, then press Enter or Space.
  • Windows 10 and 11: press the Windows key and the full stop (Win + .) to open the emoji and symbol panel and look in its symbols tabs.

Where it sits in Unicode

Rightwards Harpoon With Barb Down From Bar sits at position 96 of the Supplemental Arrows-B block, which covers U+2900 to U+297F and has 128 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Leftwards Harpoon With Barb Down From Bar (U+295E) and the one after it is Upwards Harpoon With Barb Left From Bar (U+2960).

Common questions

How do I type Rightwards Harpoon With Barb Down From Bar?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 295F then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type 295F; on Linux press Ctrl+Shift+U, type 295f and press Enter.

What is the HTML code for Rightwards Harpoon With Barb Down From Bar?

Which Unicode block is Rightwards Harpoon With Barb Down From Bar in, and when was it added?

Rightwards Harpoon With Barb Down From Bar is in the Supplemental Arrows-B block (U+2900 to U+297F). It was added in Unicode 3.2 in 2002.

How many bytes is Rightwards Harpoon With Barb Down From Bar in UTF-8?

It takes 3 bytes in UTF-8 (E2 A5 9F) and 2 bytes in UTF-16. Its code point is U+295F.
