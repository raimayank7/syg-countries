White Star is Unicode character U+2606. It is a symbol, pictogram or sign, in the Miscellaneous Symbols block. Its category is "symbol (other)". It was added in Unicode 1.1 (1993), the first version that has an age record, so it has been in the standard from the start. Its script property is Common (common means the character is shared by many writing systems rather than belonging to one).

The official name is WHITE STAR. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same. In Unicode names, black means a filled or solid shape and white means an outline; the words do not describe colour on screen.

What the standard says about it

In the code charts it sits in the group "Weather and astrological symbols".

How to type White Star

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 2606, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 2606.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 2606, then press Enter or Space.
  • Windows 10 and 11: press the Windows key and the full stop (Win + .) to open the emoji and symbol panel and look in its symbols tabs.

Where it sits in Unicode

White Star sits at position 7 of the Miscellaneous Symbols block, which covers U+2600 to U+26FF and has 256 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Black Star (U+2605) and the one after it is Lightning (U+2607).

Common questions

How do I type White Star?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 2606 then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type 2606; on Linux press Ctrl+Shift+U, type 2606 and press Enter.

What is the HTML code for White Star?

In HTML you can write &#9734; (decimal) or &#x2606; (hexadecimal) or the named entity &star;. In a style sheet the escape is \2606. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is White Star in, and when was it added?

White Star is in the Miscellaneous Symbols block (U+2600 to U+26FF). It was added in Unicode 1.1 in 1993.

How many bytes is White Star in UTF-8?

It takes 3 bytes in UTF-8 (E2 98 86) and 2 bytes in UTF-16. Its code point is U+2606.
