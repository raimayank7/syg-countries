Activate Symmetric Swapping

Unicode U+206B. A format character: it changes how text is shown or joined but prints nothing itself.

Activate Symmetric Swapping is Unicode character U+206B. It is a format character: it changes how text is shown or joined but prints nothing itself, in the General Punctuation block. Its general category in the Unicode standard is "format character". It was added in Unicode 1.1 (1993), the first version that has an age record, so it has been in the standard from the start. Its script property is Common (common means the character is shared by many writing systems rather than belonging to one).

The official name is ACTIVATE SYMMETRIC SWAPPING. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same.

What the standard says about it

In the code charts it sits in the group "Deprecated".

How to type Activate Symmetric Swapping

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 206B, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 206B.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 206b, then press Enter or Space.

Where it sits in Unicode

Activate Symmetric Swapping sits at position 108 of the General Punctuation block, which covers U+2000 to U+206F and has 111 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Inhibit Symmetric Swapping (U+206A) and the one after it is Inhibit Arabic Form Shaping (U+206C).

Common questions

How do I type Activate Symmetric Swapping?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 206B then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type 206B; on Linux press Ctrl+Shift+U, type 206b and press Enter.

What is the HTML code for Activate Symmetric Swapping?

In HTML you can write &#8299; (decimal) or &#x206B; (hexadecimal). In a style sheet the escape is \206B. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Activate Symmetric Swapping in, and when was it added?

Activate Symmetric Swapping is in the General Punctuation block (U+2000 to U+206F). It was added in Unicode 1.1 in 1993.

How many bytes is Activate Symmetric Swapping in UTF-8?

It takes 3 bytes in UTF-8 (E2 81 AB) and 2 bytes in UTF-16. Its code point is U+206B.
