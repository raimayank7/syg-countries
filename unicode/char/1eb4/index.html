Latin Capital Letter A With Breve And Tilde is Unicode character U+1EB4. It is a capital letter of an alphabet, in the Latin Extended Additional block. Its general category in the Unicode standard is "uppercase letter". It was added in Unicode 1.1 (1993), the first version that has an age record, so it has been in the standard from the start. Its script property is Latin.

The official name is LATIN CAPITAL LETTER A WITH BREVE AND TILDE. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same. The name says how the letter is built: the part before with is the base letter and the part after it is the mark added to it. "Capital letter" is Unicode's word for the upper-case form.

What the standard says about it

In the code charts it sits in the group "Latin extensions for Vietnamese".

Properties

For upper and lower case, its small form is ẵ (U+1EB5). It can also be written as a base character plus a mark: Ă (U+0102) + ̃ (U+0303). Unicode treats the two spellings as the same text.

How to type Latin Capital Letter A With Breve And Tilde

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 1EB4, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 1EB4.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 1eb4, then press Enter or Space.

Where it sits in Unicode

Latin Capital Letter A With Breve And Tilde sits at position 181 of the Latin Extended Additional block, which covers U+1E00 to U+1EFF and has 256 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Latin Small Letter A With Breve And Hook Above (U+1EB3) and the one after it is Latin Small Letter A With Breve And Tilde (U+1EB5).

Common questions

How do I type Latin Capital Letter A With Breve And Tilde?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 1EB4 then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type 1EB4; on Linux press Ctrl+Shift+U, type 1eb4 and press Enter.

What is the HTML code for Latin Capital Letter A With Breve And Tilde?

In HTML you can write &#7860; (decimal) or &#x1EB4; (hexadecimal). In a style sheet the escape is \1EB4. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Latin Capital Letter A With Breve And Tilde in, and when was it added?

Latin Capital Letter A With Breve And Tilde is in the Latin Extended Additional block (U+1E00 to U+1EFF). It was added in Unicode 1.1 in 1993.

How many bytes is Latin Capital Letter A With Breve And Tilde in UTF-8?

It takes 3 bytes in UTF-8 (E1 BA B4) and 2 bytes in UTF-16. Its code point is U+1EB4.
