⑽ Parenthesized Number Ten

Parenthesized Number Ten is Unicode character U+247D. It is a number that is not a plain decimal digit, such as a fraction, a superscript or a circled number, in the Enclosed Alphanumerics block. Its category is "other number". It was added in Unicode 1.1 (1993), the first version that has an age record, so it has been in the standard from the start. Its script property is Common (common means the character is shared by many writing systems rather than belonging to one).

The official name is PARENTHESIZED NUMBER TEN. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same. This is a single character with the enclosing shape built in, which is different from putting a circle around a plain letter or digit.

What the standard says about it

In the code charts it sits in the group "Parenthesized numbers". It is listed as compatible with: 0028 0031 0030 0029.

Properties

It is a compatibility form of ( (U+0028) + 1 (U+0031) + 0 (U+0030) + ) (U+0029) (a "compat" variant), which is why text search and normalisation can treat it as that character. Its numeric value in the standard is 10.

How to type Parenthesized Number Ten

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 247D, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 247D.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 247d, then press Enter or Space.

Where it sits in Unicode

Parenthesized Number Ten sits at position 30 of the Enclosed Alphanumerics block, which covers U+2460 to U+24FF and has 160 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Parenthesized Digit Nine (U+247C) and the one after it is Parenthesized Number Eleven (U+247E).

Common questions

How do I type Parenthesized Number Ten?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 247D then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type 247D; on Linux press Ctrl+Shift+U, type 247d and press Enter.

What is the HTML code for Parenthesized Number Ten?

In HTML you can write &#9341; (decimal) or &#x247D; (hexadecimal). In a style sheet the escape is \247D. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Parenthesized Number Ten in, and when was it added?

Parenthesized Number Ten is in the Enclosed Alphanumerics block (U+2460 to U+24FF). It was added in Unicode 1.1 in 1993.

How many bytes is Parenthesized Number Ten in UTF-8?

It takes 3 bytes in UTF-8 (E2 91 BD) and 2 bytes in UTF-16. Its code point is U+247D.
