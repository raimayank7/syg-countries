Latin Subscript Small Letter A is Unicode character U+2090. It is a small letter that modifies the sound of the letter before it, in the Superscripts and Subscripts block. Its general category in the Unicode standard is "modifier letter". It was added in Unicode 4.1 (2005). Its script property is Latin.

The official name is LATIN SUBSCRIPT SMALL LETTER A. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same. "Small letter" is Unicode's word for the lower-case form. Superscript and subscript characters are separate characters in Unicode, not formatting, so they survive copy and paste into plain text.

What the standard says about it

In the code charts it sits in the group "Subscripts". It is listed as compatible with: <sub> 0061.

Properties

It is a compatibility form of a (U+0061) (a "sub" variant), which is why text search and normalisation can treat it as that character.

How to type Latin Subscript Small Letter A

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 2090, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 2090.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 2090, then press Enter or Space.

Where it sits in Unicode

Latin Subscript Small Letter A sits at position 33 of the Superscripts and Subscripts block, which covers U+2070 to U+209F and has 46 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Modifier Letter High And Low Vertical Line (U+208F) and the one after it is Latin Subscript Small Letter E (U+2091).

Common questions

How do I type Latin Subscript Small Letter A?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 2090 then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type 2090; on Linux press Ctrl+Shift+U, type 2090 and press Enter.

What is the HTML code for Latin Subscript Small Letter A?

In HTML you can write &#8336; (decimal) or &#x2090; (hexadecimal). In a style sheet the escape is \2090. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Latin Subscript Small Letter A in, and when was it added?

Latin Subscript Small Letter A is in the Superscripts and Subscripts block (U+2070 to U+209F). It was added in Unicode 4.1 in 2005.

How many bytes is Latin Subscript Small Letter A in UTF-8?

It takes 3 bytes in UTF-8 (E2 82 90) and 2 bytes in UTF-16. Its code point is U+2090.
