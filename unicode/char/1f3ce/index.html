Racing Car is Unicode character U+1F3CE. It is a symbol, pictogram or sign, in the Miscellaneous Symbols and Pictographs block. Its category is "symbol (other)". It was added in Unicode 7.0 (2014). Its script property is Common (common means the character is shared by many writing systems rather than belonging to one).

The official name is RACING CAR. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same.

What the standard says about it

Other names listed by Unicode for it: race car. In the code charts it sits in the group "Sport symbols".

Emoji

Racing Car has an emoji form, but by default it is drawn as a plain text symbol. Adding the invisible variation selector U+FE0F after it asks for the colour picture style; U+FE0E asks for the text style. Not every app respects the request. Copy the one you want below.

How to type Racing Car

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 1F3CE, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type D83C then DFCE.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 1f3ce, then press Enter or Space.
  • Windows 10 and 11: press the Windows key and the full stop (Win + .) to open the emoji and symbol panel and look in its symbols tabs.

Where it sits in Unicode

Racing Car sits at position 207 of the Miscellaneous Symbols and Pictographs block, which covers U+1F300 to U+1F5FF and has 768 characters. The block is in the Supplementary Multilingual Plane (plane 1). In code point order, the one before it is Racing Motorcycle (U+1F3CD) and the one after it is Cricket Bat And Ball (U+1F3CF).

Common questions

How do I type Racing Car?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 1F3CE then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type its two UTF-16 halves; on Linux press Ctrl+Shift+U, type 1f3ce and press Enter.

What is the HTML code for Racing Car?

In HTML you can write &#127950; (decimal) or &#x1F3CE; (hexadecimal). In a style sheet the escape is \1F3CE. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Racing Car in, and when was it added?

Racing Car is in the Miscellaneous Symbols and Pictographs block (U+1F300 to U+1F5FF). It was added in Unicode 7.0 in 2014.

How many bytes is Racing Car in UTF-8?

It takes 4 bytes in UTF-8 (F0 9F 8F 8E) and 4 bytes in UTF-16. Its code point is U+1F3CE.

Is Racing Car an emoji?

Yes. Unicode lists it as an emoji character. It is drawn as a plain symbol by default; add U+FE0F after it to ask for the picture style.
