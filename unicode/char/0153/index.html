Latin Small Ligature Oe is Unicode character U+0153. It is a small letter of an alphabet, in the Latin Extended-A block. Its general category in the Unicode standard is "lowercase letter". It was added in Unicode 1.1 (1993), the first version that has an age record, so it has been in the standard from the start. Its script property is Latin.

The official name is LATIN SMALL LIGATURE OE. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same.

What the standard says about it

Other names listed by Unicode for it: ethel (from Old English eðel). The standard adds this note: French, IPA, Old Icelandic, Old English, . In the code charts it sits in the group "European Latin". Its name in Unicode 1.0 was LATIN SMALL LETTER O E.

Properties

For upper and lower case, its capital form is Œ (U+0152).

How to type Latin Small Ligature Oe

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Windows: hold Alt, type 0156 on the numeric keypad, then release Alt. This works on a PC set up for Western European languages; on another language setting the same number may give a different character, so check the result.
  • Microsoft Word on Windows: type 0153, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 0153.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 153, then press Enter or Space.

Where it sits in Unicode

Latin Small Ligature Oe sits at position 84 of the Latin Extended-A block, which covers U+0100 to U+017F and has 128 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Latin Capital Ligature Oe (U+0152) and the one after it is Latin Capital Letter R With Acute (U+0154).

Common questions

How do I type Latin Small Ligature Oe?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows hold Alt and type 0156 on the numeric keypad; on a Mac with the Unicode Hex Input keyboard hold Option and type 0153; on Linux press Ctrl+Shift+U, type 153 and press Enter.

What is the HTML code for Latin Small Ligature Oe?

In HTML you can write &#339; (decimal) or &#x0153; (hexadecimal) or the named entity &oelig;. In a style sheet the escape is \0153. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Latin Small Ligature Oe in, and when was it added?

Latin Small Ligature Oe is in the Latin Extended-A block (U+0100 to U+017F). It was added in Unicode 1.1 in 1993.

How many bytes is Latin Small Ligature Oe in UTF-8?

It takes 2 bytes in UTF-8 (C5 93) and 2 bytes in UTF-16. Its code point is U+0153.
