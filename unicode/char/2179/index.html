ⅹ Small Roman Numeral Ten

Small Roman Numeral Ten is Unicode character U+2179. It is a number written with letter shapes, such as a Roman numeral, in the Number Forms block. Its category is "letter-like number". It was added in Unicode 1.1 (1993), the first version that has an age record, so it has been in the standard from the start. Its script property is Latin.

The official name is SMALL ROMAN NUMERAL TEN. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same.

What the standard says about it

In the code charts it sits in the group "Roman numerals". It is listed as compatible with: 0078 latin small letter x.

Properties

For upper and lower case, its capital form is Ⅹ (U+2169). It is a compatibility form of x (U+0078) (a "compat" variant), which is why text search and normalisation can treat it as that character. Its numeric value in the standard is 10.

How to type Small Roman Numeral Ten

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 2179, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 2179.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 2179, then press Enter or Space.

Where it sits in Unicode

Small Roman Numeral Ten sits at position 42 of the Number Forms block, which covers U+2150 to U+218F and has 60 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Small Roman Numeral Nine (U+2178) and the one after it is Small Roman Numeral Eleven (U+217A).

Common questions

How do I type Small Roman Numeral Ten?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 2179 then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type 2179; on Linux press Ctrl+Shift+U, type 2179 and press Enter.

What is the HTML code for Small Roman Numeral Ten?

In HTML you can write &#8569; (decimal) or &#x2179; (hexadecimal). In a style sheet the escape is \2179. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Small Roman Numeral Ten in, and when was it added?

Small Roman Numeral Ten is in the Number Forms block (U+2150 to U+218F). It was added in Unicode 1.1 in 1993.

How many bytes is Small Roman Numeral Ten in UTF-8?

It takes 3 bytes in UTF-8 (E2 85 B9) and 2 bytes in UTF-16. Its code point is U+2179.
