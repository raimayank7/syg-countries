Circled Latin Small Letter O is Unicode character U+24DE. It is a symbol, pictogram or sign, in the Enclosed Alphanumerics block. Its category is "symbol (other)". It was added in Unicode 1.1 (1993), the first version that has an age record, so it has been in the standard from the start. Its script property is Common (common means the character is shared by many writing systems rather than belonging to one).

The official name is CIRCLED LATIN SMALL LETTER O. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same. "Small letter" is Unicode's word for the lower-case form. This is a single character with the enclosing shape built in, which is different from putting a circle around a plain letter or digit.

What the standard says about it

In the code charts it sits in the group "Circled Latin letters". It is listed as compatible with: <circle> 006F.

Properties

For upper and lower case, its capital form is Ⓞ (U+24C4). It is a compatibility form of o (U+006F) (a "circle" variant), which is why text search and normalisation can treat it as that character.

How to type Circled Latin Small Letter O

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 24DE, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type 24DE.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 24de, then press Enter or Space.
  • Windows 10 and 11: press the Windows key and the full stop (Win + .) to open the emoji and symbol panel and look in its symbols tabs.

Where it sits in Unicode

Circled Latin Small Letter O sits at position 127 of the Enclosed Alphanumerics block, which covers U+2460 to U+24FF and has 160 characters. The block is in the Basic Multilingual Plane (plane 0). In code point order, the one before it is Circled Latin Small Letter N (U+24DD) and the one after it is Circled Latin Small Letter P (U+24DF).

Common questions

How do I type Circled Latin Small Letter O?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 24DE then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type 24DE; on Linux press Ctrl+Shift+U, type 24de and press Enter.

What is the HTML code for Circled Latin Small Letter O?

In HTML you can write &#9438; (decimal) or &#x24DE; (hexadecimal). In a style sheet the escape is \24DE. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Circled Latin Small Letter O in, and when was it added?

Circled Latin Small Letter O is in the Enclosed Alphanumerics block (U+2460 to U+24FF). It was added in Unicode 1.1 in 1993.

How many bytes is Circled Latin Small Letter O in UTF-8?

It takes 3 bytes in UTF-8 (E2 93 9E) and 2 bytes in UTF-16. Its code point is U+24DE.
