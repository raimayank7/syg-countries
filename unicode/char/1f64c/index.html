Person Raising Both Hands In Celebration is Unicode character U+1F64C. It is a symbol, pictogram or sign, in the Emoticons block. Its category is "symbol (other)". It was added in Unicode 6.0 (2010). Its script property is Common (common means the character is shared by many writing systems rather than belonging to one).

The official name is PERSON RAISING BOTH HANDS IN CELEBRATION. Names in the standard are fixed once assigned and never corrected, so a name can look odd or old-fashioned while the character stays the same.

What the standard says about it

Other names listed by Unicode for it: banzai!. In the code charts it sits in the group "Gesture symbols".

Emoji

Person Raising Both Hands In Celebration is an emoji, and phones and apps draw it as a colour picture by default. To force the plain text style, add the invisible text variation selector U+FE0E after it. You can copy both forms below.

How to type Person Raising Both Hands In Celebration

  • Copy and paste: press the copy button above. It works in every app and on every phone.
  • Microsoft Word on Windows: type 1F64C, then press Alt and X together; Word turns the code into the character.
  • Mac: add the "Unicode Hex Input" keyboard in System Settings, choose it, hold Option and type D83D then DE4C.
  • Linux (GTK and most desktops): press Ctrl+Shift+U, type 1f64c, then press Enter or Space.
  • Windows 10 and 11: press the Windows key and the full stop (Win + .) to open the emoji and symbol panel and look in its symbols tabs.

Where it sits in Unicode

Person Raising Both Hands In Celebration sits at position 77 of the Emoticons block, which covers U+1F600 to U+1F64F and has 80 characters. The block is in the Supplementary Multilingual Plane (plane 1). In code point order, the one before it is Happy Person Raising One Hand (U+1F64B) and the one after it is Person Frowning (U+1F64D).

Common questions

How do I type Person Raising Both Hands In Celebration?

Copy it with the button on this page and paste it where you need it. To type it from the keyboard: on Windows in Word type 1F64C then press Alt+X; on a Mac with the Unicode Hex Input keyboard hold Option and type its two UTF-16 halves; on Linux press Ctrl+Shift+U, type 1f64c and press Enter.

What is the HTML code for Person Raising Both Hands In Celebration?

In HTML you can write &#128588; (decimal) or &#x1F64C; (hexadecimal). In a style sheet the escape is \1F64C. Pages saved as UTF-8 can also contain the character itself.

Which Unicode block is Person Raising Both Hands In Celebration in, and when was it added?

Person Raising Both Hands In Celebration is in the Emoticons block (U+1F600 to U+1F64F). It was added in Unicode 6.0 in 2010.

How many bytes is Person Raising Both Hands In Celebration in UTF-8?

It takes 4 bytes in UTF-8 (F0 9F 99 8C) and 4 bytes in UTF-16. Its code point is U+1F64C.

Is Person Raising Both Hands In Celebration an emoji?

Yes. Unicode lists it as an emoji character. It is drawn as a colour picture by default.
