Unicode versions: how many characters each release added

From 1.1 in 1993 to 18.0: a table made from the Unicode age data.

Unicode grows in numbered versions, about one a year. Each version adds new characters and leaves the old ones as they are: a character, once added, is never removed or renumbered. The table below counts them from the standard's own "age" record of every character, so the figures are exact for Unicode 18.0. Version 1.1 is the first with an age record and it already holds the characters that came with the merge with ISO 10646, which is why the first row is so large. The largest single release was 3.1, which added 44,946 characters.

What to take from it

New releases mostly add historic scripts, rare ideographs and emoji. Emoji appear every year in the September releases for the following spring on phones, but phones and apps need an update before they can draw a new character: a symbol added in the most recent version may show as an empty box on many devices for a year or more. If you want people to see your text, prefer symbols that are several versions old. Each character page on this site says in which version it was added.

Counts: Unicode Character Database 18.0 (DerivedAge.txt, UnicodeData.txt), private-use and surrogate code points excluded. Years of release are those of the Unicode Consortium's version history.
