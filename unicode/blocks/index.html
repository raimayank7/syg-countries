Unicode

All Unicode blocks

Unicode 18.0 sorts its 353 blocks into planes. Choose a block to see every character in it and copy it.

A block is a named, continuous range of code points, such as "Arrows" or "Currency Symbols". Blocks are the way the Unicode code charts are organised, and they are mostly but not strictly tied to scripts: a script can be spread over several blocks and a block can hold characters from more than one script. The blocks are grouped below by plane. A plane is a range of 65,536 code points; plane 0, the Basic Multilingual Plane, holds the characters of nearly all modern writing systems and the common symbols, while plane 1 holds historic scripts, emoji and many symbol sets, and planes 2 and 3 hold rare CJK ideographs. In total Unicode 18.0 assigns 172,873 characters (not counting private-use code points, which are left to users).
