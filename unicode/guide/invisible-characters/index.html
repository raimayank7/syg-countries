Invisible characters in Unicode

Some Unicode characters have no visible shape. They are not mistakes: each does a job, such as stopping a line from breaking, joining two letters, or setting the direction of text. But they cause surprising problems, because text that looks identical on screen is different underneath.

The ones you will meet

CodeNameWhat it doesCopy
U+00A0No-Break SpaceLooks like a space but stops a line from breaking there. Used between a number and its unit.
U+00ADSoft HyphenVisible only where a word is broken at the end of a line, then shows as a hyphen.
U+034FCombining Grapheme JoinerKeeps marks in order and blocks some joining; mostly of use to text engines.
U+061CArabic Letter MarkSets the direction of surrounding text like a right-to-left mark, for Arabic.
U+2002En SpaceA space half the width of an em.
U+2003Em SpaceA space as wide as the font size.
U+2009Thin SpaceA narrow space, used between a number and its unit in typesetting.
U+200AHair SpaceThe thinnest space.
U+200BZero Width SpaceMarks a place where a line may break; takes up no width.
U+200CZero Width Non-JoinerStops two letters from joining; needed in Persian and some Indian scripts.
U+200DZero Width JoinerJoins characters that would not join by themselves; builds many emoji and Indic conjunct letters.
U+200ELeft-To-Right MarkMakes the text after it behave as left-to-right.
U+200FRight-To-Left MarkMakes the text after it behave as right-to-left.
U+202FNarrow No-Break SpaceNarrow space that also stops a line break; used in French and some Mongolian text.
U+2060Word JoinerStops a line break at its position and has no width.
U+2066Left-To-Right IsolateStarts an isolated left-to-right run of text.
U+2067Right-To-Left IsolateStarts an isolated right-to-left run of text.
U+2069Pop Directional IsolateEnds an isolated run started by the two above.
U+3000Ideographic SpaceThe wide space of Chinese, Japanese and Korean text, as wide as one of their characters.
U+2800Braille Pattern BlankA Braille pattern with no dots: looks blank, but is a real letter-like character, so it is accepted where a space is not.
U+FE0EVariation Selector-15Asks for the text (plain) style of the character before it.
U+FE0FVariation Selector-16Asks for the picture (emoji) style of the character before it.
U+FEFFZero Width No-Break SpaceByte order mark: at the start of a file it marks the encoding; elsewhere it is a zero width no-break space and should be removed.

Where they cause trouble

  • Copied text does not match: a name or code copied from a web page or a PDF may carry a zero width space or a no-break space at the end. A form that checks the text rejects it, and a spreadsheet lookup fails.
  • Usernames and passwords: some sites accept invisible characters in names, which lets two accounts look the same. Passwords with an invisible character cannot be typed from memory.
  • Programs: a byte order mark at the start of a script or a data file can break the first line. A zero width character in source code can make a program do something different from what it looks like; this has been used in attacks that hide code with bidirectional controls.
  • Blank names: the Braille blank and similar characters are used to make "empty" names that sites do not detect as empty.

How to find them

Many code editors can show invisible characters (look for the setting "render control characters" or "show invisibles"). In a program you can print the escaped form: in Python, print(text.encode("unicode_escape")); in JavaScript, JSON.stringify(text) leaves most of them visible as escapes. To remove the common zero width ones in JavaScript, text.replace(/[\u200B-\u200D\u2060\uFEFF]/g, "") does it. Be careful not to remove the joiner from text that needs it: in emoji sequences and Indic scripts it is part of the meaning.

How to type them

You usually cannot, so copy them from the list above or from the page of the character. The no-break space is Ctrl + Shift + Space in Word and Alt + 0160 on Windows.
