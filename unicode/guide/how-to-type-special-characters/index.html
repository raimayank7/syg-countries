How to type special characters and symbols

Your keyboard shows about a hundred characters, yet Unicode defines 41,297. Every device has some way of reaching the rest, but the ways differ. This guide covers the methods that work, in the order most people should try them.

The method that always works: copy and paste

Find the character on this site (search by name or code, or use a list), press Copy, and paste. It works on every device and in every program, and it needs no memorising. If you use a character often, keep it in a note or in your phone's text replacement list.

Windows

  • Alt codes: hold Alt and type a number on the numeric keypad. Alt + 0 followed by three digits gives the Windows ANSI character; Alt + a number without a leading zero gives the old DOS character. The Alt code table lists every one. A few common ones:

  • Windows key + full stop (Windows 10 and 11) opens a panel of emoji, kaomoji and symbols with a search box.
  • Microsoft Word: type the hex code of the character and press Alt + X; or use Insert, then Symbol. This works for any Unicode character.
  • Character Map (search "charmap" in the Start menu) shows every character of a font, lets you select, copy and, for fonts that have them, see the Unicode code of each.
  • US International keyboard: if you often type accented letters, add this layout in Settings, Time and language. It lets you type é by pressing the apostrophe and then e.

Mac

  • Option key: on a US keyboard Option + G types ©, Option + R types ®, Option + 2 types ™, Option + 8 types the bullet •, and Option + Shift + 8 types the degree sign °. For accents, press Option + E then the letter for é, Option + N then n for ñ.
  • Emoji and symbols viewer: press Control + Command + Space. It has a search box and categories, and a button that opens the full character viewer.
  • Unicode Hex Input: add this keyboard in System Settings, Keyboard, Input Sources. Then hold Option and type the four hex digits of a code point to get that character.

Linux

  • In GTK programs and most desktops, press Ctrl + Shift + U, type the hex code (such as 20b9), and press Enter or Space.
  • Set a Compose key in the keyboard settings; then Compose, then o, then c gives ©, and similar combinations exist for most common symbols.

Android

Press and hold a key on the keyboard to see its variants: a long press on the e gives é, è, ê and others; on the minus sign gives dashes; on the currency key gives other currencies. On Gboard and most keyboards a symbols page (the ?123 or =\< keys) holds more, and the emoji button opens the emoji panel.

iPhone and iPad

Press and hold a key on the keyboard for its variants (for example, hold the dollar sign for other currencies). Add the emoji keyboard in Settings, General, Keyboard. For symbols you use all the time, set a text replacement in Settings, General, Keyboard, Text Replacement, such as typing "rupee" and getting ₹.

In a web page or document source

If you write HTML or CSS you can use the character codes instead of typing: see the guide to HTML, CSS and JavaScript escapes. Every character page on this site lists them.

If it shows as an empty box

You typed or pasted the right character, but the font does not have it. Change the font, or use a more common symbol. The character is not lost: the box can be copied and shown properly elsewhere.
