HTML, CSS and JavaScript escapes for Unicode characters

When you build a web page or write a program you do not always want to paste a character into the source: the editor may not display it, the file may not be saved as UTF-8, or you want the code to say clearly which character it means. Every language has a way to write a character by its number. Here they are side by side, using four characters as examples.

HTML

Write &#9829; (decimal) or &#x2665; (hexadecimal) for any character; the code is the code point. Some characters also have a name, like &hearts; or &copy;. Five need care because HTML itself uses them: write &lt;, &gt;, &amp; and &quot; instead of the plain signs inside text and attributes, or the browser may treat them as code. If your page is saved as UTF-8 and has <meta charset="utf-8">, you can simply type the characters.

CSS

In a style sheet write a backslash and the hex code, as in content: "\2665";. If the next character after the escape is a letter or digit that could be read as part of the code, add a space or write the code as six digits (\002665). Escapes work in the content property and in class names and selectors.

JavaScript

In a string write "\u2665". For code points above U+FFFF write "\u{1F600}", or use String.fromCodePoint(0x1F600). The older form needs a surrogate pair, "\uD83D\uDE00"; the length of such a string is 2, not 1, because JavaScript counts UTF-16 units. To get the code point back use "😀".codePointAt(0), and to walk through the characters use for (const ch of text) or Array.from(text), not an index loop.

Python, Java and other languages

Python writes "\u2665" for 4 hex digits and "\U0001F600" for 8; chr(0x2665) and ord("♥") convert both ways, and "\N{BLACK HEART SUIT}" uses the name. Java and C# write "\u2665", with a surrogate pair for characters above U+FFFF.

URLs

A URL can contain only a limited set of characters. Others are written as percent-encoding: the UTF-8 bytes of the character, each written as a percent sign and two hex digits, so ♥ becomes %E2%99%A5. Browsers show the readable form in the address bar but send the encoded form.

Mistakes to avoid

  • Do not paste a curly quote “ into code where a straight quote " is required.
  • Do not mix up the code point (hex) with the decimal number: &#9829; and &#x2665; are the same character.
  • Do not count characters with a length that counts UTF-16 units or bytes when you mean what the reader sees.
