What is Unicode?

Unicode is a standard that gives every character of every writing system in use, and many that are no longer used, one unique number. The number is called a code point, and it is written like U+0041 (capital A) or U+20B9 (the rupee sign). Before Unicode, computers used hundreds of different character sets, each with room for 256 characters at most. The same byte could be a letter in one set and a different letter or symbol in another, which is why old emails and web pages sometimes arrived as garbled text. Unicode replaced this with a single numbering that covers all languages.

How big is it?

Unicode 18.0 defines 41,297 characters. The code space has room for 1,114,112 code points (U+0000 to U+10FFFF), arranged in 17 planes of 65,536. About 26,596 of the code points assigned so far are letters, 2,580 are marks, 2,247 are numbers, 860 are punctuation, and 8,760 are symbols (including emoji); the rest are separators, controls and format characters. Every new version, about once a year, adds characters but never changes or removes an existing one; you can see what each version added on the versions page.

Character, code point, glyph, font

These four words are often mixed up. A character is the abstract unit, such as "capital A". A code point is the number Unicode gives it. A glyph is one drawing of it, and a font is a collection of glyphs. Unicode defines characters and numbers, not their shapes, so the same code point looks different in a serif and a sans-serif font. A character can also need several glyphs, or one glyph can stand for several characters: in many scripts, letters change shape depending on their neighbours.

Unicode is not UTF-8

Unicode is the numbering. UTF-8, UTF-16 and UTF-32 are three ways of storing those numbers as bytes (they are called encodings). UTF-8 is the one used by nearly every web page: it writes the first 128 code points, which are the same as ASCII, in a single byte, so old ASCII files remain valid. Read more in UTF-8 explained.

Blocks, scripts and categories

Characters are grouped in several ways. A block is a range of code points with a name, like Arrows; there are 353 on this site, see all blocks. A script is a writing system, such as Latin, Devanagari or Gurmukhi. A category says what kind of character it is (a capital letter, a digit, a currency sign). All three are part of the data on every character page.

Why it matters in daily life

  • It is the reason you can write Hindi, Punjabi, Chinese and emoji in the same message.
  • It is the reason a file saved on one computer opens correctly on another.
  • It is also why some text looks the same but is not: lookalike characters and different ways of writing the same accented letter.
