Alt codes list for Windows: symbols and letters with their numbers

Hold Alt, type the number on the numeric keypad, release Alt.

Alt codes are a way to type characters that are not on your keyboard, by holding the Alt key and typing a number on the numeric keypad (the separate block of digits on the right; the number row above the letters does not work, and on a laptop without a keypad you may need Num Lock and a function key). There are two kinds, and the number you type decides which you get:

  • Alt + 0 and three digits (for example Alt + 0169) gives the character at that place in the Windows ANSI set, Windows-1252 on a Western European PC. The first table lists the 123 characters from 128 to 255 in that set.
  • Alt + a number without a leading 0 (for example Alt + 169) gives the character from the old DOS set, code page 437, which has box-drawing characters, Greek letters and a few symbols. The second table lists it.

The results depend on the language settings of the PC: on a system set up for Greek or Russian the ANSI set is a different one and the same numbers give different letters. If the number does not give what you expect, copy the character from the table instead; the button works everywhere.

Both tables are generated by this site from the character sets themselves, so each number is the one that maps to that character, with its Unicode name and a link to the page that explains it. Characters above U+00FF, such as the rupee sign or arrows, have no Alt code; type their hex code and Alt + X in Word, or use the copy buttons on the lists.
