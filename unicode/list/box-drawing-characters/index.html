Box drawing characters to copy: ─ │ ┌ ┐ └ ┘ ├ ┤ ┬ ┴ ┼

Box drawing characters are used to draw frames, tables and trees in plain text and terminals: lines, corners, T-junctions and crosses in single, double, heavy and dashed styles. The block has 128 characters (U+2500 to U+257F) and the neighbouring Block Elements block has the shading and half-block shapes.

They only line up in a monospaced font, where every character has the same width. Paste them into a message in a normal font and the lines will not meet. Use them in code comments, README files and terminal tools, or paste into a text box with a fixed-width font.

This list has 160 characters from 2 Unicode blocks (Block Elements, Box Drawing). They were added between Unicode 1.1 and 3.2. Tap a symbol to copy it.

Common questions

How do I copy a symbol from this page?

Tap or click the symbol. It is copied to your clipboard, and a short message confirms it. Then paste it where you need it with Ctrl+V, or press and hold in a text field on a phone.

Why do some symbols look like empty boxes?

The font on your device does not have that character. The characters are valid Unicode, but each font covers only part of it. Try another app or font, or choose a more common symbol from the list.

Can I use these symbols in a username, a name or a file?

Many sites accept them, but some block symbols or turn them into question marks. Test on the site first. Avoid symbols in file names and passwords, where an unusual character can cause errors on another system.
