Hanifi Rohingya: Unicode block U+10D00 to U+10D3F

50 characters you can look at, copy and paste. Data from Unicode 18.0.

The Hanifi Rohingya block covers the code points U+10D00 to U+10D3F (64 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 50 of them so far, which are 36 other letters, 10 decimal digits, 4 non-spacing marks. All its characters were added in Unicode 11.0.

The characters belong to the script: Hanifi Rohingya.

What the block contains

The Unicode code charts divide this block into groups: Letters; Additional letter; Vowels; Vowel silencer; Nasalization mark; Tone signs; Gemination sign; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Hanifi Rohingya block?

Unicode 18.0 has 50 assigned characters in the Hanifi Rohingya block, out of 64 code points reserved for it (U+10D00 to U+10D3F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 11.0.
