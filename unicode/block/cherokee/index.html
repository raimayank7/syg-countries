Cherokee: Unicode block U+13A0 to U+13FF

92 characters you can look at, copy and paste. Data from Unicode 18.0.

The Cherokee block covers the code points U+13A0 to U+13FF (96 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 92 of them so far, which are 86 uppercase letters, 6 lowercase letters. Its characters were added between Unicode 3.0 and 8.0.

The characters belong to the script: Cherokee.

What the block contains

The Unicode code charts divide this block into groups: Uppercase syllables; Archaic uppercase syllable; Lowercase syllables; Archaic lowercase syllable.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Cherokee block?

Unicode 18.0 has 92 assigned characters in the Cherokee block, out of 96 code points reserved for it (U+13A0 to U+13FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.0.
