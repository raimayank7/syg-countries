Znamenny Musical Notation: Unicode block U+1CF00 to U+1CFCF

185 characters you can look at, copy and paste. Data from Unicode 18.0.

The Znamenny Musical Notation block covers the code points U+1CF00 to U+1CFCF (208 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 185 of them so far, which are 116 other symbols, 69 non-spacing marks. All its characters were added in Unicode 14.0.

The characters belong to these scripts: Common, Inherited.

What the block contains

The Unicode code charts divide this block into groups: Combining red marks; Combining black marks; Modifying marks for priznaki; Znamenny neumes.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.
