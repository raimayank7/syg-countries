Hangul Jamo: Unicode block U+1100 to U+11FF

256 characters you can look at, copy and paste. Data from Unicode 18.0.

The Hangul Jamo block covers the code points U+1100 to U+11FF (256 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 256 of them so far, which are 256 other letters. Its characters were added between Unicode 1.1 and 5.2.

The characters belong to the script: Hangul.

What the block contains

The Unicode code charts divide this block into groups: Initial consonants; Old initial consonants; Medial vowels; Old medial vowels; Final consonants; Old final consonants.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Hangul Jamo block?

Unicode 18.0 has 256 assigned characters in the Hangul Jamo block, out of 256 code points reserved for it (U+1100 to U+11FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
