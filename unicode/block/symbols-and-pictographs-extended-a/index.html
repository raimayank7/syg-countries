Symbols and Pictographs Extended-A: Unicode block U+1FA70 to U+1FAFF

128 characters you can look at, copy and paste. Data from Unicode 18.0.

The Symbols and Pictographs Extended-A block covers the code points U+1FA70 to U+1FAFF (144 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 128 of them so far, which are 128 other symbols. Its characters were added between Unicode 12.0 and 18.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Clothing; Colored heart symbols; Medical symbols; Toys and sport symbols; Musical instruments; Miscellaneous objects; Religious symbol; Animals and nature; Body parts; People; Miscellaneous; Food and drink; Faces; Emotion and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Symbols and Pictographs Extended-A block?

Unicode 18.0 has 128 assigned characters in the Symbols and Pictographs Extended-A block, out of 144 code points reserved for it (U+1FA70 to U+1FAFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 12.0.
