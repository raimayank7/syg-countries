Ancient Greek Musical Notation: Unicode block U+1D200 to U+1D24F

70 characters you can look at, copy and paste. Data from Unicode 18.0.

The Ancient Greek Musical Notation block covers the code points U+1D200 to U+1D24F (80 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 70 of them so far, which are 67 other symbols, 3 non-spacing marks. All its characters were added in Unicode 4.1.

The characters belong to the script: Greek.

What the block contains

The Unicode code charts divide this block into groups: Ancient Greek vocalic notation; Ancient Greek instrumental notation; Further Greek musical notation symbols.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Ancient Greek Musical Notation block?

Unicode 18.0 has 70 assigned characters in the Ancient Greek Musical Notation block, out of 80 code points reserved for it (U+1D200 to U+1D24F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.1.
