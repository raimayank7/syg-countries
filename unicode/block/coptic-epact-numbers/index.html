Coptic Epact Numbers: Unicode block U+102E0 to U+102FF

28 characters you can look at, copy and paste. Data from Unicode 18.0.

The Coptic Epact Numbers block covers the code points U+102E0 to U+102FF (32 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 28 of them so far, which are 27 other numbers, 1 non-spacing mark. All its characters were added in Unicode 7.0.

The characters belong to these scripts: Common, Inherited.

What the block contains

The Unicode code charts divide this block into groups: Sign; Digits; Numbers.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Coptic Epact Numbers block?

Unicode 18.0 has 28 assigned characters in the Coptic Epact Numbers block, out of 32 code points reserved for it (U+102E0 to U+102FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
