Georgian: Unicode block U+10A0 to U+10FF

88 characters you can look at, copy and paste. Data from Unicode 18.0.

The Georgian block covers the code points U+10A0 to U+10FF (96 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 88 of them so far, which are 46 lowercase letters, 40 uppercase letters, 1 punctuation (other), 1 modifier letter. Its characters were added between Unicode 1.1 and 6.1.

The characters belong to these scripts: Common, Georgian.

What the block contains

The Unicode code charts divide this block into groups: Capital letters (Khutsuri); Additional letter; Additional letter for Ossetian; Mkhedruli; Archaic letters; Additional letters for Mingrelian and Svan; Additional letters; Punctuation; Modifier letter; Additional letters for Ossetian and Abkhaz.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Georgian block?

Unicode 18.0 has 88 assigned characters in the Georgian block, out of 96 code points reserved for it (U+10A0 to U+10FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
