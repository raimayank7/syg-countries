Telugu: Unicode block U+0C00 to U+0C7F

101 characters you can look at, copy and paste. Data from Unicode 18.0.

The Telugu block covers the code points U+0C00 to U+0C7F (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 101 of them so far, which are 58 other letters, 17 non-spacing marks, 10 decimal digits, 7 spacing marks, 7 other numbers. Its characters were added between Unicode 1.1 and 17.0.

The characters belong to the script: Telugu.

What the block contains

The Unicode code charts divide this block into groups: Various signs; Independent vowels; Consonants; Sign; Addition for Sanskrit; Dependent vowel signs; Virama; Historic phonetic variants; Ligature; Consonant; Additional vowels for Sanskrit; Dependent vowels; Digits; Telugu fractions and weights.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Telugu block?

Unicode 18.0 has 101 assigned characters in the Telugu block, out of 128 code points reserved for it (U+0C00 to U+0C7F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
