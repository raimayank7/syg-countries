Bhaiksuki: Unicode block U+11C00 to U+11C6F

97 characters you can look at, copy and paste. Data from Unicode 18.0.

The Bhaiksuki block covers the code points U+11C00 to U+11C6F (112 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 97 of them so far, which are 47 other letters, 19 other numbers, 14 non-spacing marks, 10 decimal digits, 5 other punctuation marks. All its characters were added in Unicode 9.0.

The characters belong to the script: Bhaiksuki.

What the block contains

The Unicode code charts divide this block into groups: Independent vowels; Consonants; Dependent vowel signs; Various signs; Punctuation; Gap fillers; Digits; Numbers.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Bhaiksuki block?

Unicode 18.0 has 97 assigned characters in the Bhaiksuki block, out of 112 code points reserved for it (U+11C00 to U+11C6F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 9.0.
