Phonetic Extensions Supplement: Unicode block U+1D80 to U+1DBF

64 characters you can look at, copy and paste. Data from Unicode 18.0.

The Phonetic Extensions Supplement block covers the code points U+1D80 to U+1DBF (64 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 64 of them so far, which are 37 modifier letters, 27 lowercase letters. All its characters were added in Unicode 4.1.

The characters belong to these scripts: Greek, Latin.

What the block contains

The Unicode code charts divide this block into groups: Latin letters with palatal hook; Latin letters with retroflex hook; Modifier letters.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Phonetic Extensions Supplement block?

Unicode 18.0 has 64 assigned characters in the Phonetic Extensions Supplement block, out of 64 code points reserved for it (U+1D80 to U+1DBF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.1.
