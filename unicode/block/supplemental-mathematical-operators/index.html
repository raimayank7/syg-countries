Supplemental Mathematical Operators: Unicode block U+2A00 to U+2AFF

256 characters you can look at, copy and paste. Data from Unicode 18.0.

The Supplemental Mathematical Operators block covers the code points U+2A00 to U+2AFF (256 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 256 of them so far, which are 256 math symbols. All its characters were added in Unicode 3.2.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: N-ary operators; Summations and integrals; Miscellaneous large operators; Plus and minus sign operators; Multiplication and division sign operators; Miscellaneous mathematical operators; Intersections and unions; Logical ands and ors; Relational operators; Subset and superset relations; Forks; Tacks and turnstiles; Vertical line operators; Miscellaneous mathematical operator and more.

Common questions

How many characters are in the Supplemental Mathematical Operators block?

Unicode 18.0 has 256 assigned characters in the Supplemental Mathematical Operators block, out of 256 code points reserved for it (U+2A00 to U+2AFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.2.
