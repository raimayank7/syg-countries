Katakana: Unicode block U+30A0 to U+30FF

96 characters you can look at, copy and paste. Data from Unicode 18.0.

The Katakana block covers the code points U+30A0 to U+30FF (96 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 96 of them so far, which are 91 other letters, 3 modifier letters, 1 dash, 1 punctuation (other). Its characters were added between Unicode 1.1 and 3.2.

The characters belong to these scripts: Common, Katakana.

What the block contains

The Unicode code charts divide this block into groups: Katakana punctuation; Katakana letters; Conjunction and length marks; Iteration marks; Katakana digraph.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Katakana block?

Unicode 18.0 has 96 assigned characters in the Katakana block, out of 96 code points reserved for it (U+30A0 to U+30FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
