Domino Tiles: Unicode block U+1F030 to U+1F09F

100 characters you can look at, copy and paste. Data from Unicode 18.0.

The Domino Tiles block covers the code points U+1F030 to U+1F09F (112 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 100 of them so far, which are 100 other symbols. All its characters were added in Unicode 5.1.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Horizontal tiles; Zeroes; Ones; Twos; Threes; Fours; Fives; Sixes; Vertical tiles.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Domino Tiles block?

Unicode 18.0 has 100 assigned characters in the Domino Tiles block, out of 112 code points reserved for it (U+1F030 to U+1F09F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.1.
