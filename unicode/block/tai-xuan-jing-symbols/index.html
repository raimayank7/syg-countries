Tai Xuan Jing Symbols: Unicode block U+1D300 to U+1D35F

87 characters you can look at, copy and paste. Data from Unicode 18.0.

The Tai Xuan Jing Symbols block covers the code points U+1D300 to U+1D35F (96 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 87 of them so far, which are 87 other symbols. All its characters were added in Unicode 4.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Monogram; Digrams; Tetragrams.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Tai Xuan Jing Symbols block?

Unicode 18.0 has 87 assigned characters in the Tai Xuan Jing Symbols block, out of 96 code points reserved for it (U+1D300 to U+1D35F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.0.
