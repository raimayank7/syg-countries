Hangul Jamo Extended-A: Unicode block U+A960 to U+A97F

29 characters you can look at, copy and paste. Data from Unicode 18.0.

The Hangul Jamo Extended-A block covers the code points U+A960 to U+A97F (32 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 29 of them so far, which are 29 other letters. All its characters were added in Unicode 5.2.

The characters belong to the script: Hangul.

What the block contains

The Unicode code charts divide this block into groups: Old initial consonants.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Hangul Jamo Extended-A block?

Unicode 18.0 has 29 assigned characters in the Hangul Jamo Extended-A block, out of 32 code points reserved for it (U+A960 to U+A97F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.2.
