Cyrillic Supplement: Unicode block U+0500 to U+052F

48 characters you can look at, copy and paste. Data from Unicode 18.0.

The Cyrillic Supplement block covers the code points U+0500 to U+052F (48 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 48 of them so far, which are 24 uppercase letters, 24 lowercase letters. Its characters were added between Unicode 3.2 and 7.0.

The characters belong to the script: Cyrillic.

What the block contains

The Unicode code charts divide this block into groups: Komi letters; Khanty letters; Chukchi letters; Mordvin letters; Kurdish letters; Aleut letters; Chuvash letters; Abkhaz letters; Azerbaijani letters; Orok letters.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Cyrillic Supplement block?

Unicode 18.0 has 48 assigned characters in the Cyrillic Supplement block, out of 48 code points reserved for it (U+0500 to U+052F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.2.
