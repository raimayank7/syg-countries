Avestan: Unicode block U+10B00 to U+10B3F

61 characters you can look at, copy and paste. Data from Unicode 18.0.

The Avestan block covers the code points U+10B00 to U+10B3F (64 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 61 of them so far, which are 54 other letters, 7 other punctuation marks. All its characters were added in Unicode 5.2.

The characters belong to the script: Avestan.

What the block contains

The Unicode code charts divide this block into groups: Vowels; Consonants; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Avestan block?

Unicode 18.0 has 61 assigned characters in the Avestan block, out of 64 code points reserved for it (U+10B00 to U+10B3F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.2.
