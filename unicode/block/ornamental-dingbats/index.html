Ornamental Dingbats: Unicode block U+1F650 to U+1F67F

48 characters you can look at, copy and paste. Data from Unicode 18.0.

The Ornamental Dingbats block covers the code points U+1F650 to U+1F67F (48 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 48 of them so far, which are 48 other symbols. All its characters were added in Unicode 7.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Fleurons; Quilt square ornaments; Rocket ornaments; Ampersand and ligature et ornaments; Punctuation mark ornaments; Miscellaneous symbols.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Ornamental Dingbats block?

Unicode 18.0 has 48 assigned characters in the Ornamental Dingbats block, out of 48 code points reserved for it (U+1F650 to U+1F67F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
