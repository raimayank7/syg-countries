Tags: Unicode block U+E0000 to U+E007F

97 characters you can look at, copy and paste. Data from Unicode 18.0.

The Tags block covers the code points U+E0000 to U+E007F (128 positions) in the Supplementary Special-purpose Plane (plane 14). Unicode has assigned 97 of them so far, which are 97 format characters. All its characters were added in Unicode 3.1.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Tag identifiers; Tag components; Stateful tag terminator.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Tags block?

Unicode 18.0 has 97 assigned characters in the Tags block, out of 128 code points reserved for it (U+E0000 to U+E007F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.1.
