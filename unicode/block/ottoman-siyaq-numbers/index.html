Ottoman Siyaq Numbers: Unicode block U+1ED00 to U+1ED4F

61 characters you can look at, copy and paste. Data from Unicode 18.0.

The Ottoman Siyaq Numbers block covers the code points U+1ED00 to U+1ED4F (80 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 61 of them so far, which are 60 other numbers, 1 symbol (other). All its characters were added in Unicode 12.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Primary numbers; Tens; Hundreds; Thousands; Ten thousands; Multiplier; Alternate forms; Fractions.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Ottoman Siyaq Numbers block?

Unicode 18.0 has 61 assigned characters in the Ottoman Siyaq Numbers block, out of 80 code points reserved for it (U+1ED00 to U+1ED4F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 12.0.
