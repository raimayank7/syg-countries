Bamum Supplement: Unicode block U+16800 to U+16A3F

569 characters you can look at, copy and paste. Data from Unicode 18.0.

The Bamum Supplement block covers the code points U+16800 to U+16A3F (576 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 569 of them so far, which are 569 other letters. All its characters were added in Unicode 6.0.

Common questions

How many characters are in the Bamum Supplement block?

Unicode 18.0 has 569 assigned characters in the Bamum Supplement block, out of 576 code points reserved for it (U+16800 to U+16A3F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 6.0.
