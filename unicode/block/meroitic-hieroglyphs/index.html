Meroitic Hieroglyphs: Unicode block U+10980 to U+1099F

32 characters you can look at, copy and paste. Data from Unicode 18.0.

The Meroitic Hieroglyphs block covers the code points U+10980 to U+1099F (32 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 32 of them so far, which are 32 other letters. All its characters were added in Unicode 6.1.

The characters belong to the script: Meroitic Hieroglyphs.

What the block contains

The Unicode code charts divide this block into groups: Vowel letters; Consonant letters; Symbols.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Meroitic Hieroglyphs block?

Unicode 18.0 has 32 assigned characters in the Meroitic Hieroglyphs block, out of 32 code points reserved for it (U+10980 to U+1099F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 6.1.
