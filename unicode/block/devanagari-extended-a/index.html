Devanagari Extended-A: Unicode block U+11B00 to U+11B5F

11 characters you can look at, copy and paste. Data from Unicode 18.0.

The Devanagari Extended-A block covers the code points U+11B00 to U+11B5F (96 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 11 of them so far, which are 10 other punctuation marks, 1 letter (other). Its characters were added between Unicode 15.0 and 18.0.

The characters belong to the script: Devanagari.

What the block contains

The Unicode code charts divide this block into groups: Head marks; Auspicious signs; Sindhi implosive letter.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Devanagari Extended-A block?

Unicode 18.0 has 11 assigned characters in the Devanagari Extended-A block, out of 96 code points reserved for it (U+11B00 to U+11B5F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 15.0.
