Runic: Unicode block U+16A0 to U+16FF

89 characters you can look at, copy and paste. Data from Unicode 18.0.

The Runic block covers the code points U+16A0 to U+16FF (96 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 89 of them so far, which are 83 other letters, 3 other punctuation marks, 3 letter-like numbers. Its characters were added between Unicode 3.0 and 7.0.

The characters belong to these scripts: Common, Runic.

What the block contains

The Unicode code charts divide this block into groups: Letters; Punctuation; Golden number runes; Tolkienian extensions; Cryptogrammic letters.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Runic block?

Unicode 18.0 has 89 assigned characters in the Runic block, out of 96 code points reserved for it (U+16A0 to U+16FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.0.
