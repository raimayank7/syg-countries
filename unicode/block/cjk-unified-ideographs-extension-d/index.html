CJK Unified Ideographs Extension D: Unicode block U+2B740 to U+2B81F

223 characters you can look at, copy and paste. Data from Unicode 18.0.

The CJK Unified Ideographs Extension D block covers the code points U+2B740 to U+2B81F (224 positions) in the Supplementary Ideographic Plane (plane 2). Unicode has assigned 223 of them so far, which are 223 other letters. All its characters were added in Unicode 6.0.

Characters in this block are not given individual names in the standard: each is named by its code point, for example "CJK Ideograph Extension D-2B740". The table lists them in code order, 256 to a page.

Common questions

How many characters are in the CJK Unified Ideographs Extension D block?

Unicode 18.0 has 223 assigned characters in the CJK Unified Ideographs Extension D block, out of 224 code points reserved for it (U+2B740 to U+2B81F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?
