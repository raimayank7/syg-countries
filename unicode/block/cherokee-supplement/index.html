Cherokee Supplement: Unicode block U+AB70 to U+ABBF

80 characters you can look at, copy and paste. Data from Unicode 18.0.

The Cherokee Supplement block covers the code points U+AB70 to U+ABBF (80 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 80 of them so far, which are 80 lowercase letters. All its characters were added in Unicode 8.0.

The characters belong to the script: Cherokee.

What the block contains

The Unicode code charts divide this block into groups: Lowercase syllables.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Cherokee Supplement block?

Unicode 18.0 has 80 assigned characters in the Cherokee Supplement block, out of 80 code points reserved for it (U+AB70 to U+ABBF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 8.0.
