Dives Akuru: Unicode block U+11900 to U+1195F

72 characters you can look at, copy and paste. Data from Unicode 18.0.

The Dives Akuru block covers the code points U+11900 to U+1195F (96 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 72 of them so far, which are 44 other letters, 11 spacing marks, 10 decimal digits, 4 non-spacing marks, 3 other punctuation marks. All its characters were added in Unicode 13.0.

The characters belong to the script: Dives Akuru.

What the block contains

The Unicode code charts divide this block into groups: Independent vowels; Consonants; Dependent vowel signs; Nasalization signs; Signs; Conjunct-specific letters; Nukta; Punctuation; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Dives Akuru block?

Unicode 18.0 has 72 assigned characters in the Dives Akuru block, out of 96 code points reserved for it (U+11900 to U+1195F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 13.0.
