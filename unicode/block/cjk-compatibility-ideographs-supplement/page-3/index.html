CJK Compatibility Ideographs Supplement: Unicode block U+2F800 to U+2FA1F

542 characters you can look at, copy and paste. Data from Unicode 18.0.

The CJK Compatibility Ideographs Supplement block covers the code points U+2F800 to U+2FA1F (544 positions) in the Supplementary Ideographic Plane (plane 2). Unicode has assigned 542 of them so far, which are 542 other letters. All its characters were added in Unicode 3.1.

Common questions

How many characters are in the CJK Compatibility Ideographs Supplement block?

Unicode 18.0 has 542 assigned characters in the CJK Compatibility Ideographs Supplement block, out of 544 code points reserved for it (U+2F800 to U+2FA1F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.1.
