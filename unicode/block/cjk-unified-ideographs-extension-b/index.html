CJK Unified Ideographs Extension B: Unicode block U+20000 to U+2A6DF

42,720 characters you can look at, copy and paste. Data from Unicode 18.0.

The CJK Unified Ideographs Extension B block covers the code points U+20000 to U+2A6DF (42,720 positions) in the Supplementary Ideographic Plane (plane 2). Unicode has assigned 42,720 of them so far, which are 42,720 other letters. All its characters were added in Unicode 3.1.

Characters in this block are not given individual names in the standard: each is named by its code point, for example "CJK Ideograph Extension B-20000". The table lists them in code order, 256 to a page. Only the first 1,024 are listed on this site; the other 41,696 characters of the block are not shown, because a page of thousands of look-alike entries helps nobody.

Common questions

How many characters are in the CJK Unified Ideographs Extension B block?

Unicode 18.0 has 42,720 assigned characters in the CJK Unified Ideographs Extension B block, out of 42,720 code points reserved for it (U+20000 to U+2A6DF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.1.
