CJK Unified Ideographs: Unicode block U+4E00 to U+9FFF

20,992 characters you can look at, copy and paste. Data from Unicode 18.0.

The CJK Unified Ideographs block covers the code points U+4E00 to U+9FFF (20,992 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 20,992 of them so far, which are 20,992 other letters. All its characters were added in Unicode 1.1.

Characters in this block are not given individual names in the standard: each is named by its code point, for example "CJK Ideograph-4E00". The table lists them in code order, 256 to a page. Only the first 1,024 are listed on this site; the other 19,968 characters of the block are not shown, because a page of thousands of look-alike entries helps nobody.

Common questions

How many characters are in the CJK Unified Ideographs block?

Unicode 18.0 has 20,992 assigned characters in the CJK Unified Ideographs block, out of 20,992 code points reserved for it (U+4E00 to U+9FFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
