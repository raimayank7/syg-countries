Transport and Map Symbols: Unicode block U+1F680 to U+1F6FF

120 characters you can look at, copy and paste. Data from Unicode 18.0.

The Transport and Map Symbols block covers the code points U+1F680 to U+1F6FF (128 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 120 of them so far, which are 120 other symbols. Its characters were added between Unicode 6.0 and 18.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Vehicles; Traffic signs; Signage and other symbols; Accommodation symbols; Map symbols; Miscellaneous symbols.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

115 of the 120 named characters have their own page.

Common questions

How many characters are in the Transport and Map Symbols block?

Unicode 18.0 has 120 assigned characters in the Transport and Map Symbols block, out of 128 code points reserved for it (U+1F680 to U+1F6FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 6.0.
