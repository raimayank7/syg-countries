Malayalam: Unicode block U+0D00 to U+0D7F

118 characters you can look at, copy and paste. Data from Unicode 18.0.

The Malayalam block covers the code points U+0D00 to U+0D7F (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 118 of them so far, which are 67 other letters, 16 other numbers, 12 spacing marks, 11 non-spacing marks, 10 decimal digits. Its characters were added between Unicode 1.1 and 13.0.

The characters belong to the script: Malayalam.

What the block contains

The Unicode code charts divide this block into groups: Various signs; Independent vowels; Consonants; Variant shape viramas; Addition for Sanskrit; Dependent vowel signs; Two-part dependent vowel signs; Virama; Dot reph; Measurement symbol; Additional historic chillu letters; Dependent vowel sign; Minor fractions; Additional historic vowel and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Malayalam block?

Unicode 18.0 has 118 assigned characters in the Malayalam block, out of 128 code points reserved for it (U+0D00 to U+0D7F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
