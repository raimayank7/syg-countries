Supplemental Arrows-C: Unicode block U+1F800 to U+1F8FF

171 characters you can look at, copy and paste. Data from Unicode 18.0.

The Supplemental Arrows-C block covers the code points U+1F800 to U+1F8FF (256 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 171 of them so far, which are 162 other symbols, 9 math symbols. Its characters were added between Unicode 7.0 and 17.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Arrows with triangle arrowheads; Arrows with equilateral triangle arrowheads; Triangle headed arrows with different shaft weights; Finger-post arrows; Squared arrows; Compressed arrows; Heavy arrows; Sans-serif arrows; Wide-headed barb arrows; Arrowheads; Notched arrows; Heavy arrow shafts; Shaded white arrows; White arrow shafts and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Supplemental Arrows-C block?

Unicode 18.0 has 171 assigned characters in the Supplemental Arrows-C block, out of 256 code points reserved for it (U+1F800 to U+1F8FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
