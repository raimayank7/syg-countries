Symbols for Legacy Computing: Unicode block U+1FB00 to U+1FBFF

250 characters you can look at, copy and paste. Data from Unicode 18.0.

The Symbols for Legacy Computing block covers the code points U+1FB00 to U+1FBFF (256 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 250 of them so far, which are 240 other symbols, 10 decimal digits. Its characters were added between Unicode 13.0 and 17.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Block mosaic terminal graphic characters; Smooth mosaic terminal graphic characters; Block elements; Window title bar; Rectangular shade characters; Fill characters; Diagonal fill characters; Triangular shade characters; Character cell diagonals; Light solid line with stroke; Terminal graphic characters; Arrows; Negative terminal graphic characters; Geometric shapes and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Symbols for Legacy Computing block?

Unicode 18.0 has 250 assigned characters in the Symbols for Legacy Computing block, out of 256 code points reserved for it (U+1FB00 to U+1FBFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 13.0.
