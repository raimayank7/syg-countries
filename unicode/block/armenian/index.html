Armenian: Unicode block U+0530 to U+058F

94 characters you can look at, copy and paste. Data from Unicode 18.0.

The Armenian block covers the code points U+0530 to U+058F (96 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 94 of them so far, which are 41 lowercase letters, 38 uppercase letters, 7 other punctuation marks, 4 modifier letters, 2 other symbols. Its characters were added between Unicode 1.1 and 18.0.

The characters belong to the script: Armenian.

What the block contains

The Unicode code charts divide this block into groups: Uppercase letters; Modifier letters; Lowercase letters; Punctuation; Religious symbols; Currency symbol.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Armenian block?

Unicode 18.0 has 94 assigned characters in the Armenian block, out of 96 code points reserved for it (U+0530 to U+058F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
