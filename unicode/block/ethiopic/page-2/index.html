Ethiopic: Unicode block U+1200 to U+137F

358 characters you can look at, copy and paste. Data from Unicode 18.0.

The Ethiopic block covers the code points U+1200 to U+137F (384 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 358 of them so far, which are 326 other letters, 20 other numbers, 9 other punctuation marks, 3 non-spacing marks. Its characters were added between Unicode 3.0 and 6.0.

Common questions

How many characters are in the Ethiopic block?

Unicode 18.0 has 358 assigned characters in the Ethiopic block, out of 384 code points reserved for it (U+1200 to U+137F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.0.
