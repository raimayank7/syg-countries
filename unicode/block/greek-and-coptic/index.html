Greek and Coptic: Unicode block U+0370 to U+03FF

135 characters you can look at, copy and paste. Data from Unicode 18.0.

The Greek and Coptic block covers the code points U+0370 to U+03FF (144 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 135 of them so far, which are 67 lowercase letters, 60 uppercase letters, 3 modifier symbols, 2 modifier letters, 2 other punctuation marks. Its characters were added between Unicode 1.1 and 7.0.

The characters belong to these scripts: Common, Coptic, Greek.

What the block contains

The Unicode code charts divide this block into groups: Archaic letters; Numeral signs; Iota subscript; Lowercase of editorial symbols; Punctuation; Additional letter; Spacing accent marks; Letter; Letters; Variant letterforms; Coptic letters derived from Demotic; Variant letterforms and symbols; Additional archaic letters for Bactrian; Variant letterform and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Greek and Coptic block?

Unicode 18.0 has 135 assigned characters in the Greek and Coptic block, out of 144 code points reserved for it (U+0370 to U+03FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
