Combining Diacritical Marks Supplement: Unicode block U+1DC0 to U+1DFF

64 characters you can look at, copy and paste. Data from Unicode 18.0.

The Combining Diacritical Marks Supplement block covers the code points U+1DC0 to U+1DFF (64 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 64 of them so far, which are 64 non-spacing marks. Its characters were added between Unicode 4.1 and 14.0.

The characters belong to the script: Inherited.

What the block contains

The Unicode code charts divide this block into groups: Used for Ancient Greek; Miscellaneous marks; Contour tone marks; Miscellaneous mark; Double diacritic; Medievalist additions; Medieval superscript letter diacritics; Superscript letter diacritics for German dialectology; Diacritic for American lexicography; Typicon marks; Double diacritic mark for UPA; Additional marks for UPA.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Combining Diacritical Marks Supplement block?

Unicode 18.0 has 64 assigned characters in the Combining Diacritical Marks Supplement block, out of 64 code points reserved for it (U+1DC0 to U+1DFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.1.
