Tifinagh: Unicode block U+2D30 to U+2D7F

59 characters you can look at, copy and paste. Data from Unicode 18.0.

The Tifinagh block covers the code points U+2D30 to U+2D7F (80 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 59 of them so far, which are 56 other letters, 1 modifier letter, 1 punctuation (other), 1 non-spacing mark. Its characters were added between Unicode 4.1 and 6.1.

The characters belong to the script: Tifinagh.

What the block contains

The Unicode code charts divide this block into groups: Letters; Modifier letter; Punctuation; Sign.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Tifinagh block?

Unicode 18.0 has 59 assigned characters in the Tifinagh block, out of 80 code points reserved for it (U+2D30 to U+2D7F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.1.
