Cuneiform: Unicode block U+12000 to U+123FF

922 characters you can look at, copy and paste. Data from Unicode 18.0.

The Cuneiform block covers the code points U+12000 to U+123FF (1,024 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 922 of them so far, which are 922 other letters. Its characters were added between Unicode 5.0 and 8.0.

Common questions

How many characters are in the Cuneiform block?

Unicode 18.0 has 922 assigned characters in the Cuneiform block, out of 1,024 code points reserved for it (U+12000 to U+123FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.0.
