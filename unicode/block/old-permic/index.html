Old Permic: Unicode block U+10350 to U+1037F

43 characters you can look at, copy and paste. Data from Unicode 18.0.

The Old Permic block covers the code points U+10350 to U+1037F (48 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 43 of them so far, which are 38 other letters, 5 non-spacing marks. All its characters were added in Unicode 7.0.

The characters belong to the script: Old Permic.

What the block contains

The Unicode code charts divide this block into groups: Letters; Combining letters.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Old Permic block?

Unicode 18.0 has 43 assigned characters in the Old Permic block, out of 48 code points reserved for it (U+10350 to U+1037F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
