Symbols for Legacy Computing Supplement: Unicode block U+1CC00 to U+1CEBF

695 characters you can look at, copy and paste. Data from Unicode 18.0.

The Symbols for Legacy Computing Supplement block covers the code points U+1CC00 to U+1CEBF (704 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 695 of them so far, which are 685 other symbols, 10 decimal digits. Its characters were added between Unicode 16.0 and 17.0.

Common questions

How many characters are in the Symbols for Legacy Computing Supplement block?

Unicode 18.0 has 695 assigned characters in the Symbols for Legacy Computing Supplement block, out of 704 code points reserved for it (U+1CC00 to U+1CEBF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 16.0.
