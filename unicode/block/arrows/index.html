Arrows: Unicode block U+2190 to U+21FF

112 characters you can look at, copy and paste. Data from Unicode 18.0.

The Arrows block covers the code points U+2190 to U+21FF (112 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 112 of them so far, which are 85 other symbols, 27 math symbols. Its characters were added between Unicode 1.1 and 3.2.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Simple arrows; Arrows with modifications; Arrows with bent tips; Keyboard symbols and circle arrows; Harpoons; Paired arrows and harpoons; Double arrows; Miscellaneous arrows and keyboard symbols; White arrows and keyboard symbols; Miscellaneous arrows.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

109 of the 112 named characters have their own page.

Common questions

How many characters are in the Arrows block?

Unicode 18.0 has 112 assigned characters in the Arrows block, out of 112 code points reserved for it (U+2190 to U+21FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
