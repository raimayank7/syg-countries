Gunjala Gondi: Unicode block U+11D60 to U+11DAF

63 characters you can look at, copy and paste. Data from Unicode 18.0.

The Gunjala Gondi block covers the code points U+11D60 to U+11DAF (80 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 63 of them so far, which are 41 other letters, 10 decimal digits, 8 spacing marks, 4 non-spacing marks. All its characters were added in Unicode 11.0.

The characters belong to the script: Gunjala Gondi.

What the block contains

The Unicode code charts divide this block into groups: Independent vowels; Consonants; Dependent vowel signs; Various signs; Virama; Symbol; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Gunjala Gondi block?

Unicode 18.0 has 63 assigned characters in the Gunjala Gondi block, out of 80 code points reserved for it (U+11D60 to U+11DAF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 11.0.
