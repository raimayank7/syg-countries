Enclosed CJK Letters and Months: Unicode block U+3200 to U+32FF

255 characters you can look at, copy and paste. Data from Unicode 18.0.

The Enclosed CJK Letters and Months block covers the code points U+3200 to U+32FF (256 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 255 of them so far, which are 197 other symbols, 58 other numbers. Its characters were added between Unicode 1.1 and 12.1.

The characters belong to these scripts: Common, Hangul, Katakana.

What the block contains

The Unicode code charts divide this block into groups: Parenthesized Hangul letters; Parenthesized Hangul syllables; Parenthesized Korean words; Parenthesized ideographs; Circled ideographs from ARIB STD B24; Circled numbers on black squares from ARIB STD B24; Squared Latin abbreviation; Circled numbers; Circled Hangul letters; Circled Hangul syllables; Circled Korean words; Circled Hangul syllable; Symbol; Circled ideographs and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Enclosed CJK Letters and Months block?

Unicode 18.0 has 255 assigned characters in the Enclosed CJK Letters and Months block, out of 256 code points reserved for it (U+3200 to U+32FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
