Latin Extended-E: Unicode block U+AB30 to U+AB6F

62 characters you can look at, copy and paste. Data from Unicode 18.0.

The Latin Extended-E block covers the code points U+AB30 to U+AB6F (64 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 62 of them so far, which are 52 lowercase letters, 5 modifier letters, 3 modifier symbols, 2 uppercase letters. Its characters were added between Unicode 7.0 and 18.0.

The characters belong to these scripts: Common, Greek, Latin.

What the block contains

The Unicode code charts divide this block into groups: Letters for German dialectology; Modifier letters for German dialectology; Historic letters for Sakha (Yakut); Letters for Americanist orthographies; Letters for sinological and Tibetanist phonetic transcription; Letters for Scots dialectology.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Latin Extended-E block?

Unicode 18.0 has 62 assigned characters in the Latin Extended-E block, out of 64 code points reserved for it (U+AB30 to U+AB6F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
