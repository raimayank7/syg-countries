CJK Unified Ideographs Extension J: Unicode block U+323B0 to U+3347F

4,298 characters you can look at, copy and paste. Data from Unicode 18.0.

The CJK Unified Ideographs Extension J block covers the code points U+323B0 to U+3347F (4,304 positions) in the Tertiary Ideographic Plane (plane 3). Unicode has assigned 4,298 of them so far, which are 4,298 other letters. All its characters were added in Unicode 17.0.

Characters in this block are not given individual names in the standard: each is named by its code point, for example "CJK Ideograph Extension J-323B0". The table lists them in code order, 256 to a page. Only the first 1,024 are listed on this site; the other 3,274 characters of the block are not shown, because a page of thousands of look-alike entries helps nobody.

Common questions

How many characters are in the CJK Unified Ideographs Extension J block?

Unicode 18.0 has 4,298 assigned characters in the CJK Unified Ideographs Extension J block, out of 4,304 code points reserved for it (U+323B0 to U+3347F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 17.0.
