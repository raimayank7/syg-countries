Sunuwar: Unicode block U+11BC0 to U+11BFF

44 characters you can look at, copy and paste. Data from Unicode 18.0.

The Sunuwar block covers the code points U+11BC0 to U+11BFF (64 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 44 of them so far, which are 33 other letters, 10 decimal digits, 1 punctuation (other). All its characters were added in Unicode 16.0.

The characters belong to the script: Sunuwar.

What the block contains

The Unicode code charts divide this block into groups: Letters; Punctuation; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Sunuwar block?

Unicode 18.0 has 44 assigned characters in the Sunuwar block, out of 64 code points reserved for it (U+11BC0 to U+11BFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 16.0.
