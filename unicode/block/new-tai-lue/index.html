New Tai Lue: Unicode block U+1980 to U+19DF

83 characters you can look at, copy and paste. Data from Unicode 18.0.

The New Tai Lue block covers the code points U+1980 to U+19DF (96 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 83 of them so far, which are 70 other letters, 10 decimal digits, 2 other symbols, 1 other number. Its characters were added between Unicode 4.1 and 5.2.

The characters belong to the script: New Tai Lue.

What the block contains

The Unicode code charts divide this block into groups: Consonants; Vowels; Final consonants; Tone marks; Digits; Various signs.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the New Tai Lue block?

Unicode 18.0 has 83 assigned characters in the New Tai Lue block, out of 96 code points reserved for it (U+1980 to U+19DF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.1.
