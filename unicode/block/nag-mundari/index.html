Nag Mundari: Unicode block U+1E4D0 to U+1E4FF

42 characters you can look at, copy and paste. Data from Unicode 18.0.

The Nag Mundari block covers the code points U+1E4D0 to U+1E4FF (48 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 42 of them so far, which are 27 other letters, 10 decimal digits, 4 non-spacing marks, 1 modifier letter. All its characters were added in Unicode 15.0.

The characters belong to the script: Nag Mundari.

What the block contains

The Unicode code charts divide this block into groups: Letters; Various signs; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Nag Mundari block?

Unicode 18.0 has 42 assigned characters in the Nag Mundari block, out of 48 code points reserved for it (U+1E4D0 to U+1E4FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 15.0.
