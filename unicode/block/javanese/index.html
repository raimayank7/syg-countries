Javanese: Unicode block U+A980 to U+A9DF

91 characters you can look at, copy and paste. Data from Unicode 18.0.

The Javanese block covers the code points U+A980 to U+A9DF (96 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 91 of them so far, which are 47 other letters, 15 other punctuation marks, 10 non-spacing marks, 10 decimal digits, 8 spacing marks. All its characters were added in Unicode 5.2.

The characters belong to these scripts: Common, Javanese.

What the block contains

The Unicode code charts divide this block into groups: Various signs; Letters; Sign; Dependent vowel signs; Dependent consonant signs; Punctuation; Syllable reduplicator; Digits; Ellipsis marks.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Javanese block?

Unicode 18.0 has 91 assigned characters in the Javanese block, out of 96 code points reserved for it (U+A980 to U+A9DF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.2.
