Kangxi Radicals: Unicode block U+2F00 to U+2FDF

214 characters you can look at, copy and paste. Data from Unicode 18.0.

The Kangxi Radicals block covers the code points U+2F00 to U+2FDF (224 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 214 of them so far, which are 214 other symbols. All its characters were added in Unicode 3.0.

The characters belong to the script: Han.

What the block contains

The Unicode code charts divide this block into groups: Kangxi radicals.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Kangxi Radicals block?

Unicode 18.0 has 214 assigned characters in the Kangxi Radicals block, out of 224 code points reserved for it (U+2F00 to U+2FDF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.0.
