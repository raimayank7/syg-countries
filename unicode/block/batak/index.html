Batak: Unicode block U+1BC0 to U+1BFF

56 characters you can look at, copy and paste. Data from Unicode 18.0.

The Batak block covers the code points U+1BC0 to U+1BFF (64 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 56 of them so far, which are 38 other letters, 7 non-spacing marks, 7 spacing marks, 4 other punctuation marks. All its characters were added in Unicode 6.0.

The characters belong to the script: Batak.

What the block contains

The Unicode code charts divide this block into groups: Letters; Sign; Dependent vowel signs; Dependent consonant signs; Signs; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Batak block?

Unicode 18.0 has 56 assigned characters in the Batak block, out of 64 code points reserved for it (U+1BC0 to U+1BFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 6.0.
