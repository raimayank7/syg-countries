Myanmar: Unicode block U+1000 to U+109F

160 characters you can look at, copy and paste. Data from Unicode 18.0.

The Myanmar block covers the code points U+1000 to U+109F (160 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 160 of them so far, which are 74 other letters, 30 spacing marks, 28 non-spacing marks, 20 decimal digits, 6 other punctuation marks. Its characters were added between Unicode 3.0 and 5.2.

The characters belong to the script: Myanmar.

What the block contains

The Unicode code charts divide this block into groups: Consonants; Independent vowels; Dependent vowel signs; Various signs; Virama and killer; Dependent consonant signs; Consonant; Digits; Punctuation; Pali and Sanskrit extensions; Extensions for Mon; Extensions for S'gaw Karen; Extensions for Western Pwo Karen; Extensions for Eastern Pwo Karen and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Myanmar block?

Unicode 18.0 has 160 assigned characters in the Myanmar block, out of 160 code points reserved for it (U+1000 to U+109F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.0.
