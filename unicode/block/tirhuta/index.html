Tirhuta: Unicode block U+11480 to U+114DF

82 characters you can look at, copy and paste. Data from Unicode 18.0.

The Tirhuta block covers the code points U+11480 to U+114DF (96 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 82 of them so far, which are 51 other letters, 11 non-spacing marks, 10 decimal digits, 9 spacing marks, 1 punctuation (other). All its characters were added in Unicode 7.0.

The characters belong to the script: Tirhuta.

What the block contains

The Unicode code charts divide this block into groups: Sign; Independent vowels; Consonants; Dependent vowel signs; Various signs; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Tirhuta block?

Unicode 18.0 has 82 assigned characters in the Tirhuta block, out of 96 code points reserved for it (U+11480 to U+114DF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
