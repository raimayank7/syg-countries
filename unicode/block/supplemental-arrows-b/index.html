Supplemental Arrows-B: Unicode block U+2900 to U+297F

128 characters you can look at, copy and paste. Data from Unicode 18.0.

The Supplemental Arrows-B block covers the code points U+2900 to U+297F (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 128 of them so far, which are 128 math symbols. All its characters were added in Unicode 3.2.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Miscellaneous arrows; Arrow tails; Crossing arrows for knot theory; Miscellaneous curved arrows; Arrows combined with operators; Double-barbed harpoons; Modified harpoons; Paired harpoons; Miscellaneous arrow; Arrows combined with relations; Fish tails.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

107 of the 128 named characters have their own page.

Common questions

How many characters are in the Supplemental Arrows-B block?

Unicode 18.0 has 128 assigned characters in the Supplemental Arrows-B block, out of 128 code points reserved for it (U+2900 to U+297F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.2.
