Latin Extended Additional: Unicode block U+1E00 to U+1EFF

256 characters you can look at, copy and paste. Data from Unicode 18.0.

The Latin Extended Additional block covers the code points U+1E00 to U+1EFF (256 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 256 of them so far, which are 132 lowercase letters, 124 uppercase letters. Its characters were added between Unicode 1.1 and 5.1.

The characters belong to the script: Latin.

What the block contains

The Unicode code charts divide this block into groups: Latin general use extensions; Medievalist additions; Addition for German typography; Medievalist addition; Latin extensions for Vietnamese; Latin general extensions.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

255 of the 256 named characters have their own page.

Common questions

How many characters are in the Latin Extended Additional block?

Unicode 18.0 has 256 assigned characters in the Latin Extended Additional block, out of 256 code points reserved for it (U+1E00 to U+1EFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
