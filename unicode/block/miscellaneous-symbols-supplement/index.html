Miscellaneous Symbols Supplement: Unicode block U+1CEC0 to U+1CEFF

53 characters you can look at, copy and paste. Data from Unicode 18.0.

The Miscellaneous Symbols Supplement block covers the code points U+1CEC0 to U+1CEFF (64 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 53 of them so far, which are 36 other symbols, 17 math symbols. Its characters were added between Unicode 17.0 and 18.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Astronomical symbols for asteroids; Alchemical symbols; Radix signs for historical mathematics; Symbols for geomantic figures; Miscellaneous symbol; Historic Leibnizian mathematical operators; Sector and angle symbols; Miscellaneous geometrical symbol.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Miscellaneous Symbols Supplement block?

Unicode 18.0 has 53 assigned characters in the Miscellaneous Symbols Supplement block, out of 64 code points reserved for it (U+1CEC0 to U+1CEFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 17.0.
