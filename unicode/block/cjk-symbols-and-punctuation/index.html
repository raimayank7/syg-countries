CJK Symbols and Punctuation: Unicode block U+3000 to U+303F

64 characters you can look at, copy and paste. Data from Unicode 18.0.

The CJK Symbols and Punctuation block covers the code points U+3000 to U+303F (64 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 64 of them so far, which are 13 letter-like numbers, 11 closing brackets, 10 opening brackets, 8 other symbols, 7 modifier letters. Its characters were added between Unicode 1.1 and 3.2.

The characters belong to these scripts: Common, Han, Hangul, Inherited.

What the block contains

The Unicode code charts divide this block into groups: CJK symbols and punctuation; CJK angle brackets; CJK corner brackets; CJK brackets; CJK symbols; CJK punctuation; CJK symbol; Suzhou numerals; Combining tone marks; Other CJK punctuation; Kana repeat marks; Other CJK symbols; Additional Suzhou numerals; Special CJK indicators.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

53 of the 64 named characters have their own page.

Common questions

How many characters are in the CJK Symbols and Punctuation block?

Unicode 18.0 has 64 assigned characters in the CJK Symbols and Punctuation block, out of 64 code points reserved for it (U+3000 to U+303F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
