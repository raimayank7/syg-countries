Control Pictures: Unicode block U+2400 to U+243F

42 characters you can look at, copy and paste. Data from Unicode 18.0.

The Control Pictures block covers the code points U+2400 to U+243F (64 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 42 of them so far, which are 42 other symbols. Its characters were added between Unicode 1.1 and 16.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Graphic pictures for control codes; Specific symbols for space; Graphic picture for control code; Keyboard symbol; Specific symbol for control code; Legacy computer symbols for delete.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

39 of the 42 named characters have their own page.

Common questions

How many characters are in the Control Pictures block?

Unicode 18.0 has 42 assigned characters in the Control Pictures block, out of 64 code points reserved for it (U+2400 to U+243F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
