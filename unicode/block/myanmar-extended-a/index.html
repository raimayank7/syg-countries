Myanmar Extended-A: Unicode block U+AA60 to U+AA7F

32 characters you can look at, copy and paste. Data from Unicode 18.0.

The Myanmar Extended-A block covers the code points U+AA60 to U+AA7F (32 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 32 of them so far, which are 25 other letters, 3 other symbols, 2 spacing marks, 1 modifier letter, 1 non-spacing mark. Its characters were added between Unicode 5.2 and 7.0.

The characters belong to the script: Myanmar.

What the block contains

The Unicode code charts divide this block into groups: Khamti Shan consonants; Khamti Shan logograms; Aiton symbols and letters; Pa'o Karen tone mark; Tai Laing tone marks; Shwe Palaung letters.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Myanmar Extended-A block?

Unicode 18.0 has 32 assigned characters in the Myanmar Extended-A block, out of 32 code points reserved for it (U+AA60 to U+AA7F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.2.
