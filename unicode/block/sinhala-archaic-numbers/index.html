Sinhala Archaic Numbers: Unicode block U+111E0 to U+111FF

20 characters you can look at, copy and paste. Data from Unicode 18.0.

The Sinhala Archaic Numbers block covers the code points U+111E0 to U+111FF (32 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 20 of them so far, which are 20 other numbers. All its characters were added in Unicode 7.0.

The characters belong to the script: Sinhala.

What the block contains

The Unicode code charts divide this block into groups: Historical digits; Historical numbers.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Sinhala Archaic Numbers block?

Unicode 18.0 has 20 assigned characters in the Sinhala Archaic Numbers block, out of 32 code points reserved for it (U+111E0 to U+111FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
