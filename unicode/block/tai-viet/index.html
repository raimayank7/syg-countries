Tai Viet: Unicode block U+AA80 to U+AADF

72 characters you can look at, copy and paste. Data from Unicode 18.0.

The Tai Viet block covers the code points U+AA80 to U+AADF (96 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 72 of them so far, which are 60 other letters, 9 non-spacing marks, 2 other punctuation marks, 1 modifier letter. All its characters were added in Unicode 5.2.

The characters belong to the script: Tai Viet.

What the block contains

The Unicode code charts divide this block into groups: Consonants; Vowels and finals; Tones; Word ligature symbols; Repetition mark; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Tai Viet block?

Unicode 18.0 has 72 assigned characters in the Tai Viet block, out of 96 code points reserved for it (U+AA80 to U+AADF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.2.
