Sutton SignWriting: Unicode block U+1D800 to U+1DAAF

672 characters you can look at, copy and paste. Data from Unicode 18.0.

The Sutton SignWriting block covers the code points U+1D800 to U+1DAAF (688 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 672 of them so far, which are 540 other symbols, 127 non-spacing marks, 5 other punctuation marks. All its characters were added in Unicode 8.0.

The characters belong to the script: SignWriting.

What the block contains

The Unicode code charts divide this block into groups: Hand shapes with index finger; Hand shapes with index and middle fingers; Hand shapes with index and middle fingers and thumb; Hand shapes with four fingers; Hand shapes with five fingers; Hand shapes with little finger; Hand shapes with ring finger; Hand shapes with middle finger; Hand shapes with index finger and thumb; Hand shapes with thumb; Contact movement indicators; Finger movement indicators; Movement indicators; Dynamics indicators and more.
