Sutton SignWriting: Unicode block U+1D800 to U+1DAAF

672 characters you can look at, copy and paste. Data from Unicode 18.0.

The Sutton SignWriting block covers the code points U+1D800 to U+1DAAF (688 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 672 of them so far, which are 540 other symbols, 127 non-spacing marks, 5 other punctuation marks. All its characters were added in Unicode 8.0.

Common questions

How many characters are in the Sutton SignWriting block?

Unicode 18.0 has 672 assigned characters in the Sutton SignWriting block, out of 688 code points reserved for it (U+1D800 to U+1DAAF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 8.0.
