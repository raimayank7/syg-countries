Spacing Modifier Letters: Unicode block U+02B0 to U+02FF

80 characters you can look at, copy and paste. Data from Unicode 18.0.

The Spacing Modifier Letters block covers the code points U+02B0 to U+02FF (80 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 80 of them so far, which are 43 modifier symbols, 37 modifier letters. Its characters were added between Unicode 1.1 and 4.0.

The characters belong to these scripts: Bopomofo, Common, Latin.

What the block contains

The Unicode code charts divide this block into groups: Latin superscript modifier letters; Miscellaneous phonetic modifiers; Spacing clones of diacritics; Additions based on 1989 IPA; Tone letters; Extended Bopomofo tone marks; IPA modifiers; Other modifier letter; UPA modifiers.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Spacing Modifier Letters block?

Unicode 18.0 has 80 assigned characters in the Spacing Modifier Letters block, out of 80 code points reserved for it (U+02B0 to U+02FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
