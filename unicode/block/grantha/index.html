Grantha: Unicode block U+11300 to U+1137F

86 characters you can look at, copy and paste. Data from Unicode 18.0.

The Grantha block covers the code points U+11300 to U+1137F (128 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 86 of them so far, which are 53 other letters, 17 non-spacing marks, 16 spacing marks. Its characters were added between Unicode 7.0 and 11.0.

The characters belong to these scripts: Grantha, Inherited.

What the block contains

The Unicode code charts divide this block into groups: Various signs; Independent vowels; Consonants; Dependent vowel signs; Two-part dependent vowel signs; Virama; Sign; Dependent vowel sign; Anusvaras; Cantillation marks (svara) for the Samaveda.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Grantha block?

Unicode 18.0 has 86 assigned characters in the Grantha block, out of 128 code points reserved for it (U+11300 to U+1137F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
