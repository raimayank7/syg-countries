Khitan Small Script: Unicode block U+18B00 to U+18CFF

476 characters you can look at, copy and paste. Data from Unicode 18.0.

The Khitan Small Script block covers the code points U+18B00 to U+18CFF (512 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 476 of them so far, which are 476 other letters. Its characters were added between Unicode 13.0 and 18.0.

The characters belong to the script: Khitan Small Script.

What the block contains

The Unicode code charts divide this block into groups: Iteration mark; Radical-01; Radical-02; Radical-03; Radical-04; Radical-05; Radical-06; Radical-07; Radical-08; Radical-09; Radical-10; Radical-11; Radical-12; Radical-13 and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Khitan Small Script block?

Unicode 18.0 has 476 assigned characters in the Khitan Small Script block, out of 512 code points reserved for it (U+18B00 to U+18CFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 13.0.
