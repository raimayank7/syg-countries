Nushu: Unicode block U+1B170 to U+1B2FF

396 characters you can look at, copy and paste. Data from Unicode 18.0.

The Nushu block covers the code points U+1B170 to U+1B2FF (400 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 396 of them so far, which are 396 other letters. All its characters were added in Unicode 10.0.

The characters belong to the script: Nushu.

What the block contains

The Unicode code charts divide this block into groups: One-stroke character; Two-stroke characters; Three-stroke characters; Four-stroke characters; Five-stroke characters; Six-stroke characters; Seven-stroke characters; Eight-stroke characters; Nine-stroke characters; Ten-stroke characters; Eleven-stroke characters; Twelve-stroke characters; Thirteen-stroke characters; Fourteen-stroke characters and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Nushu block?

Unicode 18.0 has 396 assigned characters in the Nushu block, out of 400 code points reserved for it (U+1B170 to U+1B2FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?
