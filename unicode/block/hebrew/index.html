Hebrew: Unicode block U+0590 to U+05FF

90 characters you can look at, copy and paste. Data from Unicode 18.0.

The Hebrew block covers the code points U+0590 to U+05FF (112 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 90 of them so far, which are 53 non-spacing marks, 31 other letters, 5 other punctuation marks, 1 dash. Its characters were added between Unicode 1.1 and 18.0.

The characters belong to the script: Hebrew.

What the block contains

The Unicode code charts divide this block into groups: Cantillation marks; Points and punctuation; Puncta extraordinaria; Based on ISO/IEC 8859-8; Sign; Yiddish digraphs; Additional punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Hebrew block?

Unicode 18.0 has 90 assigned characters in the Hebrew block, out of 112 code points reserved for it (U+0590 to U+05FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
