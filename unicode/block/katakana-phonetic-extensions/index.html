Katakana Phonetic Extensions: Unicode block U+31F0 to U+31FF

16 characters you can look at, copy and paste. Data from Unicode 18.0.

The Katakana Phonetic Extensions block covers the code points U+31F0 to U+31FF (16 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 16 of them so far, which are 16 other letters. All its characters were added in Unicode 3.2.

The characters belong to the script: Katakana.

What the block contains

The Unicode code charts divide this block into groups: Phonetic extensions for Ainu.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Katakana Phonetic Extensions block?

Unicode 18.0 has 16 assigned characters in the Katakana Phonetic Extensions block, out of 16 code points reserved for it (U+31F0 to U+31FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.2.
