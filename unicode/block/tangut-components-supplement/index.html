Tangut Components Supplement: Unicode block U+18D80 to U+18DFF

115 characters you can look at, copy and paste. Data from Unicode 18.0.

The Tangut Components Supplement block covers the code points U+18D80 to U+18DFF (128 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 115 of them so far, which are 115 other letters. All its characters were added in Unicode 17.0.

The characters belong to the script: Tangut.

What the block contains

The Unicode code charts divide this block into groups: Miscellaneous components; One-stroke components; Two-stroke component; Three-stroke component; Four-stroke components; Five-stroke components; Six-stroke components; Seven-stroke components; Eight-stroke components; Nine-stroke components; Ten-stroke components; Eleven-stroke components; Twelve-stroke components; Thirteen-stroke components and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Tangut Components Supplement block?

Unicode 18.0 has 115 assigned characters in the Tangut Components Supplement block, out of 128 code points reserved for it (U+18D80 to U+18DFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 17.0.
