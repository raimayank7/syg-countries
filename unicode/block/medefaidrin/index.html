Medefaidrin: Unicode block U+16E40 to U+16E9F

91 characters you can look at, copy and paste. Data from Unicode 18.0.

The Medefaidrin block covers the code points U+16E40 to U+16E9F (96 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 91 of them so far, which are 32 uppercase letters, 32 lowercase letters, 23 other numbers, 4 other punctuation marks. All its characters were added in Unicode 11.0.

The characters belong to the script: Medefaidrin.

What the block contains

The Unicode code charts divide this block into groups: Uppercase letters; Lowercase letters; Digits; Numbers; Alternate digits; Punctuation; Symbols.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Medefaidrin block?

Unicode 18.0 has 91 assigned characters in the Medefaidrin block, out of 96 code points reserved for it (U+16E40 to U+16E9F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 11.0.
