Arabic Extended-B: Unicode block U+0870 to U+089F

43 characters you can look at, copy and paste. Data from Unicode 18.0.

The Arabic Extended-B block covers the code points U+0870 to U+089F (48 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 43 of them so far, which are 31 other letters, 9 non-spacing marks, 2 format characters, 1 modifier symbol. Its characters were added between Unicode 14.0 and 17.0.

The characters belong to the script: Arabic.

What the block contains

The Unicode code charts divide this block into groups: Additions for Quranic orthographies; Additions for Bosnian orthographies; Additions for Pegon orthographies; Abbreviation mark; Addition for Eastern Punjabi orthographies; Supertending currency symbols; Vowel sign for Pegon.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Arabic Extended-B block?

Unicode 18.0 has 43 assigned characters in the Arabic Extended-B block, out of 48 code points reserved for it (U+0870 to U+089F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 14.0.
