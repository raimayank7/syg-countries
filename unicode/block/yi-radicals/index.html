Yi Radicals: Unicode block U+A490 to U+A4CF

55 characters you can look at, copy and paste. Data from Unicode 18.0.

The Yi Radicals block covers the code points U+A490 to U+A4CF (64 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 55 of them so far, which are 55 other symbols. Its characters were added between Unicode 3.0 and 3.2.

The characters belong to the script: Yi.

What the block contains

The Unicode code charts divide this block into groups: Yi radicals.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Yi Radicals block?

Unicode 18.0 has 55 assigned characters in the Yi Radicals block, out of 64 code points reserved for it (U+A490 to U+A4CF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.0.
