Osmanya: Unicode block U+10480 to U+104AF

40 characters you can look at, copy and paste. Data from Unicode 18.0.

The Osmanya block covers the code points U+10480 to U+104AF (48 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 40 of them so far, which are 30 other letters, 10 decimal digits. All its characters were added in Unicode 4.0.

The characters belong to the script: Osmanya.

What the block contains

The Unicode code charts divide this block into groups: Letters; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Osmanya block?

Unicode 18.0 has 40 assigned characters in the Osmanya block, out of 48 code points reserved for it (U+10480 to U+104AF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.0.
