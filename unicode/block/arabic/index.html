Arabic: Unicode block U+0600 to U+06FF

256 characters you can look at, copy and paste. Data from Unicode 18.0.

The Arabic block covers the code points U+0600 to U+06FF (256 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 256 of them so far, which are 150 other letters, 52 non-spacing marks, 20 decimal digits, 13 other punctuation marks, 8 format characters. Its characters were added between Unicode 1.1 and 14.0.

The characters belong to these scripts: Arabic, Common, Inherited.

What the block contains

The Unicode code charts divide this block into groups: Subtending marks; Supertending mark; Radix symbols; Letterlike symbol; Punctuation; Currency symbol; Poetic marks; Honorifics; Quranic annotation sign; Extended Arabic mark; Quranic annotation signs; Format character; Addition for Kashmiri; Based on ISO/IEC 8859-6 and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Arabic block?

Unicode 18.0 has 256 assigned characters in the Arabic block, out of 256 code points reserved for it (U+0600 to U+06FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
