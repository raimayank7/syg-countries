Kana Extended-A: Unicode block U+1B100 to U+1B12F

41 characters you can look at, copy and paste. Data from Unicode 18.0.

The Kana Extended-A block covers the code points U+1B100 to U+1B12F (48 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 41 of them so far, which are 41 other letters. Its characters were added between Unicode 10.0 and 18.0.

The characters belong to these scripts: Hiragana, Katakana.

What the block contains

The Unicode code charts divide this block into groups: Hentaigana; Historic Hiragana; Historic Katakana; Historic Hiragana digraph; Historic Katakana digraphs.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Kana Extended-A block?

Unicode 18.0 has 41 assigned characters in the Kana Extended-A block, out of 48 code points reserved for it (U+1B100 to U+1B12F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 10.0.
