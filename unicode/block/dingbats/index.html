Dingbats: Unicode block U+2700 to U+27BF

192 characters you can look at, copy and paste. Data from Unicode 18.0.

The Dingbats block covers the code points U+2700 to U+27BF (192 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 192 of them so far, which are 148 other symbols, 30 other numbers, 7 opening brackets, 7 closing brackets. Its characters were added between Unicode 1.1 and 7.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Miscellaneous; Crosses; Stars and asterisks; Fleurons; Stars, asterisks and snowflakes; Punctuation mark ornaments; Ornamental brackets; Dingbat circled digits; Dingbat arrow; Heavy variants of arithmetic symbols; Dingbat arrows.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Dingbats block?

Unicode 18.0 has 192 assigned characters in the Dingbats block, out of 192 code points reserved for it (U+2700 to U+27BF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
