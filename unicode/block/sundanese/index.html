Sundanese: Unicode block U+1B80 to U+1BBF

64 characters you can look at, copy and paste. Data from Unicode 18.0.

The Sundanese block covers the code points U+1B80 to U+1BBF (64 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 64 of them so far, which are 38 other letters, 11 non-spacing marks, 10 decimal digits, 5 spacing marks. Its characters were added between Unicode 5.1 and 6.1.

The characters belong to the script: Sundanese.

What the block contains

The Unicode code charts divide this block into groups: Various signs; Vowels; Consonants; Consonant signs; Vowel signs; Viramas; Additional consonants; Digits; Sign; Historic letters.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Sundanese block?

Unicode 18.0 has 64 assigned characters in the Sundanese block, out of 64 code points reserved for it (U+1B80 to U+1BBF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.1.
