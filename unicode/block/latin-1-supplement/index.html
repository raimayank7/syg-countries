Latin-1 Supplement: Unicode block U+0080 to U+00FF

128 characters you can look at, copy and paste. Data from Unicode 18.0.

The Latin-1 Supplement block covers the code points U+0080 to U+00FF (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 128 of them so far, which are 33 lowercase letters, 32 control characters, 30 uppercase letters, 6 other numbers, 5 other punctuation marks. All its characters were added in Unicode 1.1.

The characters belong to these scripts: Common, Latin.

What the block contains

The Unicode code charts divide this block into groups: C1 controls; Latin-1 punctuation and symbols; Vulgar fractions; Punctuation; Uppercase letters; Mathematical operator; Lowercase letters.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Latin-1 Supplement block?

Unicode 18.0 has 128 assigned characters in the Latin-1 Supplement block, out of 128 code points reserved for it (U+0080 to U+00FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
