Ideographic Description Characters: Unicode block U+2FF0 to U+2FFF

16 characters you can look at, copy and paste. Data from Unicode 18.0.

The Ideographic Description Characters block covers the code points U+2FF0 to U+2FFF (16 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 16 of them so far, which are 16 other symbols. Its characters were added between Unicode 3.0 and 15.1.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Ideographic description characters.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Ideographic Description Characters block?

Unicode 18.0 has 16 assigned characters in the Ideographic Description Characters block, out of 16 code points reserved for it (U+2FF0 to U+2FFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.0.
