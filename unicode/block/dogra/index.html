Dogra: Unicode block U+11800 to U+1184F

60 characters you can look at, copy and paste. Data from Unicode 18.0.

The Dogra block covers the code points U+11800 to U+1184F (80 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 60 of them so far, which are 44 other letters, 11 non-spacing marks, 4 spacing marks, 1 punctuation (other). All its characters were added in Unicode 11.0.

The characters belong to the script: Dogra.

What the block contains

The Unicode code charts divide this block into groups: Independent vowels; Consonants; Dependent vowel signs; Various signs; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Dogra block?

Unicode 18.0 has 60 assigned characters in the Dogra block, out of 80 code points reserved for it (U+11800 to U+1184F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 11.0.
