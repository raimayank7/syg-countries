Superscripts and Subscripts: Unicode block U+2070 to U+209F

46 characters you can look at, copy and paste. Data from Unicode 18.0.

The Superscripts and Subscripts block covers the code points U+2070 to U+209F (48 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 46 of them so far, which are 19 modifier letters, 17 other numbers, 6 math symbols, 2 opening brackets, 2 closing brackets. Its characters were added between Unicode 1.1 and 18.0.

The characters belong to these scripts: Common, Latin.

What the block contains

The Unicode code charts divide this block into groups: Superscripts; Subscripts; Modifier letter; Subscripts for UPA; Subscripts for other phonetic transcription.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Superscripts and Subscripts block?

Unicode 18.0 has 46 assigned characters in the Superscripts and Subscripts block, out of 48 code points reserved for it (U+2070 to U+209F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
