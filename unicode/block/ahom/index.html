Ahom: Unicode block U+11700 to U+1174F

65 characters you can look at, copy and paste. Data from Unicode 18.0.

The Ahom block covers the code points U+11700 to U+1174F (80 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 65 of them so far, which are 34 other letters, 11 non-spacing marks, 10 decimal digits, 4 spacing marks, 3 other punctuation marks. Its characters were added between Unicode 8.0 and 14.0.

The characters belong to the script: Ahom.

What the block contains

The Unicode code charts divide this block into groups: Consonants; Medials; Vowel signs; Digits; Numbers; Punctuation; Additional consonants.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Ahom block?

Unicode 18.0 has 65 assigned characters in the Ahom block, out of 80 code points reserved for it (U+11700 to U+1174F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 8.0.
