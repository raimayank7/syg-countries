Box Drawing: Unicode block U+2500 to U+257F

128 characters you can look at, copy and paste. Data from Unicode 18.0.

The Box Drawing block covers the code points U+2500 to U+257F (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 128 of them so far, which are 128 other symbols. All its characters were added in Unicode 1.1.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Light and heavy solid lines; Light and heavy dashed lines; Light and heavy line box components; Double lines; Light and double line box components; Character cell arcs; Character cell diagonals; Light and heavy half lines; Mixed light and heavy lines.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Box Drawing block?

Unicode 18.0 has 128 assigned characters in the Box Drawing block, out of 128 code points reserved for it (U+2500 to U+257F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
