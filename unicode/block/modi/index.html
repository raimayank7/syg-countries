Modi: Unicode block U+11600 to U+1165F

79 characters you can look at, copy and paste. Data from Unicode 18.0.

The Modi block covers the code points U+11600 to U+1165F (96 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 79 of them so far, which are 49 other letters, 11 non-spacing marks, 10 decimal digits, 6 spacing marks, 3 other punctuation marks. All its characters were added in Unicode 7.0.

The characters belong to the script: Modi.

What the block contains

The Unicode code charts divide this block into groups: Independent vowels; Consonants; Dependent vowel signs; Various signs; Punctuation; Sign; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Modi block?

Unicode 18.0 has 79 assigned characters in the Modi block, out of 96 code points reserved for it (U+11600 to U+1165F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
