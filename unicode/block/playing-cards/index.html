Playing Cards: Unicode block U+1F0A0 to U+1F0FF

82 characters you can look at, copy and paste. Data from Unicode 18.0.

The Playing Cards block covers the code points U+1F0A0 to U+1F0FF (96 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 82 of them so far, which are 82 other symbols. Its characters were added between Unicode 6.0 and 7.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Back of card; Spades or swords; Hearts or cups; Joker; Diamonds or pentacles; Clubs or wands; Trumps.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

28 of the 82 named characters have their own page.

Common questions

How many characters are in the Playing Cards block?

Unicode 18.0 has 82 assigned characters in the Playing Cards block, out of 96 code points reserved for it (U+1F0A0 to U+1F0FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 6.0.
