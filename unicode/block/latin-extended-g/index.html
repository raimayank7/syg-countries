Latin Extended-G: Unicode block U+1DF00 to U+1DFFF

188 characters you can look at, copy and paste. Data from Unicode 18.0.

The Latin Extended-G block covers the code points U+1DF00 to U+1DFFF (256 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 188 of them so far, which are 118 lowercase letters, 51 modifier letters, 16 uppercase letters, 3 other letters. Its characters were added between Unicode 14.0 and 18.0.

The characters belong to these scripts: Greek, Latin.

What the block contains

The Unicode code charts divide this block into groups: Extended IPA for disordered speech; IPA extensions; Clicks; Lateral; Letters with palatal hooks; Letters with retroflex hooks; IPA extension; Affricate ligatures; Letters for romanized Malayalam; Ligatures of historical IPA letters; IPA letters with palatal hook; Barred letters; RFE letters; ITA letters and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Latin Extended-G block?

Unicode 18.0 has 188 assigned characters in the Latin Extended-G block, out of 256 code points reserved for it (U+1DF00 to U+1DFFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 14.0.
