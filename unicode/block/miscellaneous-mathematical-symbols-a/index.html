Miscellaneous Mathematical Symbols-A: Unicode block U+27C0 to U+27EF

48 characters you can look at, copy and paste. Data from Unicode 18.0.

The Miscellaneous Mathematical Symbols-A block covers the code points U+27C0 to U+27EF (48 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 48 of them so far, which are 36 math symbols, 6 opening brackets, 6 closing brackets. Its characters were added between Unicode 3.2 and 6.1.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Miscellaneous symbols; Paired punctuation; Operator; Vertical line operator; Miscellaneous symbol; Division operator; Operators; Database theory operators; Tacks and turnstiles; Modal logic operators; Mathematical brackets.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Miscellaneous Mathematical Symbols-A block?

Unicode 18.0 has 48 assigned characters in the Miscellaneous Mathematical Symbols-A block, out of 48 code points reserved for it (U+27C0 to U+27EF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.2.
