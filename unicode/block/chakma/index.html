Chakma: Unicode block U+11100 to U+1114F

71 characters you can look at, copy and paste. Data from Unicode 18.0.

The Chakma block covers the code points U+11100 to U+1114F (80 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 71 of them so far, which are 38 other letters, 16 non-spacing marks, 10 decimal digits, 4 other punctuation marks, 3 spacing marks. Its characters were added between Unicode 6.1 and 13.0.

The characters belong to the script: Chakma.

What the block contains

The Unicode code charts divide this block into groups: Various signs; Independent vowels; Consonants; Dependent vowel signs; Digits; Punctuation; Consonant.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Chakma block?

Unicode 18.0 has 71 assigned characters in the Chakma block, out of 80 code points reserved for it (U+11100 to U+1114F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 6.1.
