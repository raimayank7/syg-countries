Ethiopic Extended-A: Unicode block U+AB00 to U+AB2F

32 characters you can look at, copy and paste. Data from Unicode 18.0.

The Ethiopic Extended-A block covers the code points U+AB00 to U+AB2F (48 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 32 of them so far, which are 32 other letters. All its characters were added in Unicode 6.0.

The characters belong to the script: Ethiopic.

What the block contains

The Unicode code charts divide this block into groups: Gamo-Gofa-Dawro and Basketo; Gamo-Gofa-Dawro; Gumuz.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Ethiopic Extended-A block?

Unicode 18.0 has 32 assigned characters in the Ethiopic Extended-A block, out of 48 code points reserved for it (U+AB00 to U+AB2F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 6.0.
