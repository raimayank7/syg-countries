Miscellaneous Symbols and Pictographs: Unicode block U+1F300 to U+1F5FF

768 characters you can look at, copy and paste. Data from Unicode 18.0.

The Miscellaneous Symbols and Pictographs block covers the code points U+1F300 to U+1F5FF (768 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 768 of them so far, which are 763 other symbols, 5 modifier symbols. Its characters were added between Unicode 6.0 and 9.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Weather, landscape, and sky symbols; Globe symbols; Moon, sun, and star symbols; Weather symbols; Food symbols; Plant symbols; Fruit and vegetable symbols; Beverage symbols; Accommodation symbol; Beverage and food symbols; Celebration symbols; Musical symbols; Entertainment symbols; Game symbols and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

726 of the 768 named characters have their own page.

Common questions

How many characters are in the Miscellaneous Symbols and Pictographs block?

Unicode 18.0 has 768 assigned characters in the Miscellaneous Symbols and Pictographs block, out of 768 code points reserved for it (U+1F300 to U+1F5FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 6.0.
