Variation Selectors Supplement: Unicode block U+E0100 to U+E01EF

240 characters you can look at, copy and paste. Data from Unicode 18.0.

The Variation Selectors Supplement block covers the code points U+E0100 to U+E01EF (240 positions) in the Supplementary Special-purpose Plane (plane 14). Unicode has assigned 240 of them so far, which are 240 non-spacing marks. All its characters were added in Unicode 4.0.

The characters belong to the script: Inherited.

What the block contains

The Unicode code charts divide this block into groups: Ideographic-specific variation selectors.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Variation Selectors Supplement block?

Unicode 18.0 has 240 assigned characters in the Variation Selectors Supplement block, out of 240 code points reserved for it (U+E0100 to U+E01EF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.0.
