Manichaean: Unicode block U+10AC0 to U+10AFF

51 characters you can look at, copy and paste. Data from Unicode 18.0.

The Manichaean block covers the code points U+10AC0 to U+10AFF (64 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 51 of them so far, which are 36 other letters, 7 other punctuation marks, 5 other numbers, 2 non-spacing marks, 1 symbol (other). All its characters were added in Unicode 7.0.

The characters belong to the script: Manichaean.

What the block contains

The Unicode code charts divide this block into groups: Letters; Logogram; Combining marks; Numbers; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Manichaean block?

Unicode 18.0 has 51 assigned characters in the Manichaean block, out of 64 code points reserved for it (U+10AC0 to U+10AFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
