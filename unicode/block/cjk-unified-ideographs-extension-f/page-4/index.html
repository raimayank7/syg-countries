CJK Unified Ideographs Extension F: Unicode block U+2CEB0 to U+2EBEF

7,473 characters you can look at, copy and paste. Data from Unicode 18.0.

The CJK Unified Ideographs Extension F block covers the code points U+2CEB0 to U+2EBEF (7,488 positions) in the Supplementary Ideographic Plane (plane 2). Unicode has assigned 7,473 of them so far, which are 7,473 other letters. All its characters were added in Unicode 10.0.

Common questions

How many characters are in the CJK Unified Ideographs Extension F block?

Unicode 18.0 has 7,473 assigned characters in the CJK Unified Ideographs Extension F block, out of 7,488 code points reserved for it (U+2CEB0 to U+2EBEF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 10.0.
