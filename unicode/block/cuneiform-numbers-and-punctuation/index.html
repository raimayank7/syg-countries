Cuneiform Numbers and Punctuation: Unicode block U+12400 to U+1247F

128 characters you can look at, copy and paste. Data from Unicode 18.0.

The Cuneiform Numbers and Punctuation block covers the code points U+12400 to U+1247F (128 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 128 of them so far, which are 123 letter-like numbers, 5 other punctuation marks. Its characters were added between Unicode 5.0 and 18.0.

The characters belong to the script: Cuneiform.

What the block contains

The Unicode code charts divide this block into groups: Common numeric signs; Area measures; Variant stacking patterns; Slanted numerals; Capacity measures; Fractions; Elamite fractions; Elamite numeric signs; Slanted numeral; Punctuation; Numerals for Early Dynastic regnal years.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Cuneiform Numbers and Punctuation block?

Unicode 18.0 has 128 assigned characters in the Cuneiform Numbers and Punctuation block, out of 128 code points reserved for it (U+12400 to U+1247F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.0.
