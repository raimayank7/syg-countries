Soyombo: Unicode block U+11A50 to U+11AAF

83 characters you can look at, copy and paste. Data from Unicode 18.0.

The Soyombo block covers the code points U+11A50 to U+11AAF (96 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 83 of them so far, which are 48 other letters, 24 non-spacing marks, 8 other punctuation marks, 3 spacing marks. Its characters were added between Unicode 10.0 and 12.0.

The characters belong to the script: Soyombo.

What the block contains

The Unicode code charts divide this block into groups: Vowel letter; Vowel signs; Vowel length mark; Consonants; Alternate visarga signs; Cluster-initial letters; Final consonant signs; Various signs; Gemination mark; Subjoiner; Punctuation; Elongation mark; Head marks; Terminal marks.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Soyombo block?

Unicode 18.0 has 83 assigned characters in the Soyombo block, out of 96 code points reserved for it (U+11A50 to U+11AAF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 10.0.
