CJK Unified Ideographs Extension E: Unicode block U+2B820 to U+2CEAF

5,774 characters you can look at, copy and paste. Data from Unicode 18.0.

The CJK Unified Ideographs Extension E block covers the code points U+2B820 to U+2CEAF (5,776 positions) in the Supplementary Ideographic Plane (plane 2). Unicode has assigned 5,774 of them so far, which are 5,774 other letters. All its characters were added in Unicode 8.0.

Characters in this block are not given individual names in the standard: each is named by its code point, for example "CJK Ideograph Extension E-2B820". The table lists them in code order, 256 to a page. Only the first 1,024 are listed on this site; the other 4,750 characters of the block are not shown, because a page of thousands of look-alike entries helps nobody.

Common questions

How many characters are in the CJK Unified Ideographs Extension E block?

Unicode 18.0 has 5,774 assigned characters in the CJK Unified Ideographs Extension E block, out of 5,776 code points reserved for it (U+2B820 to U+2CEAF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 8.0.
