CJK Compatibility Forms: Unicode block U+FE30 to U+FE4F

32 characters you can look at, copy and paste. Data from Unicode 18.0.

The CJK Compatibility Forms block covers the code points U+FE30 to U+FE4F (32 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 32 of them so far, which are 9 opening brackets, 9 closing brackets, 7 other punctuation marks, 5 connector punctuations, 2 dashes. Its characters were added between Unicode 1.1 and 4.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Glyphs for vertical variants; Sidelining emphasis marks; Overscores and underscores.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the CJK Compatibility Forms block?

Unicode 18.0 has 32 assigned characters in the CJK Compatibility Forms block, out of 32 code points reserved for it (U+FE30 to U+FE4F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
