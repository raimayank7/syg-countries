Egyptian Hieroglyphs: Unicode block U+13000 to U+1342F

1,072 characters you can look at, copy and paste. Data from Unicode 18.0.

The Egyptian Hieroglyphs block covers the code points U+13000 to U+1342F (1,072 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 1,072 of them so far, which are 1,072 other letters. Its characters were added between Unicode 5.2 and 15.0.

Common questions

How many characters are in the Egyptian Hieroglyphs block?

Unicode 18.0 has 1,072 assigned characters in the Egyptian Hieroglyphs block, out of 1,072 code points reserved for it (U+13000 to U+1342F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.2.
