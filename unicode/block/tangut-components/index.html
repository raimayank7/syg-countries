Tangut Components: Unicode block U+18800 to U+18AFF

768 characters you can look at, copy and paste. Data from Unicode 18.0.

The Tangut Components block covers the code points U+18800 to U+18AFF (768 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 768 of them so far, which are 768 other letters. Its characters were added between Unicode 9.0 and 13.0.

The characters belong to the script: Tangut.

What the block contains

The Unicode code charts divide this block into groups: One-stroke components; Two-stroke components; Three-stroke components; Four-stroke components; Five-stroke components; Six-stroke components; Seven-stroke components; Eight-stroke components; Nine-stroke components; Ten-stroke component; Ten-stroke components; Eleven-stroke components; Twelve-stroke components; Thirteen-stroke components and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Tangut Components block?

Unicode 18.0 has 768 assigned characters in the Tangut Components block, out of 768 code points reserved for it (U+18800 to U+18AFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 9.0.
