Mahajani: Unicode block U+11150 to U+1117F

39 characters you can look at, copy and paste. Data from Unicode 18.0.

The Mahajani block covers the code points U+11150 to U+1117F (48 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 39 of them so far, which are 36 other letters, 2 other punctuation marks, 1 non-spacing mark. All its characters were added in Unicode 7.0.

The characters belong to the script: Mahajani.

What the block contains

The Unicode code charts divide this block into groups: Vowels; Consonants; Sign; Punctuation; Word ligature.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Mahajani block?

Unicode 18.0 has 39 assigned characters in the Mahajani block, out of 48 code points reserved for it (U+11150 to U+1117F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
