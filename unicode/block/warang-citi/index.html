Warang Citi: Unicode block U+118A0 to U+118FF

84 characters you can look at, copy and paste. Data from Unicode 18.0.

The Warang Citi block covers the code points U+118A0 to U+118FF (96 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 84 of them so far, which are 32 uppercase letters, 32 lowercase letters, 10 decimal digits, 9 other numbers, 1 letter (other). All its characters were added in Unicode 7.0.

The characters belong to the script: Warang Citi.

What the block contains

The Unicode code charts divide this block into groups: Uppercase vowels; Uppercase consonants; Lowercase vowels; Lowercase consonants; Digits; Numbers; Sign.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Warang Citi block?

Unicode 18.0 has 84 assigned characters in the Warang Citi block, out of 96 code points reserved for it (U+118A0 to U+118FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
