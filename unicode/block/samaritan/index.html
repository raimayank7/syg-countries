Samaritan: Unicode block U+0800 to U+083F

61 characters you can look at, copy and paste. Data from Unicode 18.0.

The Samaritan block covers the code points U+0800 to U+083F (64 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 61 of them so far, which are 22 other letters, 21 non-spacing marks, 15 other punctuation marks, 3 modifier letters. All its characters were added in Unicode 5.2.

The characters belong to the script: Samaritan.

What the block contains

The Unicode code charts divide this block into groups: Letters; Consonant modifiers; Vowel signs; Variant reading sign; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Samaritan block?

Unicode 18.0 has 61 assigned characters in the Samaritan block, out of 64 code points reserved for it (U+0800 to U+083F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.2.
