Sharada: Unicode block U+11180 to U+111DF

96 characters you can look at, copy and paste. Data from Unicode 18.0.

The Sharada block covers the code points U+11180 to U+111DF (96 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 96 of them so far, which are 54 other letters, 16 non-spacing marks, 10 decimal digits, 9 other punctuation marks, 7 spacing marks. Its characters were added between Unicode 6.1 and 13.0.

The characters belong to the script: Sharada.

What the block contains

The Unicode code charts divide this block into groups: Various signs; Independent vowels; Consonants; Dependent vowel signs; Virama; Punctuation; Sign; Signs for Kashmiri; Historic vowel sign; Digits; Section marks.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Sharada block?

Unicode 18.0 has 96 assigned characters in the Sharada block, out of 96 code points reserved for it (U+11180 to U+111DF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 6.1.
