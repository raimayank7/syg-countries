Meroitic Cursive: Unicode block U+109A0 to U+109FF

90 characters you can look at, copy and paste. Data from Unicode 18.0.

The Meroitic Cursive block covers the code points U+109A0 to U+109FF (96 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 90 of them so far, which are 64 other numbers, 26 other letters. Its characters were added between Unicode 6.1 and 8.0.

The characters belong to the script: Meroitic Cursive.

What the block contains

The Unicode code charts divide this block into groups: Vowel letters; Consonant letters; Fractions; Logograms; Digits; Tens; Hundreds; Thousands; Ten thousands; Hundred thousands.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Meroitic Cursive block?

Unicode 18.0 has 90 assigned characters in the Meroitic Cursive block, out of 96 code points reserved for it (U+109A0 to U+109FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 6.1.
