Musical Symbols: Unicode block U+1D100 to U+1D1FF

256 characters you can look at, copy and paste. Data from Unicode 18.0.

The Musical Symbols block covers the code points U+1D100 to U+1D1FF (256 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 256 of them so far, which are 216 other symbols, 24 non-spacing marks, 8 spacing marks, 8 format characters. Its characters were added between Unicode 3.1 and 18.0.

The characters belong to these scripts: Common, Inherited.

What the block contains

The Unicode code charts divide this block into groups: Bars; Codas; Figure repetitions; Holds and pauses; Staff brackets; Staves; Tablature; Clefs; Stress marks; Rest; Pitch modifiers; Time signatures; Octaves; Rests and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Musical Symbols block?

Unicode 18.0 has 256 assigned characters in the Musical Symbols block, out of 256 code points reserved for it (U+1D100 to U+1D1FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.1.
