Limbu: Unicode block U+1900 to U+194F

68 characters you can look at, copy and paste. Data from Unicode 18.0.

The Limbu block covers the code points U+1900 to U+194F (80 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 68 of them so far, which are 31 other letters, 15 spacing marks, 10 decimal digits, 9 non-spacing marks, 2 other punctuation marks. Its characters were added between Unicode 4.0 and 7.0.

The characters belong to the script: Limbu.

What the block contains

The Unicode code charts divide this block into groups: Consonants; Dependent vowel signs; Subjoined consonants; Final consonants; Various signs; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Limbu block?

Unicode 18.0 has 68 assigned characters in the Limbu block, out of 80 code points reserved for it (U+1900 to U+194F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.0.
