Lao: Unicode block U+0E80 to U+0EFF

83 characters you can look at, copy and paste. Data from Unicode 18.0.

The Lao block covers the code points U+0E80 to U+0EFF (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 83 of them so far, which are 55 other letters, 17 non-spacing marks, 10 decimal digits, 1 modifier letter. Its characters were added between Unicode 1.1 and 15.0.

The characters belong to the script: Lao.

What the block contains

The Unicode code charts divide this block into groups: Consonants; Sign; Vowels; Virama; Vowel; Signs; Repetition mark; Tone marks; Digits; Digraphs; Consonants for Khmu.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Lao block?

Unicode 18.0 has 83 assigned characters in the Lao block, out of 128 code points reserved for it (U+0E80 to U+0EFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
