Linear A: Unicode block U+10600 to U+1077F

341 characters you can look at, copy and paste. Data from Unicode 18.0.

The Linear A block covers the code points U+10600 to U+1077F (384 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 341 of them so far, which are 341 other letters. All its characters were added in Unicode 7.0.

The characters belong to the script: Linear A.

What the block contains

The Unicode code charts divide this block into groups: Simple signs; Vase shapes; Complex signs; Complex signs with vase shapes; Fractions and compound fractions; Additional signs.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Linear A block?

Unicode 18.0 has 341 assigned characters in the Linear A block, out of 384 code points reserved for it (U+10600 to U+1077F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
