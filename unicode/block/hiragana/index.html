Hiragana: Unicode block U+3040 to U+309F

93 characters you can look at, copy and paste. Data from Unicode 18.0.

The Hiragana block covers the code points U+3040 to U+309F (96 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 93 of them so far, which are 87 other letters, 2 non-spacing marks, 2 modifier symbols, 2 modifier letters. Its characters were added between Unicode 1.1 and 3.2.

The characters belong to these scripts: Common, Hiragana, Inherited.

What the block contains

The Unicode code charts divide this block into groups: Hiragana letters; Small letters; Voicing marks; Iteration marks; Hiragana digraph.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Hiragana block?

Unicode 18.0 has 93 assigned characters in the Hiragana block, out of 96 code points reserved for it (U+3040 to U+309F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
