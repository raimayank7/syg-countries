Mahjong Tiles: Unicode block U+1F000 to U+1F02F

44 characters you can look at, copy and paste. Data from Unicode 18.0.

The Mahjong Tiles block covers the code points U+1F000 to U+1F02F (48 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 44 of them so far, which are 44 other symbols. All its characters were added in Unicode 5.1.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Prevailing wind tiles; Dragon tiles; Character suit tiles; Bamboo suit tiles; Circle suit tiles; Flower tiles; Season tiles; Miscellaneous tiles.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

11 of the 44 named characters have their own page.

Common questions

How many characters are in the Mahjong Tiles block?

Unicode 18.0 has 44 assigned characters in the Mahjong Tiles block, out of 48 code points reserved for it (U+1F000 to U+1F02F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.1.
