Nyiakeng Puachue Hmong: Unicode block U+1E100 to U+1E14F

71 characters you can look at, copy and paste. Data from Unicode 18.0.

The Nyiakeng Puachue Hmong block covers the code points U+1E100 to U+1E14F (80 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 71 of them so far, which are 46 other letters, 10 decimal digits, 7 non-spacing marks, 7 modifier letters, 1 symbol (other). All its characters were added in Unicode 12.0.

The characters belong to the script: Nyiakeng Puachue Hmong.

What the block contains

The Unicode code charts divide this block into groups: Consonant onsets; Vowel rimes; Tone marks; Determinatives; Repetition mark; Syllable lengthener; Digits; Symbols.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.
