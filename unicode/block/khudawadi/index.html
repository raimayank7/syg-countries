Khudawadi: Unicode block U+112B0 to U+112FF

69 characters you can look at, copy and paste. Data from Unicode 18.0.

The Khudawadi block covers the code points U+112B0 to U+112FF (80 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 69 of them so far, which are 47 other letters, 10 decimal digits, 9 non-spacing marks, 3 spacing marks. All its characters were added in Unicode 7.0.

The characters belong to the script: Khudawadi.

What the block contains

The Unicode code charts divide this block into groups: Independent vowels; Consonants; Sign; Dependent vowel signs; Various signs; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Khudawadi block?

Unicode 18.0 has 69 assigned characters in the Khudawadi block, out of 80 code points reserved for it (U+112B0 to U+112FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
