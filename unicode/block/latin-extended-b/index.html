Latin Extended-B: Unicode block U+0180 to U+024F

208 characters you can look at, copy and paste. Data from Unicode 18.0.

The Latin Extended-B block covers the code points U+0180 to U+024F (208 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 208 of them so far, which are 103 uppercase letters, 96 lowercase letters, 5 other letters, 4 titlecase letters. Its characters were added between Unicode 1.1 and 5.0.

The characters belong to the script: Latin.

What the block contains

The Unicode code charts divide this block into groups: Non-European and historic Latin; African letters for clicks; Latin digraphs matching Serbian Cyrillic letters; Pinyin diacritic-vowel combinations; Phonetic and historic letters; Additions for Slovenian; Additions for Romanian; Miscellaneous additions; Additions for Livonian; Additions for Sinology; Miscellaneous addition; Additions for Africanist linguistics; Additions for Sencoten.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Latin Extended-B block?

Unicode 18.0 has 208 assigned characters in the Latin Extended-B block, out of 208 code points reserved for it (U+0180 to U+024F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
