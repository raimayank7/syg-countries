Deseret: Unicode block U+10400 to U+1044F

80 characters you can look at, copy and paste. Data from Unicode 18.0.

The Deseret block covers the code points U+10400 to U+1044F (80 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 80 of them so far, which are 40 uppercase letters, 40 lowercase letters. Its characters were added between Unicode 3.1 and 4.0.

The characters belong to the script: Deseret.

What the block contains

The Unicode code charts divide this block into groups: Uppercase letters; Lowercase letters.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Deseret block?

Unicode 18.0 has 80 assigned characters in the Deseret block, out of 80 code points reserved for it (U+10400 to U+1044F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.1.
