Early Dynastic Cuneiform: Unicode block U+12480 to U+1254F

196 characters you can look at, copy and paste. Data from Unicode 18.0.

The Early Dynastic Cuneiform block covers the code points U+12480 to U+1254F (208 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 196 of them so far, which are 196 other letters. All its characters were added in Unicode 8.0.

The characters belong to the script: Cuneiform.

What the block contains

The Unicode code charts divide this block into groups: Signs.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Early Dynastic Cuneiform block?

Unicode 18.0 has 196 assigned characters in the Early Dynastic Cuneiform block, out of 208 code points reserved for it (U+12480 to U+1254F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 8.0.
