Linear B Syllabary: Unicode block U+10000 to U+1007F

88 characters you can look at, copy and paste. Data from Unicode 18.0.

The Linear B Syllabary block covers the code points U+10000 to U+1007F (128 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 88 of them so far, which are 88 other letters. All its characters were added in Unicode 4.0.

The characters belong to the script: Linear B.

What the block contains

The Unicode code charts divide this block into groups: Basic syllables; Supplementary signs; Symbols.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Linear B Syllabary block?

Unicode 18.0 has 88 assigned characters in the Linear B Syllabary block, out of 128 code points reserved for it (U+10000 to U+1007F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.0.
