Unified Canadian Aboriginal Syllabics Extended: Unicode block U+18B0 to U+18FF

70 characters you can look at, copy and paste. Data from Unicode 18.0.

The Unified Canadian Aboriginal Syllabics Extended block covers the code points U+18B0 to U+18FF (80 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 70 of them so far, which are 70 other letters. All its characters were added in Unicode 5.2.

The characters belong to the script: Canadian Aboriginal.

What the block contains

The Unicode code charts divide this block into groups: Syllables for Moose Cree; Syllables for Cree and Ojibway; Finals for Cree and Ojibway; Syllables for Beaver Dene, Hare Dene, and Chipewyan Dene; Finals for Dene and Carrier.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Unified Canadian Aboriginal Syllabics Extended block?

Unicode 18.0 has 70 assigned characters in the Unified Canadian Aboriginal Syllabics Extended block, out of 80 code points reserved for it (U+18B0 to U+18FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.2.
