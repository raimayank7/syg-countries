Tangsa: Unicode block U+16A70 to U+16ACF

89 characters you can look at, copy and paste. Data from Unicode 18.0.

The Tangsa block covers the code points U+16A70 to U+16ACF (96 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 89 of them so far, which are 79 other letters, 10 decimal digits. All its characters were added in Unicode 14.0.

The characters belong to the script: Tangsa.

What the block contains

The Unicode code charts divide this block into groups: Vowels; Consonants; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Tangsa block?

Unicode 18.0 has 89 assigned characters in the Tangsa block, out of 96 code points reserved for it (U+16A70 to U+16ACF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 14.0.
