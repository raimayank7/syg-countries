Arabic Supplement: Unicode block U+0750 to U+077F

48 characters you can look at, copy and paste. Data from Unicode 18.0.

The Arabic Supplement block covers the code points U+0750 to U+077F (48 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 48 of them so far, which are 48 other letters. Its characters were added between Unicode 4.1 and 5.1.

The characters belong to the script: Arabic.

What the block contains

The Unicode code charts divide this block into groups: Extended Arabic letters; Additions for Khowar; Addition for Torwali; Additions for Burushaski; Additions for early Persian.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Arabic Supplement block?

Unicode 18.0 has 48 assigned characters in the Arabic Supplement block, out of 48 code points reserved for it (U+0750 to U+077F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.1.
