Kannada: Unicode block U+0C80 to U+0CFF

92 characters you can look at, copy and paste. Data from Unicode 18.0.

The Kannada block covers the code points U+0C80 to U+0CFF (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 92 of them so far, which are 58 other letters, 15 spacing marks, 10 decimal digits, 8 non-spacing marks, 1 punctuation (other). Its characters were added between Unicode 1.1 and 17.0.

The characters belong to the script: Kannada.

What the block contains

The Unicode code charts divide this block into groups: Various signs; Independent vowels; Consonants; Dependent vowel signs; Virama; Ligature; Additional consonants; Additional vowels for Sanskrit; Dependent vowels; Digits; Signs used in Sanskrit.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Kannada block?

Unicode 18.0 has 92 assigned characters in the Kannada block, out of 128 code points reserved for it (U+0C80 to U+0CFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
