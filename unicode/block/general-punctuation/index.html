General Punctuation: Unicode block U+2000 to U+206F

111 characters you can look at, copy and paste. Data from Unicode 18.0.

The General Punctuation block covers the code points U+2000 to U+206F (112 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 111 of them so far, which are 48 other punctuation marks, 25 format characters, 13 spaces, 6 dashes, 5 opening quotation marks. Its characters were added between Unicode 1.1 and 6.3.

The characters belong to these scripts: Common, Inherited.

What the block contains

The Unicode code charts divide this block into groups: Spaces; Format characters; Dashes; General punctuation; Quotation marks and apostrophe; Separators; Space; Quotation marks; Double punctuation for vertical text; Brackets; Archaic punctuation; Format character; Invisible operators; Deprecated.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

103 of the 111 named characters have their own page.

Common questions

How many characters are in the General Punctuation block?

Unicode 18.0 has 111 assigned characters in the General Punctuation block, out of 112 code points reserved for it (U+2000 to U+206F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
