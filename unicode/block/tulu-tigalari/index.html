Tulu-Tigalari: Unicode block U+11380 to U+113FF

80 characters you can look at, copy and paste. Data from Unicode 18.0.

The Tulu-Tigalari block covers the code points U+11380 to U+113FF (128 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 80 of them so far, which are 53 other letters, 12 spacing marks, 11 non-spacing marks, 4 other punctuation marks. All its characters were added in Unicode 16.0.

The characters belong to the script: Tulu Tigalari.

What the block contains

The Unicode code charts divide this block into groups: Independent vowels; Consonants; Avagraha; Vowel signs; Various signs; Vowel length mark; Punctuation; Vedic tone marks.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Tulu-Tigalari block?

Unicode 18.0 has 80 assigned characters in the Tulu-Tigalari block, out of 128 code points reserved for it (U+11380 to U+113FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 16.0.
