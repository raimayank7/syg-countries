Bamum: Unicode block U+A6A0 to U+A6FF

88 characters you can look at, copy and paste. Data from Unicode 18.0.

The Bamum block covers the code points U+A6A0 to U+A6FF (96 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 88 of them so far, which are 70 other letters, 10 letter-like numbers, 6 other punctuation marks, 2 non-spacing marks. All its characters were added in Unicode 5.2.

The characters belong to the script: Bamum.

What the block contains

The Unicode code charts divide this block into groups: Syllables; Combining marks; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Bamum block?

Unicode 18.0 has 88 assigned characters in the Bamum block, out of 96 code points reserved for it (U+A6A0 to U+A6FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.2.
