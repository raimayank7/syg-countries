Kawi: Unicode block U+11F00 to U+11F5F

87 characters you can look at, copy and paste. Data from Unicode 18.0.

The Kawi block covers the code points U+11F00 to U+11F5F (96 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 87 of them so far, which are 48 other letters, 13 other punctuation marks, 10 non-spacing marks, 10 decimal digits, 6 spacing marks. Its characters were added between Unicode 15.0 and 16.0.

The characters belong to the script: Kawi.

What the block contains

The Unicode code charts divide this block into groups: Signs; Independent vowels; Consonants; Dependent vowel signs; Viramas; Punctuation; Digits; Nukta.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Kawi block?

Unicode 18.0 has 87 assigned characters in the Kawi block, out of 96 code points reserved for it (U+11F00 to U+11F5F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 15.0.
