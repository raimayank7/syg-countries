Mathematical Operators: Unicode block U+2200 to U+22FF

256 characters you can look at, copy and paste. Data from Unicode 18.0.

The Mathematical Operators block covers the code points U+2200 to U+22FF (256 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 256 of them so far, which are 256 math symbols. Its characters were added between Unicode 1.1 and 3.2.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Miscellaneous mathematical symbols; Set membership; Miscellaneous mathematical symbol; N-ary operators; Operators; Angles; Relations; Logical and set operators; Integrals; Operator; Relation; Logical operators; Matrix ellipses.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

245 of the 256 named characters have their own page.

Common questions

How many characters are in the Mathematical Operators block?

Unicode 18.0 has 256 assigned characters in the Mathematical Operators block, out of 256 code points reserved for it (U+2200 to U+22FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
