Arabic Mathematical Alphabetic Symbols: Unicode block U+1EE00 to U+1EEFF

143 characters you can look at, copy and paste. Data from Unicode 18.0.

The Arabic Mathematical Alphabetic Symbols block covers the code points U+1EE00 to U+1EEFF (256 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 143 of them so far, which are 141 other letters, 2 math symbols. All its characters were added in Unicode 6.1.

The characters belong to the script: Arabic.

What the block contains

The Unicode code charts divide this block into groups: Isolated symbols; Initial symbols; Tailed symbols; Stretched symbols; Looped symbols; Double-struck symbols; Stretching operators.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Arabic Mathematical Alphabetic Symbols block?

Unicode 18.0 has 143 assigned characters in the Arabic Mathematical Alphabetic Symbols block, out of 256 code points reserved for it (U+1EE00 to U+1EEFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 6.1.
