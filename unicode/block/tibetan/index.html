Tibetan: Unicode block U+0F00 to U+0FFF

211 characters you can look at, copy and paste. Data from Unicode 18.0.

The Tibetan block covers the code points U+0F00 to U+0FFF (256 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 211 of them so far, which are 74 non-spacing marks, 50 other letters, 36 other symbols, 24 other punctuation marks, 10 decimal digits. Its characters were added between Unicode 2.0 and 6.0.

The characters belong to these scripts: Common, Tibetan.

What the block contains

The Unicode code charts divide this block into groups: Syllable; Head marks; Marks and signs; Astrological signs; Digits; Digits minus half; Paired punctuation; Consonants; Extensions for Balti; Dependent vowel signs; Vocalic modification; Transliteration head letters; Transliteration subjoined signs; Subjoined consonants and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Tibetan block?

Unicode 18.0 has 211 assigned characters in the Tibetan block, out of 256 code points reserved for it (U+0F00 to U+0FFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 2.0.
