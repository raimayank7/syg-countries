Brahmi: Unicode block U+11000 to U+1107F

115 characters you can look at, copy and paste. Data from Unicode 18.0.

The Brahmi block covers the code points U+11000 to U+1107F (128 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 115 of them so far, which are 56 other letters, 20 non-spacing marks, 20 other numbers, 10 decimal digits, 7 other punctuation marks. Its characters were added between Unicode 6.0 and 14.0.

The characters belong to the script: Brahmi.

What the block contains

The Unicode code charts divide this block into groups: Various signs; Independent vowels; Consonants; Dependent vowel signs; Virama; Punctuation; Numbers; Digits; Consonant; Number joiner.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Brahmi block?

Unicode 18.0 has 115 assigned characters in the Brahmi block, out of 128 code points reserved for it (U+11000 to U+1107F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 6.0.
