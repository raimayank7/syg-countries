Arabic Extended-A: Unicode block U+08A0 to U+08FF

96 characters you can look at, copy and paste. Data from Unicode 18.0.

The Arabic Extended-A block covers the code points U+08A0 to U+08FF (96 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 96 of them so far, which are 53 non-spacing marks, 41 other letters, 1 modifier letter, 1 format character. Its characters were added between Unicode 6.1 and 14.0.

The characters belong to these scripts: Arabic, Common.

What the block contains

The Unicode code charts divide this block into groups: Arabic letters for African languages; Dependent consonants for Rohingya; Arabic letters for European and Central Asian languages; Arabic letter for Berber; Arabic letters for Arwi; Early Arabic letter; Arabic letters for Bravanese; Arabic letters for Warsh orthography; Arabic letters for Hindko; Arabic letters for Hausa, Wolof and other African orthographies; Arabic letter for Punjabi; Arabic letter for Balti; Additions for Quranic orthographies; Quranic annotation signs and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Arabic Extended-A block?

Unicode 18.0 has 96 assigned characters in the Arabic Extended-A block, out of 96 code points reserved for it (U+08A0 to U+08FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 6.1.
