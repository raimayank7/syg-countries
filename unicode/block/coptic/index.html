Coptic: Unicode block U+2C80 to U+2CFF

123 characters you can look at, copy and paste. Data from Unicode 18.0.

The Coptic block covers the code points U+2C80 to U+2CFF (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 123 of them so far, which are 54 lowercase letters, 53 uppercase letters, 6 other symbols, 6 other punctuation marks, 3 non-spacing marks. Its characters were added between Unicode 4.1 and 6.1.

The characters belong to the script: Coptic.

What the block contains

The Unicode code charts divide this block into groups: Bohairic Coptic letters; Old Coptic and dialect letters; Old Nubian letters; Symbols; Cryptogrammic letters; Combining marks; Old Nubian punctuation; Numeric character; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Coptic block?

Unicode 18.0 has 123 assigned characters in the Coptic block, out of 128 code points reserved for it (U+2C80 to U+2CFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.1.
