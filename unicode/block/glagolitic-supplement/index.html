Glagolitic Supplement: Unicode block U+1E000 to U+1E02F

38 characters you can look at, copy and paste. Data from Unicode 18.0.

The Glagolitic Supplement block covers the code points U+1E000 to U+1E02F (48 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 38 of them so far, which are 38 non-spacing marks. All its characters were added in Unicode 9.0.

The characters belong to the script: Glagolitic.

What the block contains

The Unicode code charts divide this block into groups: Combining letters.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Glagolitic Supplement block?

Unicode 18.0 has 38 assigned characters in the Glagolitic Supplement block, out of 48 code points reserved for it (U+1E000 to U+1E02F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 9.0.
