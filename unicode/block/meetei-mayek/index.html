Meetei Mayek: Unicode block U+ABC0 to U+ABFF

56 characters you can look at, copy and paste. Data from Unicode 18.0.

The Meetei Mayek block covers the code points U+ABC0 to U+ABFF (64 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 56 of them so far, which are 35 other letters, 10 decimal digits, 7 spacing marks, 3 non-spacing marks, 1 punctuation (other). All its characters were added in Unicode 5.2.

The characters belong to the script: Meetei Mayek.

What the block contains

The Unicode code charts divide this block into groups: Letters; Final consonants; Dependent vowel signs; Punctuation; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Meetei Mayek block?

Unicode 18.0 has 56 assigned characters in the Meetei Mayek block, out of 64 code points reserved for it (U+ABC0 to U+ABFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.2.
