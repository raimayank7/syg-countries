Byzantine Musical Symbols: Unicode block U+1D000 to U+1D0FF

246 characters you can look at, copy and paste. Data from Unicode 18.0.

The Byzantine Musical Symbols block covers the code points U+1D000 to U+1D0FF (256 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 246 of them so far, which are 246 other symbols. All its characters were added in Unicode 3.1.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Prosodies (Prosodics); Ekfonetika; Melodimata (Melodics); Fonitika (Vocals); Afona or Ypostaseis (Mutes or Hypostases); Argies (Retards); Leimmata or Siopes (Leimmas or Silencers); Synagmata or Gorgotites (Synagmas or Quickeners); Agogika (Conduits); Ichimata and Martyrika (Ichimas and Evidentials); Fthores (Destroyers); Alloioseis (Differentiators); Rythmika (Rhythmics); Grammata (Letters) and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Byzantine Musical Symbols block?

Unicode 18.0 has 246 assigned characters in the Byzantine Musical Symbols block, out of 256 code points reserved for it (U+1D000 to U+1D0FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.
