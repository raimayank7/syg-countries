Old Turkic: Unicode block U+10C00 to U+10C4F

73 characters you can look at, copy and paste. Data from Unicode 18.0.

The Old Turkic block covers the code points U+10C00 to U+10C4F (80 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 73 of them so far, which are 73 other letters. All its characters were added in Unicode 5.2.

The characters belong to the script: Old Turkic.

What the block contains

The Unicode code charts divide this block into groups: Vowels; Consonants.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Old Turkic block?

Unicode 18.0 has 73 assigned characters in the Old Turkic block, out of 80 code points reserved for it (U+10C00 to U+10C4F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.2.
