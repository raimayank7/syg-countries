Tamil Supplement: Unicode block U+11FC0 to U+11FFF

51 characters you can look at, copy and paste. Data from Unicode 18.0.

The Tamil Supplement block covers the code points U+11FC0 to U+11FFF (64 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 51 of them so far, which are 25 other symbols, 21 other numbers, 4 currency symbols, 1 punctuation (other). All its characters were added in Unicode 12.0.

The characters belong to the script: Tamil.

What the block contains

The Unicode code charts divide this block into groups: Fractions; Measures of grain; Old currency symbols; Symbols of weight, length, and area; Agricultural symbols; Clerical symbols; Other symbols and abbreviations; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Tamil Supplement block?

Unicode 18.0 has 51 assigned characters in the Tamil Supplement block, out of 64 code points reserved for it (U+11FC0 to U+11FFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 12.0.
