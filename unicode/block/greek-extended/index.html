Greek Extended: Unicode block U+1F00 to U+1FFF

233 characters you can look at, copy and paste. Data from Unicode 18.0.

The Greek Extended block covers the code points U+1F00 to U+1FFF (256 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 233 of them so far, which are 122 lowercase letters, 69 uppercase letters, 27 titlecase letters, 15 modifier symbols. All its characters were added in Unicode 1.1.

The characters belong to the script: Greek.

What the block contains

The Unicode code charts divide this block into groups: Precomposed polytonic Greek.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Greek Extended block?

Unicode 18.0 has 233 assigned characters in the Greek Extended block, out of 256 code points reserved for it (U+1F00 to U+1FFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
