Egyptian Hieroglyph Format Controls: Unicode block U+13430 to U+1345F

38 characters you can look at, copy and paste. Data from Unicode 18.0.

The Egyptian Hieroglyph Format Controls block covers the code points U+13430 to U+1345F (48 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 38 of them so far, which are 16 format characters, 16 non-spacing marks, 6 other letters. Its characters were added between Unicode 12.0 and 15.0.

The characters belong to the script: Egyptian Hieroglyphs.

What the block contains

The Unicode code charts divide this block into groups: Joiners; Sign insertion controls; Sign stacking control; Segment scoping delimiters; Enclosure controls; Mirror control; Blank and lost signs; Damage modifiers.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Egyptian Hieroglyph Format Controls block?

Unicode 18.0 has 38 assigned characters in the Egyptian Hieroglyph Format Controls block, out of 48 code points reserved for it (U+13430 to U+1345F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 12.0.
