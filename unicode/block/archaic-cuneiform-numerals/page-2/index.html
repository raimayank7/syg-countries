Archaic Cuneiform Numerals: Unicode block U+12550 to U+1268F

311 characters you can look at, copy and paste. Data from Unicode 18.0.

The Archaic Cuneiform Numerals block covers the code points U+12550 to U+1268F (320 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 311 of them so far, which are 311 letter-like numbers. All its characters were added in Unicode 18.0.

Common questions

How many characters are in the Archaic Cuneiform Numerals block?

Unicode 18.0 has 311 assigned characters in the Archaic Cuneiform Numerals block, out of 320 code points reserved for it (U+12550 to U+1268F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 18.0.
