Combining Diacritical Marks Extended: Unicode block U+1AB0 to U+1AFF

65 characters you can look at, copy and paste. Data from Unicode 18.0.

The Combining Diacritical Marks Extended block covers the code points U+1AB0 to U+1AFF (80 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 65 of them so far, which are 64 non-spacing marks, 1 enclosing mark. Its characters were added between Unicode 7.0 and 18.0.

The characters belong to the script: Inherited.

What the block contains

The Unicode code charts divide this block into groups: Used in German dialectology; Marks surrounding other diacritics or letters; Used in Scots dialectology; Marks next to or surrounding other diacritics; Phonetic sign; Used in extended IPA; Used in Middle English Ormulum; Compound tone diacritics; J.P. Harrington diacritics; Intermediate tone diacritics; IPA positional variants; Historical IPA; Extended IPA positional variants.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Combining Diacritical Marks Extended block?

Unicode 18.0 has 65 assigned characters in the Combining Diacritical Marks Extended block, out of 80 code points reserved for it (U+1AB0 to U+1AFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
