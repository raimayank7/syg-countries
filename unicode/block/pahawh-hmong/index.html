Pahawh Hmong: Unicode block U+16B00 to U+16B8F

127 characters you can look at, copy and paste. Data from Unicode 18.0.

The Pahawh Hmong block covers the code points U+16B00 to U+16B8F (144 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 127 of them so far, which are 88 other letters, 10 decimal digits, 7 non-spacing marks, 7 other numbers, 6 other punctuation marks. All its characters were added in Unicode 7.0.

The characters belong to the script: Pahawh Hmong.

What the block contains

The Unicode code charts divide this block into groups: Vowel rimes; Consonant onsets; Combining diacritical marks; Punctuation; Mathematical operators; Modifier letters; Digits; Numbers; Logographs; Logographs for clan names.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.
