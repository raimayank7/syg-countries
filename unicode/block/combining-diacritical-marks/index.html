Combining Diacritical Marks: Unicode block U+0300 to U+036F

112 characters you can look at, copy and paste. Data from Unicode 18.0.

The Combining Diacritical Marks block covers the code points U+0300 to U+036F (112 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 112 of them so far, which are 112 non-spacing marks. Its characters were added between Unicode 1.1 and 4.1.

The characters belong to the script: Inherited.

What the block contains

The Unicode code charts divide this block into groups: Ordinary diacritics; Overstruck diacritics; Miscellaneous additions; Vietnamese tone marks; Additions for Greek; Additions for IPA; IPA diacritics for disordered speech; Miscellaneous addition; Additions for the Uralic Phonetic Alphabet; Double diacritics; Medieval superscript letter diacritics.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

89 of the 112 named characters have their own page.

Common questions

How many characters are in the Combining Diacritical Marks block?

Unicode 18.0 has 112 assigned characters in the Combining Diacritical Marks block, out of 112 code points reserved for it (U+0300 to U+036F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
