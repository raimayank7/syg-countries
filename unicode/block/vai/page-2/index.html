Vai: Unicode block U+A500 to U+A63F

300 characters you can look at, copy and paste. Data from Unicode 18.0.

The Vai block covers the code points U+A500 to U+A63F (320 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 300 of them so far, which are 286 other letters, 10 decimal digits, 3 other punctuation marks, 1 modifier letter. All its characters were added in Unicode 5.1.

Common questions

How many characters are in the Vai block?

Unicode 18.0 has 300 assigned characters in the Vai block, out of 320 code points reserved for it (U+A500 to U+A63F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.1.
