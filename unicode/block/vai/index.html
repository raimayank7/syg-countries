Vai: Unicode block U+A500 to U+A63F

300 characters you can look at, copy and paste. Data from Unicode 18.0.

The Vai block covers the code points U+A500 to U+A63F (320 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 300 of them so far, which are 286 other letters, 10 decimal digits, 3 other punctuation marks, 1 modifier letter. All its characters were added in Unicode 5.1.

The characters belong to the script: Vai.

What the block contains

The Unicode code charts divide this block into groups: Syllables in -ee; Syllables in -i; Syllables in -a; Syllables in -oo; Syllables in -u; Syllables in -o; Syllables in -e; Syllable finals; Punctuation; Historic syllables; Logograms; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.
