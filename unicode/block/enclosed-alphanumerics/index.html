Enclosed Alphanumerics: Unicode block U+2460 to U+24FF

160 characters you can look at, copy and paste. Data from Unicode 18.0.

The Enclosed Alphanumerics block covers the code points U+2460 to U+24FF (160 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 160 of them so far, which are 82 other numbers, 78 other symbols. Its characters were added between Unicode 1.1 and 4.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Circled numbers; Parenthesized numbers; Numbers period; Parenthesized Latin letters; Circled Latin letters; Additional circled number; White on black circled numbers; Double circled numbers; Additional white on black circled number.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Enclosed Alphanumerics block?

Unicode 18.0 has 160 assigned characters in the Enclosed Alphanumerics block, out of 160 code points reserved for it (U+2460 to U+24FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
