Phags-pa: Unicode block U+A840 to U+A87F

56 characters you can look at, copy and paste. Data from Unicode 18.0.

The Phags-pa block covers the code points U+A840 to U+A87F (64 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 56 of them so far, which are 52 other letters, 4 other punctuation marks. All its characters were added in Unicode 5.0.

The characters belong to the script: Phags Pa.

What the block contains

The Unicode code charts divide this block into groups: Consonants; Letter A; Vowels; Vowel; Subjoined consonants; Consonant additions for Sanskrit; Alternate consonant forms for Chinese; Subjoined consonant; Consonant addition for Tibetan; Candrabindu; Head marks for Tibetan; Punctuation for Tibetan.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Phags-pa block?

Unicode 18.0 has 56 assigned characters in the Phags-pa block, out of 64 code points reserved for it (U+A840 to U+A87F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.0.
