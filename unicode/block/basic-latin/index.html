Basic Latin: Unicode block U+0000 to U+007F

128 characters you can look at, copy and paste. Data from Unicode 18.0.

The Basic Latin block covers the code points U+0000 to U+007F (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 128 of them so far, which are 33 control characters, 26 uppercase letters, 26 lowercase letters, 15 other punctuation marks, 10 decimal digits. All its characters were added in Unicode 1.1.

The characters belong to these scripts: Common, Latin.

What the block contains

The Unicode code charts divide this block into groups: C0 controls; ASCII punctuation and symbols; ASCII math operator; ASCII punctuation; ASCII digits; ASCII mathematical operators; Uppercase Latin alphabet; Lowercase Latin alphabet; Control character.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Basic Latin block?

Unicode 18.0 has 128 assigned characters in the Basic Latin block, out of 128 code points reserved for it (U+0000 to U+007F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
