Phaistos Disc: Unicode block U+101D0 to U+101FF

46 characters you can look at, copy and paste. Data from Unicode 18.0.

The Phaistos Disc block covers the code points U+101D0 to U+101FF (48 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 46 of them so far, which are 45 other symbols, 1 non-spacing mark. All its characters were added in Unicode 5.1.

The characters belong to these scripts: Common, Inherited.

What the block contains

The Unicode code charts divide this block into groups: Signs; Combining stroke.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Phaistos Disc block?

Unicode 18.0 has 46 assigned characters in the Phaistos Disc block, out of 48 code points reserved for it (U+101D0 to U+101FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.1.
