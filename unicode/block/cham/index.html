Cham: Unicode block U+AA00 to U+AA5F

83 characters you can look at, copy and paste. Data from Unicode 18.0.

The Cham block covers the code points U+AA00 to U+AA5F (96 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 83 of them so far, which are 52 other letters, 12 non-spacing marks, 10 decimal digits, 5 spacing marks, 4 other punctuation marks. All its characters were added in Unicode 5.1.

The characters belong to the script: Cham.

What the block contains

The Unicode code charts divide this block into groups: Independent vowels; Consonants; Dependent vowel signs; Consonant signs; Final consonants; Digits; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Cham block?

Unicode 18.0 has 83 assigned characters in the Cham block, out of 96 code points reserved for it (U+AA00 to U+AA5F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.1.
