Nabataean: Unicode block U+10880 to U+108AF

40 characters you can look at, copy and paste. Data from Unicode 18.0.

The Nabataean block covers the code points U+10880 to U+108AF (48 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 40 of them so far, which are 31 other letters, 9 other numbers. All its characters were added in Unicode 7.0.

The characters belong to the script: Nabataean.

What the block contains

The Unicode code charts divide this block into groups: Letters; Numbers.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Nabataean block?

Unicode 18.0 has 40 assigned characters in the Nabataean block, out of 48 code points reserved for it (U+10880 to U+108AF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
