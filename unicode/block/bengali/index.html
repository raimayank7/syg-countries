Bengali: Unicode block U+0980 to U+09FF

96 characters you can look at, copy and paste. Data from Unicode 18.0.

The Bengali block covers the code points U+0980 to U+09FF (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 96 of them so far, which are 55 other letters, 10 non-spacing marks, 10 spacing marks, 10 decimal digits, 6 other numbers. Its characters were added between Unicode 1.1 and 11.0.

The characters belong to the script: Bengali.

What the block contains

The Unicode code charts divide this block into groups: Various signs; Independent vowels; Consonants; Dependent vowel signs; Two-part dependent vowel signs; Virama; Additional consonant; Sign; Additional consonants; Additional vowels for Sanskrit; Digits; Additions for Assamese; Currency symbols; Historic symbols for fractional values and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Bengali block?

Unicode 18.0 has 96 assigned characters in the Bengali block, out of 128 code points reserved for it (U+0980 to U+09FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
