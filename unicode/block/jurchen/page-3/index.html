Jurchen: Unicode block U+18E00 to U+1919F

914 characters you can look at, copy and paste. Data from Unicode 18.0.

The Jurchen block covers the code points U+18E00 to U+1919F (928 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 914 of them so far, which are 914 other letters. All its characters were added in Unicode 18.0.

Common questions

How many characters are in the Jurchen block?

Unicode 18.0 has 914 assigned characters in the Jurchen block, out of 928 code points reserved for it (U+18E00 to U+1919F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 18.0.
