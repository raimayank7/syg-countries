Zanabazar Square: Unicode block U+11A00 to U+11A4F

72 characters you can look at, copy and paste. Data from Unicode 18.0.

The Zanabazar Square block covers the code points U+11A00 to U+11A4F (80 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 72 of them so far, which are 42 other letters, 21 non-spacing marks, 8 other punctuation marks, 1 spacing mark. All its characters were added in Unicode 10.0.

The characters belong to the script: Zanabazar Square.

What the block contains

The Unicode code charts divide this block into groups: Vowel letter; Vowel signs; Vowel length mark; Consonants; Final consonant mark; Virama; Candrabindu and candra ornaments; Signs for Sanskrit; Cluster-initial consonant; Cluster-final consonants; Head marks; Punctuation; Subjoiner.

Common questions

How many characters are in the Zanabazar Square block?

Unicode 18.0 has 72 assigned characters in the Zanabazar Square block, out of 80 code points reserved for it (U+11A00 to U+11A4F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 10.0.
