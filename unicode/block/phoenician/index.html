Phoenician: Unicode block U+10900 to U+1091F

29 characters you can look at, copy and paste. Data from Unicode 18.0.

The Phoenician block covers the code points U+10900 to U+1091F (32 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 29 of them so far, which are 22 other letters, 6 other numbers, 1 punctuation (other). Its characters were added between Unicode 5.0 and 5.2.

The characters belong to the script: Phoenician.

What the block contains

The Unicode code charts divide this block into groups: Letters; Numbers; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Phoenician block?

Unicode 18.0 has 29 assigned characters in the Phoenician block, out of 32 code points reserved for it (U+10900 to U+1091F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.0.
