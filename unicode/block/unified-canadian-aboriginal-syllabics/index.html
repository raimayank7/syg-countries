Unified Canadian Aboriginal Syllabics: Unicode block U+1400 to U+167F

640 characters you can look at, copy and paste. Data from Unicode 18.0.

The Unified Canadian Aboriginal Syllabics block covers the code points U+1400 to U+167F (640 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 640 of them so far, which are 637 other letters, 1 dash, 1 symbol (other), 1 punctuation (other). Its characters were added between Unicode 3.0 and 5.2.

The characters belong to the script: Canadian Aboriginal.

What the block contains

The Unicode code charts divide this block into groups: Punctuation; Syllables; Syllables for Carrier; Symbol.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Unified Canadian Aboriginal Syllabics block?

Unicode 18.0 has 640 assigned characters in the Unified Canadian Aboriginal Syllabics block, out of 640 code points reserved for it (U+1400 to U+167F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?
