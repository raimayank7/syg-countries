Bassa Vah: Unicode block U+16AD0 to U+16AFF

36 characters you can look at, copy and paste. Data from Unicode 18.0.

The Bassa Vah block covers the code points U+16AD0 to U+16AFF (48 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 36 of them so far, which are 30 other letters, 5 non-spacing marks, 1 punctuation (other). All its characters were added in Unicode 7.0.

The characters belong to the script: Bassa Vah.

What the block contains

The Unicode code charts divide this block into groups: Consonant letters; Vowel letters; Combining tone marks; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Bassa Vah block?

Unicode 18.0 has 36 assigned characters in the Bassa Vah block, out of 48 code points reserved for it (U+16AD0 to U+16AFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
