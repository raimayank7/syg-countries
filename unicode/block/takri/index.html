Takri: Unicode block U+11680 to U+116CF

68 characters you can look at, copy and paste. Data from Unicode 18.0.

The Takri block covers the code points U+11680 to U+116CF (80 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 68 of them so far, which are 44 other letters, 10 decimal digits, 9 non-spacing marks, 4 spacing marks, 1 punctuation (other). Its characters were added between Unicode 6.1 and 14.0.

The characters belong to the script: Takri.

What the block contains

The Unicode code charts divide this block into groups: Independent vowels; Consonants; Various signs; Dependent vowel signs; Virama; Nukta; Consonant; Punctuation; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Takri block?

Unicode 18.0 has 68 assigned characters in the Takri block, out of 80 code points reserved for it (U+11680 to U+116CF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 6.1.
