CJK Unified Ideographs Extension H: Unicode block U+31350 to U+323AF

4,192 characters you can look at, copy and paste. Data from Unicode 18.0.

The CJK Unified Ideographs Extension H block covers the code points U+31350 to U+323AF (4,192 positions) in the Tertiary Ideographic Plane (plane 3). Unicode has assigned 4,192 of them so far, which are 4,192 other letters. All its characters were added in Unicode 15.0.

Common questions

How many characters are in the CJK Unified Ideographs Extension H block?

Unicode 18.0 has 4,192 assigned characters in the CJK Unified Ideographs Extension H block, out of 4,192 code points reserved for it (U+31350 to U+323AF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 15.0.
