Yi Syllables: Unicode block U+A000 to U+A48F

1,165 characters you can look at, copy and paste. Data from Unicode 18.0.

The Yi Syllables block covers the code points U+A000 to U+A48F (1,168 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 1,165 of them so far, which are 1,164 other letters, 1 modifier letter. All its characters were added in Unicode 3.0.

The characters belong to the script: Yi.

What the block contains

The Unicode code charts divide this block into groups: Syllables; Syllable iteration mark.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Yi Syllables block?

Unicode 18.0 has 1,165 assigned characters in the Yi Syllables block, out of 1,168 code points reserved for it (U+A000 to U+A48F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?
