CJK Unified Ideographs Extension A: Unicode block U+3400 to U+4DBF

6,592 characters you can look at, copy and paste. Data from Unicode 18.0.

The CJK Unified Ideographs Extension A block covers the code points U+3400 to U+4DBF (6,592 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 6,592 of them so far, which are 6,592 other letters. All its characters were added in Unicode 3.0.

Characters in this block are not given individual names in the standard: each is named by its code point, for example "CJK Ideograph Extension A-3400". The table lists them in code order, 256 to a page. Only the first 1,024 are listed on this site; the other 5,568 characters of the block are not shown, because a page of thousands of look-alike entries helps nobody.

Common questions

How many characters are in the CJK Unified Ideographs Extension A block?

Unicode 18.0 has 6,592 assigned characters in the CJK Unified Ideographs Extension A block, out of 6,592 code points reserved for it (U+3400 to U+4DBF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.0.
