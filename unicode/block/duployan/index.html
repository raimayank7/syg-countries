Duployan: Unicode block U+1BC00 to U+1BC9F

143 characters you can look at, copy and paste. Data from Unicode 18.0.

The Duployan block covers the code points U+1BC00 to U+1BC9F (160 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 143 of them so far, which are 139 other letters, 2 non-spacing marks, 1 symbol (other), 1 punctuation (other). All its characters were added in Unicode 7.0.

The characters belong to the script: Duployan.

What the block contains

The Unicode code charts divide this block into groups: Non-joining consonants; Line consonants; Arc consonants; Quarter-arc consonants written downwards; Quarter-arc consonants written upwards; Circle vowels; Semi-circle vowels; Diagonal-line vowels; Quarter-circle vowels; Other vowels; Dotted-circle vowels; Compound vowels; Basic nasal vowels; Additional nasal vowels and more.
