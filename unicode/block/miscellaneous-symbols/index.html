Miscellaneous Symbols: Unicode block U+2600 to U+26FF

256 characters you can look at, copy and paste. Data from Unicode 18.0.

The Miscellaneous Symbols block covers the code points U+2600 to U+26FF (256 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 256 of them so far, which are 255 other symbols, 1 math symbol. Its characters were added between Unicode 1.1 and 6.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Weather and astrological symbols; Miscellaneous symbols; Weather symbol; Miscellaneous symbol; Japanese chess symbols; Pointing hand symbols; Warning signs; Medical and healing symbols; Religious and political symbols; Yijing trigram symbols; Emoticons; Astrological symbols; Zodiacal symbols; Chess symbols and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Miscellaneous Symbols block?

Unicode 18.0 has 256 assigned characters in the Miscellaneous Symbols block, out of 256 code points reserved for it (U+2600 to U+26FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
