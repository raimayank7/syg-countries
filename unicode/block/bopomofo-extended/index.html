Bopomofo Extended: Unicode block U+31A0 to U+31BF

32 characters you can look at, copy and paste. Data from Unicode 18.0.

The Bopomofo Extended block covers the code points U+31A0 to U+31BF (32 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 32 of them so far, which are 32 other letters. Its characters were added between Unicode 3.0 and 13.0.

The characters belong to the script: Bopomofo.

What the block contains

The Unicode code charts divide this block into groups: Extended Bopomofo for Minnan and Hakka; Extended Bopomofo for Hmu and Ge; Extended Bopomofo for Cantonese.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Bopomofo Extended block?

Unicode 18.0 has 32 assigned characters in the Bopomofo Extended block, out of 32 code points reserved for it (U+31A0 to U+31BF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.0.
