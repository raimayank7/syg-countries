Tangut: Unicode block U+17000 to U+187FF

6,144 characters you can look at, copy and paste. Data from Unicode 18.0.

The Tangut block covers the code points U+17000 to U+187FF (6,144 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 6,144 of them so far, which are 6,144 other letters. All its characters were added in Unicode 9.0.

Common questions

How many characters are in the Tangut block?

Unicode 18.0 has 6,144 assigned characters in the Tangut block, out of 6,144 code points reserved for it (U+17000 to U+187FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 9.0.
