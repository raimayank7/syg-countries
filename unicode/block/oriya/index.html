Oriya: Unicode block U+0B00 to U+0B7F

93 characters you can look at, copy and paste. Data from Unicode 18.0.

The Oriya block covers the code points U+0B00 to U+0B7F (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 93 of them so far, which are 53 other letters, 14 non-spacing marks, 10 decimal digits, 9 spacing marks, 6 other numbers. Its characters were added between Unicode 1.1 and 18.0.

The characters belong to the script: Oriya.

What the block contains

The Unicode code charts divide this block into groups: Various signs; Independent vowels; Consonants; Dependent vowel signs; Two-part dependent vowel signs; Virama; Additional consonants; Additional vowels for Sanskrit; Dependent vowels; Digits; Sign; Additional consonant; Fraction signs.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Oriya block?

Unicode 18.0 has 93 assigned characters in the Oriya block, out of 128 code points reserved for it (U+0B00 to U+0B7F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
