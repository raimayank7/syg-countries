Ethiopic Extended: Unicode block U+2D80 to U+2DDF

79 characters you can look at, copy and paste. Data from Unicode 18.0.

The Ethiopic Extended block covers the code points U+2D80 to U+2DDF (96 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 79 of them so far, which are 79 other letters. All its characters were added in Unicode 4.1.

The characters belong to the script: Ethiopic.

What the block contains

The Unicode code charts divide this block into groups: Syllables for Me'en; Syllables for Blin; Syllables for Bench; Syllables for Gurage.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Ethiopic Extended block?

Unicode 18.0 has 79 assigned characters in the Ethiopic Extended block, out of 96 code points reserved for it (U+2D80 to U+2DDF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.1.
