Georgian Extended: Unicode block U+1C90 to U+1CBF

46 characters you can look at, copy and paste. Data from Unicode 18.0.

The Georgian Extended block covers the code points U+1C90 to U+1CBF (48 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 46 of them so far, which are 46 uppercase letters. All its characters were added in Unicode 11.0.

The characters belong to the script: Georgian.

What the block contains

The Unicode code charts divide this block into groups: Capital letters (Mtavruli); Archaic letters; Additional letters for Mingrelian and Svan; Additional letters; Additional letters for Ossetian and Abkhaz.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Georgian Extended block?

Unicode 18.0 has 46 assigned characters in the Georgian Extended block, out of 48 code points reserved for it (U+1C90 to U+1CBF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 11.0.
