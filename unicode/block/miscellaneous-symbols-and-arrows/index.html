Miscellaneous Symbols and Arrows: Unicode block U+2B00 to U+2BFF

254 characters you can look at, copy and paste. Data from Unicode 18.0.

The Miscellaneous Symbols and Arrows block covers the code points U+2B00 to U+2BFF (256 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 254 of them so far, which are 227 other symbols, 27 math symbols. Its characters were added between Unicode 4.0 and 17.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: White and black arrows; Arrows with bent tips; Squares; Diamonds; Pentagons; Hexagons; Circle; Diamonds and lozenges; Ellipses; Mathematical arrows; Miscellaneous arrow; Intonation marks for Lithuanian dialectology; Stars; Traffic sign from ARIB STD B24 and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

146 of the 254 named characters have their own page.

Common questions

How many characters are in the Miscellaneous Symbols and Arrows block?

Unicode 18.0 has 254 assigned characters in the Miscellaneous Symbols and Arrows block, out of 256 code points reserved for it (U+2B00 to U+2BFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.0.
