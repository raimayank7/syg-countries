Syriac Supplement: Unicode block U+0860 to U+086F

11 characters you can look at, copy and paste. Data from Unicode 18.0.

The Syriac Supplement block covers the code points U+0860 to U+086F (16 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 11 of them so far, which are 11 other letters. All its characters were added in Unicode 10.0.

The characters belong to the script: Syriac.

What the block contains

The Unicode code charts divide this block into groups: Syriac letters.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Syriac Supplement block?

Unicode 18.0 has 11 assigned characters in the Syriac Supplement block, out of 16 code points reserved for it (U+0860 to U+086F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 10.0.
