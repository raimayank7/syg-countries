Alphabetic Presentation Forms: Unicode block U+FB00 to U+FB4F

58 characters you can look at, copy and paste. Data from Unicode 18.0.

The Alphabetic Presentation Forms block covers the code points U+FB00 to U+FB4F (80 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 58 of them so far, which are 44 other letters, 12 lowercase letters, 1 non-spacing mark, 1 math symbol. Its characters were added between Unicode 1.1 and 3.0.

The characters belong to these scripts: Armenian, Hebrew, Latin.

What the block contains

The Unicode code charts divide this block into groups: Latin ligatures; Armenian ligatures; Hebrew presentation forms.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Alphabetic Presentation Forms block?

Unicode 18.0 has 58 assigned characters in the Alphabetic Presentation Forms block, out of 80 code points reserved for it (U+FB00 to U+FB4F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
