Letterlike Symbols: Unicode block U+2100 to U+214F

80 characters you can look at, copy and paste. Data from Unicode 18.0.

The Letterlike Symbols block covers the code points U+2100 to U+214F (80 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 80 of them so far, which are 28 uppercase letters, 27 other symbols, 14 lowercase letters, 7 math symbols, 4 other letters. Its characters were added between Unicode 1.1 and 5.1.

The characters belong to these scripts: Common, Greek, Latin.

What the block contains

The Unicode code charts divide this block into groups: Letterlike symbols; Hebrew letterlike math symbols; Additional letterlike symbols; Double-struck large operator; Double-struck italic math symbols; Lowercase Claudian letter; Biblical editorial symbol.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

75 of the 80 named characters have their own page.

Common questions

How many characters are in the Letterlike Symbols block?

Unicode 18.0 has 80 assigned characters in the Letterlike Symbols block, out of 80 code points reserved for it (U+2100 to U+214F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
