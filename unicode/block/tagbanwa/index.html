Tagbanwa: Unicode block U+1760 to U+177F

18 characters you can look at, copy and paste. Data from Unicode 18.0.

The Tagbanwa block covers the code points U+1760 to U+177F (32 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 18 of them so far, which are 16 other letters, 2 non-spacing marks. All its characters were added in Unicode 3.2.

The characters belong to the script: Tagbanwa.

What the block contains

The Unicode code charts divide this block into groups: Independent vowels; Consonants; Dependent vowel signs.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Tagbanwa block?

Unicode 18.0 has 18 assigned characters in the Tagbanwa block, out of 32 code points reserved for it (U+1760 to U+177F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.2.
