Syriac: Unicode block U+0700 to U+074F

77 characters you can look at, copy and paste. Data from Unicode 18.0.

The Syriac block covers the code points U+0700 to U+074F (80 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 77 of them so far, which are 34 other letters, 28 non-spacing marks, 14 other punctuation marks, 1 format character. Its characters were added between Unicode 3.0 and 4.0.

The characters belong to the script: Syriac.

What the block contains

The Unicode code charts divide this block into groups: Syriac punctuation and signs; Syriac format control character; Syriac letters; Persian letters; Syriac points (vowels); Syriac marks; Sogdian letters.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Syriac block?

Unicode 18.0 has 77 assigned characters in the Syriac block, out of 80 code points reserved for it (U+0700 to U+074F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.0.
