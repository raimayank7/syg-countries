Sinhala: Unicode block U+0D80 to U+0DFF

91 characters you can look at, copy and paste. Data from Unicode 18.0.

The Sinhala block covers the code points U+0D80 to U+0DFF (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 91 of them so far, which are 59 other letters, 15 spacing marks, 10 decimal digits, 6 non-spacing marks, 1 punctuation (other). Its characters were added between Unicode 3.0 and 13.0.

The characters belong to the script: Sinhala.

What the block contains

The Unicode code charts divide this block into groups: Various signs; Independent vowels; Consonants; Sign; Dependent vowel signs; Two-part dependent vowel signs; Dependent vowel sign; Astrological digits; Additional dependent vowel signs; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Sinhala block?

Unicode 18.0 has 91 assigned characters in the Sinhala block, out of 128 code points reserved for it (U+0D80 to U+0DFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.0.
