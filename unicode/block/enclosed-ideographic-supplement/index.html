Enclosed Ideographic Supplement: Unicode block U+1F200 to U+1F2FF

64 characters you can look at, copy and paste. Data from Unicode 18.0.

The Enclosed Ideographic Supplement block covers the code points U+1F200 to U+1F2FF (256 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 64 of them so far, which are 64 other symbols. Its characters were added between Unicode 5.2 and 10.0.

The characters belong to these scripts: Common, Hiragana.

What the block contains

The Unicode code charts divide this block into groups: Squared hiragana from ARIB STD B24; Squared katakana; Squared ideographs and kana from ARIB STD B24; Squared ideographs; Ideographs with tortoise shell brackets from ARIB STD B24; Circled ideographs; Symbols for Chinese folk religion.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Enclosed Ideographic Supplement block?

Unicode 18.0 has 64 assigned characters in the Enclosed Ideographic Supplement block, out of 256 code points reserved for it (U+1F200 to U+1F2FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.2.
