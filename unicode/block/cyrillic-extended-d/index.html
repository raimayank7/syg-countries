Cyrillic Extended-D: Unicode block U+1E030 to U+1E08F

63 characters you can look at, copy and paste. Data from Unicode 18.0.

The Cyrillic Extended-D block covers the code points U+1E030 to U+1E08F (96 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 63 of them so far, which are 62 modifier letters, 1 non-spacing mark. All its characters were added in Unicode 15.0.

The characters belong to the script: Cyrillic.

What the block contains

The Unicode code charts divide this block into groups: Superscript modifier letters; Subscript modifier letters; Diacritical mark.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Cyrillic Extended-D block?

Unicode 18.0 has 63 assigned characters in the Cyrillic Extended-D block, out of 96 code points reserved for it (U+1E030 to U+1E08F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 15.0.
