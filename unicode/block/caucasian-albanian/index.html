Caucasian Albanian: Unicode block U+10530 to U+1056F

53 characters you can look at, copy and paste. Data from Unicode 18.0.

The Caucasian Albanian block covers the code points U+10530 to U+1056F (64 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 53 of them so far, which are 52 other letters, 1 punctuation (other). All its characters were added in Unicode 7.0.

The characters belong to the script: Caucasian Albanian.

What the block contains

The Unicode code charts divide this block into groups: Letters; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Caucasian Albanian block?

Unicode 18.0 has 53 assigned characters in the Caucasian Albanian block, out of 64 code points reserved for it (U+10530 to U+1056F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
