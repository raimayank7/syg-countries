CJK Compatibility Ideographs: Unicode block U+F900 to U+FAFF

472 characters you can look at, copy and paste. Data from Unicode 18.0.

The CJK Compatibility Ideographs block covers the code points U+F900 to U+FAFF (512 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 472 of them so far, which are 472 other letters. Its characters were added between Unicode 1.1 and 6.1.

The characters belong to the script: Han.

What the block contains

The Unicode code charts divide this block into groups: Pronunciation variants from KS X 1001:1998; Duplicate characters from Big 5; The IBM 32 compatibility ideographs; Korean compatibility ideographs; JIS X 0213 compatibility ideographs; ARIB compatibility ideographs; DPRK compatibility ideographs.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the CJK Compatibility Ideographs block?

Unicode 18.0 has 472 assigned characters in the CJK Compatibility Ideographs block, out of 512 code points reserved for it (U+F900 to U+FAFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
