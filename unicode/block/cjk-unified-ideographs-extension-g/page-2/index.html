CJK Unified Ideographs Extension G: Unicode block U+30000 to U+3134F

4,939 characters you can look at, copy and paste. Data from Unicode 18.0.

The CJK Unified Ideographs Extension G block covers the code points U+30000 to U+3134F (4,944 positions) in the Tertiary Ideographic Plane (plane 3). Unicode has assigned 4,939 of them so far, which are 4,939 other letters. All its characters were added in Unicode 13.0.

Common questions

How many characters are in the CJK Unified Ideographs Extension G block?

Unicode 18.0 has 4,939 assigned characters in the CJK Unified Ideographs Extension G block, out of 4,944 code points reserved for it (U+30000 to U+3134F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 13.0.
