Glagolitic: Unicode block U+2C00 to U+2C5F

96 characters you can look at, copy and paste. Data from Unicode 18.0.

The Glagolitic block covers the code points U+2C00 to U+2C5F (96 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 96 of them so far, which are 48 uppercase letters, 48 lowercase letters. Its characters were added between Unicode 4.1 and 14.0.

The characters belong to the script: Glagolitic.

What the block contains

The Unicode code charts divide this block into groups: Capital letters; Small letters.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Glagolitic block?

Unicode 18.0 has 96 assigned characters in the Glagolitic block, out of 96 code points reserved for it (U+2C00 to U+2C5F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.1.
