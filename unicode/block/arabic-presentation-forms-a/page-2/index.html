Arabic Presentation Forms-A: Unicode block U+FB50 to U+FDFF

656 characters you can look at, copy and paste. Data from Unicode 18.0.

The Arabic Presentation Forms-A block covers the code points U+FB50 to U+FDFF (688 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 656 of them so far, which are 591 other letters, 45 other symbols, 17 modifier symbols, 1 closing bracket, 1 opening bracket. Its characters were added between Unicode 1.1 and 17.0.

Common questions

How many characters are in the Arabic Presentation Forms-A block?

Unicode 18.0 has 656 assigned characters in the Arabic Presentation Forms-A block, out of 688 code points reserved for it (U+FB50 to U+FDFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
