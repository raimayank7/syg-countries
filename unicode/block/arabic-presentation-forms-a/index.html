Arabic Presentation Forms-A: Unicode block U+FB50 to U+FDFF

656 characters you can look at, copy and paste. Data from Unicode 18.0.

The Arabic Presentation Forms-A block covers the code points U+FB50 to U+FDFF (688 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 656 of them so far, which are 591 other letters, 45 other symbols, 17 modifier symbols, 1 closing bracket, 1 opening bracket. Its characters were added between Unicode 1.1 and 17.0.

The characters belong to these scripts: Arabic, Common.

What the block contains

The Unicode code charts divide this block into groups: Glyphs for contextual forms of letters for Persian, Urdu, Sindhi, etc.; Arabic pedagogical symbols; Honorific word ligatures; Glyphs for contextual forms of letters for Central Asian languages; Ligatures (two elements); Punctuation; Ligatures (three elements); Word ligatures; Currency symbol.
