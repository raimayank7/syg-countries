Marchen: Unicode block U+11C70 to U+11CBF

68 characters you can look at, copy and paste. Data from Unicode 18.0.

The Marchen block covers the code points U+11C70 to U+11CBF (80 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 68 of them so far, which are 33 non-spacing marks, 30 other letters, 3 spacing marks, 2 other punctuation marks. All its characters were added in Unicode 9.0.

The characters belong to the script: Marchen.

What the block contains

The Unicode code charts divide this block into groups: Punctuation; Letters; Subjoined letters; Dependent vowel signs; Various signs.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Marchen block?

Unicode 18.0 has 68 assigned characters in the Marchen block, out of 80 code points reserved for it (U+11C70 to U+11CBF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 9.0.
