Anatolian Hieroglyphs: Unicode block U+14400 to U+1467F

583 characters you can look at, copy and paste. Data from Unicode 18.0.

The Anatolian Hieroglyphs block covers the code points U+14400 to U+1467F (640 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 583 of them so far, which are 583 other letters. All its characters were added in Unicode 8.0.

The characters belong to the script: Anatolian Hieroglyphs.

What the block contains

The Unicode code charts divide this block into groups: A. The human body and clothing; B. Animals; C. Plants; D. Nature; E. Buildings; F. Arms, tools, furniture, and other instruments; G. Vases and receptacles; H. Symbols; J. Lines, numbers, and geometric shapes; K. Varia; M. Additional signs.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.
