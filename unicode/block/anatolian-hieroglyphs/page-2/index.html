Anatolian Hieroglyphs: Unicode block U+14400 to U+1467F

583 characters you can look at, copy and paste. Data from Unicode 18.0.

The Anatolian Hieroglyphs block covers the code points U+14400 to U+1467F (640 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 583 of them so far, which are 583 other letters. All its characters were added in Unicode 8.0.

Common questions

How many characters are in the Anatolian Hieroglyphs block?

Unicode 18.0 has 583 assigned characters in the Anatolian Hieroglyphs block, out of 640 code points reserved for it (U+14400 to U+1467F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 8.0.
