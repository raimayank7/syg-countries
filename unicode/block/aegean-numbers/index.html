Aegean Numbers: Unicode block U+10100 to U+1013F

57 characters you can look at, copy and paste. Data from Unicode 18.0.

The Aegean Numbers block covers the code points U+10100 to U+1013F (64 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 57 of them so far, which are 45 other numbers, 9 other symbols, 3 other punctuation marks. All its characters were added in Unicode 4.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Punctuation; Numbers; Measures.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Aegean Numbers block?

Unicode 18.0 has 57 assigned characters in the Aegean Numbers block, out of 64 code points reserved for it (U+10100 to U+1013F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.0.
