Old Persian: Unicode block U+103A0 to U+103DF

50 characters you can look at, copy and paste. Data from Unicode 18.0.

The Old Persian block covers the code points U+103A0 to U+103DF (64 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 50 of them so far, which are 44 other letters, 5 letter-like numbers, 1 punctuation (other). All its characters were added in Unicode 4.1.

The characters belong to the script: Old Persian.

What the block contains

The Unicode code charts divide this block into groups: Independent vowels; Consonants; Various signs; Punctuation; Numbers.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Old Persian block?

Unicode 18.0 has 50 assigned characters in the Old Persian block, out of 64 code points reserved for it (U+103A0 to U+103DF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.1.
