CJK Radicals Supplement: Unicode block U+2E80 to U+2EFF

115 characters you can look at, copy and paste. Data from Unicode 18.0.

The CJK Radicals Supplement block covers the code points U+2E80 to U+2EFF (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 115 of them so far, which are 115 other symbols. All its characters were added in Unicode 3.0.

The characters belong to the script: Han.

What the block contains

The Unicode code charts divide this block into groups: CJK radicals supplement.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the CJK Radicals Supplement block?

Unicode 18.0 has 115 assigned characters in the CJK Radicals Supplement block, out of 128 code points reserved for it (U+2E80 to U+2EFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.0.
