Arabic Extended-C: Unicode block U+10EC0 to U+10EFF

60 characters you can look at, copy and paste. Data from Unicode 18.0.

The Arabic Extended-C block covers the code points U+10EC0 to U+10EFF (64 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 60 of them so far, which are 27 other letters, 21 non-spacing marks, 8 other symbols, 2 modifier symbols, 1 modifier letter. Its characters were added between Unicode 15.0 and 18.0.

The characters belong to the script: Arabic.

What the block contains

The Unicode code charts divide this block into groups: Letters for Pegon; Quranic letter used in Indonesia; Quranic letter used in Warsh orthography; Letter used for Swahili; Quranic marks; Biblical punctuation mark; Honorific word ligatures; Crown letters; Quranic naql marks; Crown mark; Tanween mark used in Old Sindhi; Quranic mark used in Indonesia; Quranic mark used in Libya; Quranic marks used in Turkey.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Arabic Extended-C block?

Unicode 18.0 has 60 assigned characters in the Arabic Extended-C block, out of 64 code points reserved for it (U+10EC0 to U+10EFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 15.0.
