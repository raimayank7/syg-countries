Syloti Nagri: Unicode block U+A800 to U+A82F

45 characters you can look at, copy and paste. Data from Unicode 18.0.

The Syloti Nagri block covers the code points U+A800 to U+A82F (48 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 45 of them so far, which are 32 other letters, 6 non-spacing marks, 4 other symbols, 3 spacing marks. Its characters were added between Unicode 4.1 and 13.0.

The characters belong to the script: Syloti Nagri.

What the block contains

The Unicode code charts divide this block into groups: Independent vowels and dvisvara; Sign; Consonants and consonant signs; Dependent vowel signs; Poetry marks.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Syloti Nagri block?

Unicode 18.0 has 45 assigned characters in the Syloti Nagri block, out of 48 code points reserved for it (U+A800 to U+A82F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.1.
