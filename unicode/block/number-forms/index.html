Number Forms: Unicode block U+2150 to U+218F

60 characters you can look at, copy and paste. Data from Unicode 18.0.

The Number Forms block covers the code points U+2150 to U+218F (64 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 60 of them so far, which are 39 letter-like numbers, 17 other numbers, 2 other symbols, 1 uppercase letter, 1 lowercase letter. Its characters were added between Unicode 1.1 and 8.0.

The characters belong to these scripts: Common, Latin.

What the block contains

The Unicode code charts divide this block into groups: Fractions; Roman numerals; Archaic Roman numerals; Lowercase Claudian letter; Fraction; Turned digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Number Forms block?

Unicode 18.0 has 60 assigned characters in the Number Forms block, out of 64 code points reserved for it (U+2150 to U+218F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
