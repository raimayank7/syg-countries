Miao: Unicode block U+16F00 to U+16F9F

149 characters you can look at, copy and paste. Data from Unicode 18.0.

The Miao block covers the code points U+16F00 to U+16F9F (160 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 149 of them so far, which are 76 other letters, 55 spacing marks, 13 modifier letters, 5 non-spacing marks. Its characters were added between Unicode 6.1 and 12.0.

The characters belong to the script: Miao.

What the block contains

The Unicode code charts divide this block into groups: Consonant onsets; Modifiers; Vowels and finals; Positioning tone marks; Baseline tone marks; Archaic baseline tone marks.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Miao block?

Unicode 18.0 has 149 assigned characters in the Miao block, out of 160 code points reserved for it (U+16F00 to U+16F9F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 6.1.
