Bopomofo: Unicode block U+3100 to U+312F

43 characters you can look at, copy and paste. Data from Unicode 18.0.

The Bopomofo block covers the code points U+3100 to U+312F (48 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 43 of them so far, which are 43 other letters. Its characters were added between Unicode 1.1 and 11.0.

The characters belong to the script: Bopomofo.

What the block contains

The Unicode code charts divide this block into groups: Based on GB 2312; Dialect (non-Mandarin) letters; Miscellaneous additions.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Bopomofo block?

Unicode 18.0 has 43 assigned characters in the Bopomofo block, out of 48 code points reserved for it (U+3100 to U+312F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
