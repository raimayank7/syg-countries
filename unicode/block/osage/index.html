Osage: Unicode block U+104B0 to U+104FF

72 characters you can look at, copy and paste. Data from Unicode 18.0.

The Osage block covers the code points U+104B0 to U+104FF (80 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 72 of them so far, which are 36 uppercase letters, 36 lowercase letters. All its characters were added in Unicode 9.0.

The characters belong to the script: Osage.

What the block contains

The Unicode code charts divide this block into groups: Uppercase letters; Lowercase letters.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Osage block?

Unicode 18.0 has 72 assigned characters in the Osage block, out of 80 code points reserved for it (U+104B0 to U+104FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 9.0.
