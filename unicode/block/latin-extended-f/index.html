Latin Extended-F: Unicode block U+10780 to U+107BF

62 characters you can look at, copy and paste. Data from Unicode 18.0.

The Latin Extended-F block covers the code points U+10780 to U+107BF (64 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 62 of them so far, which are 62 modifier letters. Its characters were added between Unicode 14.0 and 18.0.

The characters belong to the script: Latin.

What the block contains

The Unicode code charts divide this block into groups: Modifier letter for VoQS; Modifier letters for IPA.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Latin Extended-F block?

Unicode 18.0 has 62 assigned characters in the Latin Extended-F block, out of 64 code points reserved for it (U+10780 to U+107BF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 14.0.
