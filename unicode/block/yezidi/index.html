Yezidi: Unicode block U+10E80 to U+10EBF

47 characters you can look at, copy and paste. Data from Unicode 18.0.

The Yezidi block covers the code points U+10E80 to U+10EBF (64 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 47 of them so far, which are 44 other letters, 2 non-spacing marks, 1 dash. All its characters were added in Unicode 13.0.

The characters belong to the script: Yezidi.

What the block contains

The Unicode code charts divide this block into groups: Letters; Combining marks; Punctuation; Historical letters with diacritics.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Yezidi block?

Unicode 18.0 has 47 assigned characters in the Yezidi block, out of 64 code points reserved for it (U+10E80 to U+10EBF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 13.0.
