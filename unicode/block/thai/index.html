Thai: Unicode block U+0E00 to U+0E7F

87 characters you can look at, copy and paste. Data from Unicode 18.0.

The Thai block covers the code points U+0E00 to U+0E7F (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 87 of them so far, which are 56 other letters, 16 non-spacing marks, 10 decimal digits, 3 other punctuation marks, 1 currency symbol. All its characters were added in Unicode 1.1.

The characters belong to these scripts: Common, Thai.

What the block contains

The Unicode code charts divide this block into groups: Consonants; Sign; Vowels; Currency symbol; Vowel length sign; Repetition mark; Vowel; Tone marks; Signs; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Thai block?

Unicode 18.0 has 87 assigned characters in the Thai block, out of 128 code points reserved for it (U+0E00 to U+0E7F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
