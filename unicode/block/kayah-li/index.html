Kayah Li: Unicode block U+A900 to U+A92F

48 characters you can look at, copy and paste. Data from Unicode 18.0.

The Kayah Li block covers the code points U+A900 to U+A92F (48 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 48 of them so far, which are 28 other letters, 10 decimal digits, 8 non-spacing marks, 2 other punctuation marks. All its characters were added in Unicode 5.1.

The characters belong to these scripts: Common, Kayah Li.

What the block contains

The Unicode code charts divide this block into groups: Digits; Consonants; Vowels; Tone marks; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Kayah Li block?

Unicode 18.0 has 48 assigned characters in the Kayah Li block, out of 48 code points reserved for it (U+A900 to U+A92F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.1.
