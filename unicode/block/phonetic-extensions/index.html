Phonetic Extensions: Unicode block U+1D00 to U+1D7F

128 characters you can look at, copy and paste. Data from Unicode 18.0.

The Phonetic Extensions block covers the code points U+1D00 to U+1D7F (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 128 of them so far, which are 64 lowercase letters, 64 modifier letters. Its characters were added between Unicode 4.0 and 4.1.

The characters belong to these scripts: Cyrillic, Greek, Latin.

What the block contains

The Unicode code charts divide this block into groups: Latin letters; Greek letters; Cyrillic letter; Latin superscript modifier letters; Greek superscript modifier letters; Latin subscript modifier letters; Greek subscript modifier letters; Latin letter for American lexicography; Latin letters with middle tilde; Letters for Caucasian linguistics; Other phonetic symbols.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Phonetic Extensions block?

Unicode 18.0 has 128 assigned characters in the Phonetic Extensions block, out of 128 code points reserved for it (U+1D00 to U+1D7F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.0.
