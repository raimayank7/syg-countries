Cypro-Minoan: Unicode block U+12F90 to U+12FFF

99 characters you can look at, copy and paste. Data from Unicode 18.0.

The Cypro-Minoan block covers the code points U+12F90 to U+12FFF (112 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 99 of them so far, which are 97 other letters, 2 other punctuation marks. All its characters were added in Unicode 14.0.

The characters belong to the script: Cypro Minoan.

What the block contains

The Unicode code charts divide this block into groups: Signs; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Cypro-Minoan block?

Unicode 18.0 has 99 assigned characters in the Cypro-Minoan block, out of 112 code points reserved for it (U+12F90 to U+12FFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.
