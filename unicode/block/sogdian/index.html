Sogdian: Unicode block U+10F30 to U+10F6F

42 characters you can look at, copy and paste. Data from Unicode 18.0.

The Sogdian block covers the code points U+10F30 to U+10F6F (64 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 42 of them so far, which are 22 other letters, 11 non-spacing marks, 5 other punctuation marks, 4 other numbers. All its characters were added in Unicode 11.0.

The characters belong to the script: Sogdian.

What the block contains

The Unicode code charts divide this block into groups: Letters; Phonogram; Combining marks; Numbers; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Sogdian block?

Unicode 18.0 has 42 assigned characters in the Sogdian block, out of 64 code points reserved for it (U+10F30 to U+10F6F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 11.0.
