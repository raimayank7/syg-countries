Gurmukhi: Unicode block U+0A00 to U+0A7F

80 characters you can look at, copy and paste. Data from Unicode 18.0.

The Gurmukhi block covers the code points U+0A00 to U+0A7F (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 80 of them so far, which are 51 other letters, 14 non-spacing marks, 10 decimal digits, 4 spacing marks, 1 punctuation (other). Its characters were added between Unicode 1.1 and 11.0.

The characters belong to the script: Gurmukhi.

What the block contains

The Unicode code charts divide this block into groups: Various signs; Independent vowels; Consonants; Dependent vowel signs; Virama; Sign; Additional consonants; Digits; Signs; Vowel bases.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

32 of the 80 named characters have their own page.

Common questions

How many characters are in the Gurmukhi block?

Unicode 18.0 has 80 assigned characters in the Gurmukhi block, out of 128 code points reserved for it (U+0A00 to U+0A7F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
