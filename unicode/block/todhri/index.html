Todhri: Unicode block U+105C0 to U+105FF

52 characters you can look at, copy and paste. Data from Unicode 18.0.

The Todhri block covers the code points U+105C0 to U+105FF (64 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 52 of them so far, which are 52 other letters. All its characters were added in Unicode 16.0.

The characters belong to the script: Todhri.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Todhri block?

Unicode 18.0 has 52 assigned characters in the Todhri block, out of 64 code points reserved for it (U+105C0 to U+105FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 16.0.
