Cyrillic Extended-B: Unicode block U+A640 to U+A69F

96 characters you can look at, copy and paste. Data from Unicode 18.0.

The Cyrillic Extended-B block covers the code points U+A640 to U+A69F (96 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 96 of them so far, which are 37 uppercase letters, 37 lowercase letters, 13 non-spacing marks, 3 enclosing marks, 3 modifier letters. Its characters were added between Unicode 5.1 and 8.0.

The characters belong to the script: Cyrillic.

What the block contains

The Unicode code charts divide this block into groups: Letters for Old Cyrillic; Abbreviation mark; Combining numeric signs; Punctuation mark; Combining marks for Old Cyrillic; Modifier letter; Letters for Old Abkhasian orthography; Intonation marks for Lithuanian dialectology.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Cyrillic Extended-B block?

Unicode 18.0 has 96 assigned characters in the Cyrillic Extended-B block, out of 96 code points reserved for it (U+A640 to U+A69F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.1.
