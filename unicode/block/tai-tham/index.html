Tai Tham: Unicode block U+1A20 to U+1AAF

127 characters you can look at, copy and paste. Data from Unicode 18.0.

The Tai Tham block covers the code points U+1A20 to U+1AAF (144 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 127 of them so far, which are 53 other letters, 29 non-spacing marks, 20 decimal digits, 13 other punctuation marks, 11 spacing marks. All its characters were added in Unicode 5.2.

The characters belong to the script: Tai Tham.

What the block contains

The Unicode code charts divide this block into groups: Consonants; Independent vowels; Consonant signs; Sign; Dependent vowel signs; Tone marks; Other marks; Cryptogrammic mark; Hora digits; Tham digits; Logographs; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Tai Tham block?

Unicode 18.0 has 127 assigned characters in the Tai Tham block, out of 144 code points reserved for it (U+1A20 to U+1AAF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.2.
