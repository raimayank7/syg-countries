Adlam: Unicode block U+1E900 to U+1E95F

88 characters you can look at, copy and paste. Data from Unicode 18.0.

The Adlam block covers the code points U+1E900 to U+1E95F (96 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 88 of them so far, which are 34 uppercase letters, 34 lowercase letters, 10 decimal digits, 7 non-spacing marks, 2 other punctuation marks. Its characters were added between Unicode 9.0 and 12.0.

The characters belong to the script: Adlam.

What the block contains

The Unicode code charts divide this block into groups: Capital letters; Supplementary capital letters; Small letters; Supplementary small letters; Diacritical marks; Modifier letter; Digits; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Adlam block?

Unicode 18.0 has 88 assigned characters in the Adlam block, out of 96 code points reserved for it (U+1E900 to U+1E95F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 9.0.
