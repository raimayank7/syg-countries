Rejang: Unicode block U+A930 to U+A95F

37 characters you can look at, copy and paste. Data from Unicode 18.0.

The Rejang block covers the code points U+A930 to U+A95F (48 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 37 of them so far, which are 23 other letters, 11 non-spacing marks, 2 spacing marks, 1 punctuation (other). All its characters were added in Unicode 5.1.

The characters belong to the script: Rejang.

What the block contains

The Unicode code charts divide this block into groups: Consonants; Vowel signs; Consonant signs; Virama; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Rejang block?

Unicode 18.0 has 37 assigned characters in the Rejang block, out of 48 code points reserved for it (U+A930 to U+A95F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.1.
