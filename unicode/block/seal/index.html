Seal: Unicode block U+3D000 to U+3FC3F

11,328 characters you can look at, copy and paste. Data from Unicode 18.0.

The Seal block covers the code points U+3D000 to U+3FC3F (11,328 positions) in the Tertiary Ideographic Plane (plane 3). Unicode has assigned 11,328 of them so far, which are 11,328 other letters. All its characters were added in Unicode 18.0.

Characters in this block are not given individual names in the standard: each is named by its code point, for example "Seal Character". The table lists them in code order, 256 to a page. Only the first 1,024 are listed on this site; the other 10,304 characters of the block are not shown, because a page of thousands of look-alike entries helps nobody.

Common questions

How many characters are in the Seal block?

Unicode 18.0 has 11,328 assigned characters in the Seal block, out of 11,328 code points reserved for it (U+3D000 to U+3FC3F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 18.0.
