Buginese: Unicode block U+1A00 to U+1A1F

30 characters you can look at, copy and paste. Data from Unicode 18.0.

The Buginese block covers the code points U+1A00 to U+1A1F (32 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 30 of them so far, which are 23 other letters, 3 non-spacing marks, 2 spacing marks, 2 other punctuation marks. All its characters were added in Unicode 4.1.

The characters belong to the script: Buginese.

What the block contains

The Unicode code charts divide this block into groups: Consonants; Vowels; Various signs.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Buginese block?

Unicode 18.0 has 30 assigned characters in the Buginese block, out of 32 code points reserved for it (U+1A00 to U+1A1F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.1.
