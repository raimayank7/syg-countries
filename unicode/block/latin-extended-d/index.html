Latin Extended-D: Unicode block U+A720 to U+A7FF

206 characters you can look at, copy and paste. Data from Unicode 18.0.

The Latin Extended-D block covers the code points U+A720 to U+A7FF (224 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 206 of them so far, which are 95 uppercase letters, 92 lowercase letters, 8 modifier letters, 7 other letters, 4 modifier symbols. Its characters were added between Unicode 5.0 and 18.0.

The characters belong to these scripts: Common, Latin.

What the block contains

The Unicode code charts divide this block into groups: Additions for UPA; Egyptological additions; Mayanist additions; Medievalist additions; Insular and Celticist letters; Modifier letters; Orthographic letters for glottals; Additional letter; Phonetic symbol; Transliteration letter for sinology; Additional letters; Additions for Lithuanian dialectology; Letters for Middle Vietnamese; Archaic letters for Ewe and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Latin Extended-D block?

Unicode 18.0 has 206 assigned characters in the Latin Extended-D block, out of 224 code points reserved for it (U+A720 to U+A7FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.0.
