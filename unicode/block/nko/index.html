NKo: Unicode block U+07C0 to U+07FF

62 characters you can look at, copy and paste. Data from Unicode 18.0.

The NKo block covers the code points U+07C0 to U+07FF (64 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 62 of them so far, which are 33 other letters, 10 decimal digits, 10 non-spacing marks, 3 modifier letters, 3 other punctuation marks. Its characters were added between Unicode 5.0 and 11.0.

The characters belong to the script: Nko.

What the block contains

The Unicode code charts divide this block into groups: Digits; Letters; Archaic letters; Tone marks; Other diacritics; Tonal apostrophes; Symbol; Punctuation; Letter extender; Abbreviation sign; Currency symbols.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the NKo block?

Unicode 18.0 has 62 assigned characters in the NKo block, out of 64 code points reserved for it (U+07C0 to U+07FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.0.
