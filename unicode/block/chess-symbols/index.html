Chess Symbols: Unicode block U+1FA00 to U+1FA6F

102 characters you can look at, copy and paste. Data from Unicode 18.0.

The Chess Symbols block covers the code points U+1FA00 to U+1FA6F (112 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 102 of them so far, which are 102 other symbols. Its characters were added between Unicode 11.0 and 17.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Neutral chess symbols; Chess symbols rotated 45 degrees; Chess symbols rotated 90 degrees; Chess symbols rotated 135 degrees; Chess symbols rotated 180 degrees (turned); Chess symbols rotated 225 degrees; Chess symbols rotated 270 degrees; Chess symbols rotated 315 degrees; Chess equihoppers; Chess equihoppers rotated 90 degrees; Hybrid chess symbols; Shatranj chess symbols; Xiangqi symbols.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

27 of the 102 named characters have their own page.

Common questions

How many characters are in the Chess Symbols block?

Unicode 18.0 has 102 assigned characters in the Chess Symbols block, out of 112 code points reserved for it (U+1FA00 to U+1FA6F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 11.0.
