Old Hungarian: Unicode block U+10C80 to U+10CFF

108 characters you can look at, copy and paste. Data from Unicode 18.0.

The Old Hungarian block covers the code points U+10C80 to U+10CFF (128 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 108 of them so far, which are 51 uppercase letters, 51 lowercase letters, 6 other numbers. All its characters were added in Unicode 8.0.

The characters belong to the script: Old Hungarian.

What the block contains

The Unicode code charts divide this block into groups: Uppercase letters; Lowercase letters; Numbers.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Old Hungarian block?

Unicode 18.0 has 108 assigned characters in the Old Hungarian block, out of 128 code points reserved for it (U+10C80 to U+10CFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 8.0.
