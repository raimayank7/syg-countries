Khojki: Unicode block U+11200 to U+1124F

65 characters you can look at, copy and paste. Data from Unicode 18.0.

The Khojki block covers the code points U+11200 to U+1124F (80 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 65 of them so far, which are 45 other letters, 8 non-spacing marks, 6 spacing marks, 6 other punctuation marks. Its characters were added between Unicode 7.0 and 15.0.

The characters belong to the script: Khojki.

What the block contains

The Unicode code charts divide this block into groups: Independent vowels; Consonants; Dependent vowel signs; Various signs; Punctuation; Sign; Consonant; Independent vowel; Dependent vowel sign.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Khojki block?

Unicode 18.0 has 65 assigned characters in the Khojki block, out of 80 code points reserved for it (U+11200 to U+1124F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
