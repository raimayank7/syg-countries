Khmer: Unicode block U+1780 to U+17FF

114 characters you can look at, copy and paste. Data from Unicode 18.0.

The Khmer block covers the code points U+1780 to U+17FF (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 114 of them so far, which are 53 other letters, 22 non-spacing marks, 11 spacing marks, 10 decimal digits, 10 other numbers. Its characters were added between Unicode 3.0 and 4.0.

The characters belong to the script: Khmer.

What the block contains

The Unicode code charts divide this block into groups: Consonants; Deprecated independent vowels for transliteration; Independent vowels; Inherent vowels; Dependent vowel signs; Two-part dependent vowel signs; Various signs; Consonant shifters; Lunar date sign; Currency symbol; Digits; Numeric symbols for divination lore.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Khmer block?

Unicode 18.0 has 114 assigned characters in the Khmer block, out of 128 code points reserved for it (U+1780 to U+17FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.0.
