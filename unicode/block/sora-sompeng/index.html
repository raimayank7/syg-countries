Sora Sompeng: Unicode block U+110D0 to U+110FF

35 characters you can look at, copy and paste. Data from Unicode 18.0.

The Sora Sompeng block covers the code points U+110D0 to U+110FF (48 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 35 of them so far, which are 25 other letters, 10 decimal digits. All its characters were added in Unicode 6.1.

The characters belong to the script: Sora Sompeng.

What the block contains

The Unicode code charts divide this block into groups: Consonants; Vowels; Other letter; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Sora Sompeng block?

Unicode 18.0 has 35 assigned characters in the Sora Sompeng block, out of 48 code points reserved for it (U+110D0 to U+110FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 6.1.
