Counting Rod Numerals: Unicode block U+1D360 to U+1D37F

25 characters you can look at, copy and paste. Data from Unicode 18.0.

The Counting Rod Numerals block covers the code points U+1D360 to U+1D37F (32 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 25 of them so far, which are 25 other numbers. Its characters were added between Unicode 5.0 and 11.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Counting rod units; Ideographic tally marks; Western tally marks.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Counting Rod Numerals block?

Unicode 18.0 has 25 assigned characters in the Counting Rod Numerals block, out of 32 code points reserved for it (U+1D360 to U+1D37F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.0.
