Old Uyghur: Unicode block U+10F70 to U+10FAF

26 characters you can look at, copy and paste. Data from Unicode 18.0.

The Old Uyghur block covers the code points U+10F70 to U+10FAF (64 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 26 of them so far, which are 18 other letters, 4 non-spacing marks, 4 other punctuation marks. All its characters were added in Unicode 14.0.

The characters belong to the script: Old Uyghur.

What the block contains

The Unicode code charts divide this block into groups: Letters; Combining signs; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Old Uyghur block?

Unicode 18.0 has 26 assigned characters in the Old Uyghur block, out of 64 code points reserved for it (U+10F70 to U+10FAF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 14.0.
