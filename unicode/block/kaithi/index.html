Kaithi: Unicode block U+11080 to U+110CF

68 characters you can look at, copy and paste. Data from Unicode 18.0.

The Kaithi block covers the code points U+11080 to U+110CF (80 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 68 of them so far, which are 45 other letters, 9 non-spacing marks, 6 spacing marks, 6 other punctuation marks, 2 format characters. Its characters were added between Unicode 5.2 and 14.0.

The characters belong to the script: Kaithi.

What the block contains

The Unicode code charts divide this block into groups: Various signs; Independent vowels; Consonants; Dependent vowel signs; Virama; Punctuation; Vowel sign; Sign.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Kaithi block?

Unicode 18.0 has 68 assigned characters in the Kaithi block, out of 80 code points reserved for it (U+11080 to U+110CF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.2.
