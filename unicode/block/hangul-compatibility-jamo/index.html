Hangul Compatibility Jamo: Unicode block U+3130 to U+318F

94 characters you can look at, copy and paste. Data from Unicode 18.0.

The Hangul Compatibility Jamo block covers the code points U+3130 to U+318F (96 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 94 of them so far, which are 94 other letters. All its characters were added in Unicode 1.1.

The characters belong to the script: Hangul.

What the block contains

The Unicode code charts divide this block into groups: Consonant letters; Vowel letters; Special character; Old consonant letters; Old vowel letters.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Hangul Compatibility Jamo block?

Unicode 18.0 has 94 assigned characters in the Hangul Compatibility Jamo block, out of 96 code points reserved for it (U+3130 to U+318F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
