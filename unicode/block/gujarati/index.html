Gujarati: Unicode block U+0A80 to U+0AFF

91 characters you can look at, copy and paste. Data from Unicode 18.0.

The Gujarati block covers the code points U+0A80 to U+0AFF (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 91 of them so far, which are 53 other letters, 19 non-spacing marks, 10 decimal digits, 7 spacing marks, 1 punctuation (other). Its characters were added between Unicode 1.1 and 10.0.

The characters belong to the script: Gujarati.

What the block contains

The Unicode code charts divide this block into groups: Various signs; Independent vowels; Consonants; Dependent vowel signs; Virama; Additional vowels for Sanskrit; Digits; Abbreviation sign; Currency symbol; Additional consonant; Transliteration signs.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Gujarati block?

Unicode 18.0 has 91 assigned characters in the Gujarati block, out of 128 code points reserved for it (U+0A80 to U+0AFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
