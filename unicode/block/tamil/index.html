Tamil: Unicode block U+0B80 to U+0BFF

72 characters you can look at, copy and paste. Data from Unicode 18.0.

The Tamil block covers the code points U+0B80 to U+0BFF (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 72 of them so far, which are 37 other letters, 11 spacing marks, 10 decimal digits, 7 other symbols, 3 non-spacing marks. Its characters were added between Unicode 1.1 and 5.1.

The characters belong to the script: Tamil.

What the block contains

The Unicode code charts divide this block into groups: Various signs; Independent vowels; Consonants; Dependent vowel signs; Two-part dependent vowel signs; Virama; Digits; Tamil numerics; Tamil calendrical symbols; Tamil clerical symbols; Currency symbol; Tamil clerical symbol.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Tamil block?

Unicode 18.0 has 72 assigned characters in the Tamil block, out of 128 code points reserved for it (U+0B80 to U+0BFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
