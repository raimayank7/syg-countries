Siddham: Unicode block U+11580 to U+115FF

92 characters you can look at, copy and paste. Data from Unicode 18.0.

The Siddham block covers the code points U+11580 to U+115FF (128 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 92 of them so far, which are 51 other letters, 23 other punctuation marks, 10 non-spacing marks, 8 spacing marks. Its characters were added between Unicode 7.0 and 8.0.

The characters belong to the script: Siddham.

What the block contains

The Unicode code charts divide this block into groups: Independent vowels; Consonants; Dependent vowel signs; Various signs; Head mark; Punctuation; Repetition marks; Terminal mark; Section marks; Alternate letters; Alternate vowel signs.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Siddham block?

Unicode 18.0 has 92 assigned characters in the Siddham block, out of 128 code points reserved for it (U+11580 to U+115FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
