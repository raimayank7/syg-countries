CJK Unified Ideographs Extension C: Unicode block U+2A700 to U+2B73F

4,160 characters you can look at, copy and paste. Data from Unicode 18.0.

The CJK Unified Ideographs Extension C block covers the code points U+2A700 to U+2B73F (4,160 positions) in the Supplementary Ideographic Plane (plane 2). Unicode has assigned 4,160 of them so far, which are 4,160 other letters. All its characters were added in Unicode 5.2.

Common questions

How many characters are in the CJK Unified Ideographs Extension C block?

Unicode 18.0 has 4,160 assigned characters in the CJK Unified Ideographs Extension C block, out of 4,160 code points reserved for it (U+2A700 to U+2B73F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.2.
