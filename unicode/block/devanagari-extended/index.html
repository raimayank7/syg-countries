Devanagari Extended: Unicode block U+A8E0 to U+A8FF

32 characters you can look at, copy and paste. Data from Unicode 18.0.

The Devanagari Extended block covers the code points U+A8E0 to U+A8FF (32 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 32 of them so far, which are 19 non-spacing marks, 9 other letters, 4 other punctuation marks. Its characters were added between Unicode 5.2 and 11.0.

The characters belong to the script: Devanagari.

What the block contains

The Unicode code charts divide this block into groups: Cantillation marks (svara) for the Samaveda; Marks of nasalization; Editorial marks; Signs; Additional vowel and vowel sign.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Devanagari Extended block?

Unicode 18.0 has 32 assigned characters in the Devanagari Extended block, out of 32 code points reserved for it (U+A8E0 to U+A8FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.2.
