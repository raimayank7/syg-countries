Hangul Syllables: Unicode block U+AC00 to U+D7AF

11,172 characters you can look at, copy and paste. Data from Unicode 18.0.

The Hangul Syllables block covers the code points U+AC00 to U+D7AF (11,184 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 11,172 of them so far, which are 11,172 other letters. All its characters were added in Unicode 2.0.

Common questions

How many characters are in the Hangul Syllables block?

Unicode 18.0 has 11,172 assigned characters in the Hangul Syllables block, out of 11,184 code points reserved for it (U+AC00 to U+D7AF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 2.0.
