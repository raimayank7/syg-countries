Mathematical Alphanumeric Symbols: Unicode block U+1D400 to U+1D7FF

997 characters you can look at, copy and paste. Data from Unicode 18.0.

The Mathematical Alphanumeric Symbols block covers the code points U+1D400 to U+1D7FF (1,024 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 997 of them so far, which are 493 lowercase letters, 444 uppercase letters, 50 decimal digits, 10 math symbols. Its characters were added between Unicode 3.1 and 18.0.

Common questions

How many characters are in the Mathematical Alphanumeric Symbols block?

Unicode 18.0 has 997 assigned characters in the Mathematical Alphanumeric Symbols block, out of 1,024 code points reserved for it (U+1D400 to U+1D7FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.1.
