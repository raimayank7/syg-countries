Balinese: Unicode block U+1B00 to U+1B7F

127 characters you can look at, copy and paste. Data from Unicode 18.0.

The Balinese block covers the code points U+1B00 to U+1B7F (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 127 of them so far, which are 55 other letters, 21 non-spacing marks, 19 other symbols, 12 other punctuation marks, 10 spacing marks. Its characters were added between Unicode 5.0 and 16.0.

The characters belong to the script: Balinese.

What the block contains

The Unicode code charts divide this block into groups: Various signs; Independent vowels; Consonants; Sign; Dependent vowel signs; Additional consonants; Punctuation; Digits; Musical symbols for notes; Diacritical marks for musical symbols; Musical symbols.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Balinese block?

Unicode 18.0 has 127 assigned characters in the Balinese block, out of 128 code points reserved for it (U+1B00 to U+1B7F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.0.
