Garay: Unicode block U+10D40 to U+10D8F

69 characters you can look at, copy and paste. Data from Unicode 18.0.

The Garay block covers the code points U+10D40 to U+10D8F (80 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 69 of them so far, which are 22 uppercase letters, 22 lowercase letters, 10 decimal digits, 5 other letters, 5 non-spacing marks. All its characters were added in Unicode 16.0.

The characters belong to the script: Garay.

What the block contains

The Unicode code charts divide this block into groups: Digits; Vowel signs; Vowel modifiers; Uppercase consonant letters; Vowel sign; Marks; Punctuation and reduplication mark; Lowercase consonant letters; Mathematical symbols.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Garay block?

Unicode 18.0 has 69 assigned characters in the Garay block, out of 80 code points reserved for it (U+10D40 to U+10D8F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 16.0.
