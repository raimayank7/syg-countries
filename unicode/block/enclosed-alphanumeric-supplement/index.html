Enclosed Alphanumeric Supplement: Unicode block U+1F100 to U+1F1FF

201 characters you can look at, copy and paste. Data from Unicode 18.0.

The Enclosed Alphanumeric Supplement block covers the code points U+1F100 to U+1F1FF (256 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 201 of them so far, which are 188 other symbols, 13 other numbers. Its characters were added between Unicode 5.2 and 18.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Number with full stop; Numbers with comma; Circled sans-serif digits; Creative Commons symbols; Parenthesized Latin letters; Latin letter with tortoise shell brackets; Circled italic Latin letters; Circled Latin letters or letter sequences; Squared Latin letters; White on black circled Latin letters; Raised squared Latin sequences; White on black squared Latin letters; Squared Latin letter sequences; Squared Latin letter sequences from ARIB STD B62 and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Enclosed Alphanumeric Supplement block?

Unicode 18.0 has 201 assigned characters in the Enclosed Alphanumeric Supplement block, out of 256 code points reserved for it (U+1F100 to U+1F1FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.2.
