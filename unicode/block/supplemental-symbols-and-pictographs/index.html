Supplemental Symbols and Pictographs: Unicode block U+1F900 to U+1F9FF

256 characters you can look at, copy and paste. Data from Unicode 18.0.

The Supplemental Symbols and Pictographs block covers the code points U+1F900 to U+1F9FF (256 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 256 of them so far, which are 256 other symbols. Its characters were added between Unicode 8.0 and 14.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Typicon symbols; Hand symbol; Colored heart symbols; Emoticon faces; Hand symbols; Portrait and role symbols; Sport symbols; Miscellaneous symbols; Food symbols; Faces; Clothing; Animal symbols; Accessibility symbols; Emoji components and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

244 of the 256 named characters have their own page.

Common questions

How many characters are in the Supplemental Symbols and Pictographs block?

Unicode 18.0 has 256 assigned characters in the Supplemental Symbols and Pictographs block, out of 256 code points reserved for it (U+1F900 to U+1F9FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 8.0.
