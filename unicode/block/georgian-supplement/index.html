Georgian Supplement: Unicode block U+2D00 to U+2D2F

40 characters you can look at, copy and paste. Data from Unicode 18.0.

The Georgian Supplement block covers the code points U+2D00 to U+2D2F (48 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 40 of them so far, which are 40 lowercase letters. Its characters were added between Unicode 4.1 and 6.1.

The characters belong to the script: Georgian.

What the block contains

The Unicode code charts divide this block into groups: Small letters (Khutsuri); Additional letter; Additional letter for Ossetian.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Georgian Supplement block?

Unicode 18.0 has 40 assigned characters in the Georgian Supplement block, out of 48 code points reserved for it (U+2D00 to U+2D2F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.1.
