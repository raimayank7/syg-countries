Gurung Khema: Unicode block U+16100 to U+1613F

58 characters you can look at, copy and paste. Data from Unicode 18.0.

The Gurung Khema block covers the code points U+16100 to U+1613F (64 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 58 of them so far, which are 30 other letters, 15 non-spacing marks, 10 decimal digits, 3 spacing marks. All its characters were added in Unicode 16.0.

The characters belong to the script: Gurung Khema.

What the block contains

The Unicode code charts divide this block into groups: Vowel carrier; Consonants; Vowel signs; Vowel length mark; Medial consonant signs; Various signs; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Gurung Khema block?

Unicode 18.0 has 58 assigned characters in the Gurung Khema block, out of 64 code points reserved for it (U+16100 to U+1613F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 16.0.
