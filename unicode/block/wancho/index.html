Wancho: Unicode block U+1E2C0 to U+1E2FF

59 characters you can look at, copy and paste. Data from Unicode 18.0.

The Wancho block covers the code points U+1E2C0 to U+1E2FF (64 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 59 of them so far, which are 44 other letters, 10 decimal digits, 4 non-spacing marks, 1 currency symbol. All its characters were added in Unicode 12.0.

The characters belong to the script: Wancho.

What the block contains

The Unicode code charts divide this block into groups: Letters; Tone marks; Digits; Currency symbol.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Wancho block?

Unicode 18.0 has 59 assigned characters in the Wancho block, out of 64 code points reserved for it (U+1E2C0 to U+1E2FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 12.0.
