Devanagari: Unicode block U+0900 to U+097F

128 characters you can look at, copy and paste. Data from Unicode 18.0.

The Devanagari block covers the code points U+0900 to U+097F (128 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 128 of them so far, which are 80 other letters, 23 non-spacing marks, 11 spacing marks, 10 decimal digits, 3 other punctuation marks. Its characters were added between Unicode 1.1 and 7.0.

The characters belong to these scripts: Common, Devanagari, Inherited.

What the block contains

The Unicode code charts divide this block into groups: Various signs; Independent vowels; Consonants; Dependent vowel signs; Virama; Sign; Vedic tone marks; Accent marks; Dependent vowel sign; Dependent vowel signs for Kashmiri; Additional consonants; Additional vowels for Sanskrit; Generic punctuation for scripts of India; Digits and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

47 of the 128 named characters have their own page.

Common questions

How many characters are in the Devanagari block?

Unicode 18.0 has 128 assigned characters in the Devanagari block, out of 128 code points reserved for it (U+0900 to U+097F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
