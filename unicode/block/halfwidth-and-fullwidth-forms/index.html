Halfwidth and Fullwidth Forms: Unicode block U+FF00 to U+FFEF

225 characters you can look at, copy and paste. Data from Unicode 18.0.

The Halfwidth and Fullwidth Forms block covers the code points U+FF00 to U+FFEF (240 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 225 of them so far, which are 107 other letters, 26 uppercase letters, 26 lowercase letters, 18 other punctuation marks, 11 math symbols. Its characters were added between Unicode 1.1 and 3.2.

The characters belong to these scripts: Common, Hangul, Katakana, Latin.

What the block contains

The Unicode code charts divide this block into groups: Fullwidth ASCII variants; Fullwidth brackets; Halfwidth CJK punctuation; Halfwidth Katakana variants; Halfwidth Hangul variants; Fullwidth symbol variants; Halfwidth symbol variants.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Halfwidth and Fullwidth Forms block?

Unicode 18.0 has 225 assigned characters in the Halfwidth and Fullwidth Forms block, out of 240 code points reserved for it (U+FF00 to U+FFEF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
