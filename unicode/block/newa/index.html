Newa: Unicode block U+11400 to U+1147F

97 characters you can look at, copy and paste. Data from Unicode 18.0.

The Newa block covers the code points U+11400 to U+1147F (128 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 97 of them so far, which are 60 other letters, 13 non-spacing marks, 10 decimal digits, 8 other punctuation marks, 6 spacing marks. Its characters were added between Unicode 9.0 and 13.0.

The characters belong to the script: Newa.

What the block contains

The Unicode code charts divide this block into groups: Independent vowels; Consonants; Dependent vowel signs; Various signs; Invocation signs; Punctuation; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Newa block?

Unicode 18.0 has 97 assigned characters in the Newa block, out of 128 code points reserved for it (U+11400 to U+1147F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 9.0.
