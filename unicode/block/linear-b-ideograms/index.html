Linear B Ideograms: Unicode block U+10080 to U+100FF

123 characters you can look at, copy and paste. Data from Unicode 18.0.

The Linear B Ideograms block covers the code points U+10080 to U+100FF (128 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 123 of them so far, which are 123 other letters. All its characters were added in Unicode 4.0.

The characters belong to the script: Linear B.

What the block contains

The Unicode code charts divide this block into groups: People and animals; Cereals and plants; Extracts; Metals; Other materials; Vessels.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Linear B Ideograms block?

Unicode 18.0 has 123 assigned characters in the Linear B Ideograms block, out of 128 code points reserved for it (U+10080 to U+100FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.0.
