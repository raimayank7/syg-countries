Masaram Gondi: Unicode block U+11D00 to U+11D5F

75 characters you can look at, copy and paste. Data from Unicode 18.0.

The Masaram Gondi block covers the code points U+11D00 to U+11D5F (96 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 75 of them so far, which are 48 other letters, 17 non-spacing marks, 10 decimal digits. All its characters were added in Unicode 10.0.

The characters belong to the script: Masaram Gondi.

What the block contains

The Unicode code charts divide this block into groups: Vowels; Consonants; Conjunct letters; Dependent vowel signs; Various signs; Virama; Cluster-specific consonant forms; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Masaram Gondi block?

Unicode 18.0 has 75 assigned characters in the Masaram Gondi block, out of 96 code points reserved for it (U+11D00 to U+11D5F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 10.0.
