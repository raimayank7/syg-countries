Kharoshthi: Unicode block U+10A00 to U+10A5F

68 characters you can look at, copy and paste. Data from Unicode 18.0.

The Kharoshthi block covers the code points U+10A00 to U+10A5F (96 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 68 of them so far, which are 37 other letters, 13 non-spacing marks, 9 other numbers, 9 other punctuation marks. Its characters were added between Unicode 4.1 and 11.0.

The characters belong to the script: Kharoshthi.

What the block contains

The Unicode code charts divide this block into groups: Vowels; Length mark; Various signs; Consonants; Virama; Digits; Numbers and fractions; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Kharoshthi block?

Unicode 18.0 has 68 assigned characters in the Kharoshthi block, out of 96 code points reserved for it (U+10A00 to U+10A5F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.1.
