Gothic: Unicode block U+10330 to U+1034F

27 characters you can look at, copy and paste. Data from Unicode 18.0.

The Gothic block covers the code points U+10330 to U+1034F (32 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 27 of them so far, which are 25 other letters, 2 letter-like numbers. All its characters were added in Unicode 3.1.

The characters belong to the script: Gothic.

What the block contains

The Unicode code charts divide this block into groups: Letters.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Gothic block?

Unicode 18.0 has 27 assigned characters in the Gothic block, out of 32 code points reserved for it (U+10330 to U+1034F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.1.
