Myanmar Extended-B: Unicode block U+A9E0 to U+A9FF

31 characters you can look at, copy and paste. Data from Unicode 18.0.

The Myanmar Extended-B block covers the code points U+A9E0 to U+A9FF (32 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 31 of them so far, which are 19 other letters, 10 decimal digits, 1 non-spacing mark, 1 modifier letter. All its characters were added in Unicode 7.0.

The characters belong to the script: Myanmar.

What the block contains

The Unicode code charts divide this block into groups: Additions for Shan Pali; Reduplication mark; Tai Laing consonants; Tai Laing digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Myanmar Extended-B block?

Unicode 18.0 has 31 assigned characters in the Myanmar Extended-B block, out of 32 code points reserved for it (U+A9E0 to U+A9FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 7.0.
