CJK Unified Ideographs Extension I: Unicode block U+2EBF0 to U+2EE5F

622 characters you can look at, copy and paste. Data from Unicode 18.0.

The CJK Unified Ideographs Extension I block covers the code points U+2EBF0 to U+2EE5F (624 positions) in the Supplementary Ideographic Plane (plane 2). Unicode has assigned 622 of them so far, which are 622 other letters. All its characters were added in Unicode 15.1.

Common questions

How many characters are in the CJK Unified Ideographs Extension I block?

Unicode 18.0 has 622 assigned characters in the CJK Unified Ideographs Extension I block, out of 624 code points reserved for it (U+2EBF0 to U+2EE5F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 15.1.
