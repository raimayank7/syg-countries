Ancient Greek Numbers: Unicode block U+10140 to U+1018F

79 characters you can look at, copy and paste. Data from Unicode 18.0.

The Ancient Greek Numbers block covers the code points U+10140 to U+1018F (80 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 79 of them so far, which are 53 letter-like numbers, 20 other symbols, 6 other numbers. Its characters were added between Unicode 4.1 and 9.0.

The characters belong to the script: Greek.

What the block contains

The Unicode code charts divide this block into groups: Ancient Greek acrophonic numerals; Ancient Greek papyrological numbers; Ancient Greek symbols.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Ancient Greek Numbers block?

Unicode 18.0 has 79 assigned characters in the Ancient Greek Numbers block, out of 80 code points reserved for it (U+10140 to U+1018F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 4.1.
