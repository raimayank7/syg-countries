Miscellaneous Technical: Unicode block U+2300 to U+23FF

256 characters you can look at, copy and paste. Data from Unicode 18.0.

The Miscellaneous Technical block covers the code points U+2300 to U+23FF (256 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 256 of them so far, which are 216 other symbols, 34 math symbols, 3 opening brackets, 3 closing brackets. Its characters were added between Unicode 1.1 and 10.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Miscellaneous technical; Ceilings and floors; Crops; User interface symbols; Quine corners; Integral pieces; Frown and smile; Keyboard symbols; Deprecated angle brackets; Keyboard symbol; Chemistry symbol; Drafting symbols; APL; Graphics for control codes and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

138 of the 256 named characters have their own page.

Common questions

How many characters are in the Miscellaneous Technical block?

Unicode 18.0 has 256 assigned characters in the Miscellaneous Technical block, out of 256 code points reserved for it (U+2300 to U+23FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
