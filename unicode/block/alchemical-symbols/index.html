Alchemical Symbols: Unicode block U+1F700 to U+1F77F

128 characters you can look at, copy and paste. Data from Unicode 18.0.

The Alchemical Symbols block covers the code points U+1F700 to U+1F77F (128 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 128 of them so far, which are 128 other symbols. Its characters were added between Unicode 6.0 and 17.0.

The characters belong to the script: Common.

What the block contains

The Unicode code charts divide this block into groups: Symbols for Aristotelian elements; Symbols for important solvents; Symbols for sulfur and mercury; Symbols for salt, vitriol, and nitre; Symbols for gold and silver; Symbols for iron, iron ore and derivatives; Symbols for copper, copper ore and derivatives; Symbols for tin and lead ore; Symbols for antimony, antimony ore and derivatives; Symbols for other substances; Composition; Processes; Apparatus; Time and more.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Alchemical Symbols block?

Unicode 18.0 has 128 assigned characters in the Alchemical Symbols block, out of 128 code points reserved for it (U+1F700 to U+1F77F).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 6.0.
