Makasar: Unicode block U+11EE0 to U+11EFF

25 characters you can look at, copy and paste. Data from Unicode 18.0.

The Makasar block covers the code points U+11EE0 to U+11EFF (32 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 25 of them so far, which are 19 other letters, 2 non-spacing marks, 2 spacing marks, 2 other punctuation marks. All its characters were added in Unicode 11.0.

The characters belong to the script: Makasar.

What the block contains

The Unicode code charts divide this block into groups: Consonants; Consonant reduplicator; Vowel signs; Punctuation.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Makasar block?

Unicode 18.0 has 25 assigned characters in the Makasar block, out of 32 code points reserved for it (U+11EE0 to U+11EFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 11.0.
