Arabic Presentation Forms-B: Unicode block U+FE70 to U+FEFF

141 characters you can look at, copy and paste. Data from Unicode 18.0.

The Arabic Presentation Forms-B block covers the code points U+FE70 to U+FEFF (144 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 141 of them so far, which are 140 other letters, 1 format character. Its characters were added between Unicode 1.1 and 3.2.

The characters belong to these scripts: Arabic, Common.

What the block contains

The Unicode code charts divide this block into groups: Glyphs for spacing forms of Arabic points; Glyph part; Basic glyphs for Arabic language contextual forms; Special.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Arabic Presentation Forms-B block?

Unicode 18.0 has 141 assigned characters in the Arabic Presentation Forms-B block, out of 144 code points reserved for it (U+FE70 to U+FEFF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.
