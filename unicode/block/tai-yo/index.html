Tai Yo: Unicode block U+1E6C0 to U+1E6FF

55 characters you can look at, copy and paste. Data from Unicode 18.0.

The Tai Yo block covers the code points U+1E6C0 to U+1E6FF (64 positions) in the Supplementary Multilingual Plane (plane 1). Unicode has assigned 55 of them so far, which are 49 other letters, 5 non-spacing marks, 1 modifier letter. All its characters were added in Unicode 17.0.

The characters belong to the script: Tai Yo.

What the block contains

The Unicode code charts divide this block into groups: Letters; Vowel letters and rhyme signs; Finals; Symbols.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Tai Yo block?

Unicode 18.0 has 55 assigned characters in the Tai Yo block, out of 64 code points reserved for it (U+1E6C0 to U+1E6FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 17.0.
