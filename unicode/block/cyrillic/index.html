Cyrillic: Unicode block U+0400 to U+04FF

256 characters you can look at, copy and paste. Data from Unicode 18.0.

The Cyrillic block covers the code points U+0400 to U+04FF (256 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 256 of them so far, which are 124 uppercase letters, 124 lowercase letters, 5 non-spacing marks, 2 enclosing marks, 1 symbol (other). Its characters were added between Unicode 1.1 and 5.1.

The characters belong to these scripts: Cyrillic, Inherited.

What the block contains

The Unicode code charts divide this block into groups: Cyrillic extensions; Basic Russian alphabet; Historic letters; Historic digraphs; Historic miscellaneous; Extended Cyrillic; Additions for Nivkh.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

255 of the 256 named characters have their own page.

Common questions

How many characters are in the Cyrillic block?

Unicode 18.0 has 256 assigned characters in the Cyrillic block, out of 256 code points reserved for it (U+0400 to U+04FF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 1.1.
