Mongolian: Unicode block U+1800 to U+18AF

158 characters you can look at, copy and paste. Data from Unicode 18.0.

The Mongolian block covers the code points U+1800 to U+18AF (176 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 158 of them so far, which are 128 other letters, 10 other punctuation marks, 10 decimal digits, 7 non-spacing marks, 1 dash. Its characters were added between Unicode 3.0 and 14.0.

The characters belong to these scripts: Common, Mongolian.

What the block contains

The Unicode code charts divide this block into groups: Punctuation; Format controls; Digits; Basic letters; Todo letters; Sibe letters; Manchu letters; Buryat letter; Extensions for Sanskrit and Tibetan.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Mongolian block?

Unicode 18.0 has 158 assigned characters in the Mongolian block, out of 176 code points reserved for it (U+1800 to U+18AF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 3.0.
