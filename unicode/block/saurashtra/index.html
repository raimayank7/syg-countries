Saurashtra: Unicode block U+A880 to U+A8DF

82 characters you can look at, copy and paste. Data from Unicode 18.0.

The Saurashtra block covers the code points U+A880 to U+A8DF (96 positions) in the Basic Multilingual Plane (plane 0). Unicode has assigned 82 of them so far, which are 50 other letters, 18 spacing marks, 10 decimal digits, 2 non-spacing marks, 2 other punctuation marks. Its characters were added between Unicode 5.1 and 9.0.

The characters belong to the script: Saurashtra.

What the block contains

The Unicode code charts divide this block into groups: Various signs; Independent vowels; Consonants; Dependent vowel signs; Virama; Sign; Punctuation; Digits.

Each name below links to a page with the character's codes, how to type it and where it is used, where such a page exists. The copy button puts the character itself on your clipboard.

Common questions

How many characters are in the Saurashtra block?

Unicode 18.0 has 82 assigned characters in the Saurashtra block, out of 96 code points reserved for it (U+A880 to U+A8DF).

Can I copy these characters?

Yes. Press Copy in the row of the character you want. Whether it appears correctly depends on the fonts of the app or device that shows it: a missing font draws an empty box.

Which Unicode version is this?

The data is from the Unicode Character Database 18.0. The first characters of this block date from Unicode 5.1.
