Storm event types

48 event types appear in the database from 1996 to 2025, sorted by the number of reports. Pick one for the states with most reports and the year-by-year counts.

The event type is the category assigned to each report in the database, such as hail, thunderstorm wind, flash flood or tornado. The list mixes very common types with rare ones, and some types appear in the file only from a later year, so counts of two types are only comparable when both were recorded for the whole period. Reports describe what was observed and entered, which depends on where people and spotters are as well as on the weather.
