How an LEI is built

An LEI has 20 characters, letters A to Z and digits 0 to 9, in three parts:

  • Characters 1 to 4: a prefix that identifies the Local Operating Unit that first issued the code.
  • Characters 5 to 18: the entity-specific part, 14 characters that make the code unique.
  • Characters 19 and 20: two check digits.

The code reveals nothing about the company. It does not contain the name or the country, and it is never reused for another entity.

The check digits

The check digits catch typing mistakes. They are worked out so that the whole code passes a test called MOD 97-10, the same as for IBANs (ISO 7064). The test is:

  1. Replace each letter by two digits: A is 10, B is 11 and so on to Z, which is 35. Digits stay as they are.
  2. Read the resulting digits as one very large number.
  3. Divide it by 97. A valid LEI leaves a remainder of exactly 1.

Worked example

Take the LEI 335800ZFUZ3FBKQASV25, which the GLEIF service lists for an entity registered in India. Turning the letters into numbers gives 3358003515303531511202610283125. Dividing this number by 97 leaves a remainder of 1, so the check digits are correct. If you change any one character, the remainder is almost certainly no longer 1.

The checker on the home page does this sum for you before it asks GLEIF about the code. A code that passes only shows that it is written correctly; it does not show that the LEI was ever issued.
