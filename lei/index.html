LEI checker and company look-up

Paste a 20-character LEI to check it and see the entity, or type a company name to find its LEI.

What is sent, and to whom: the LEI or company name you type is sent from your browser to the GLEIF server (api.gleif.org) to get the answer. It does not pass through us; we do not receive it and we do not store it. GLEIF sees it, together with your IP address, and handles it under its own privacy policy. The test of the check digits happens in your browser alone.

What this does

The Legal Entity Identifier (LEI) is a global code for legal entities in financial markets. This page does two jobs. First it checks that a code is written correctly, using the check-digit rule of ISO 17442, which catches a mistyped character before you rely on the code. Second it looks the code up in the Global LEI Index, kept by GLEIF, and shows the legal name, address, status and renewal date, or searches by name when you type words.

Not sure what an LEI is? Read what an LEI is and how it is built. A correct code is not proof that a company is sound; see the status guide for what to look at.

Common questions

What is an LEI?

A 20-character code that identifies a legal entity, used in financial markets (ISO 17442).

How do I check an LEI?

Paste it in the box above. The page checks the two check digits and then looks the code up in the GLEIF index.

Is the look-up free?

Yes. GLEIF provides the data free of charge under CC0 and this site asks its API from your browser.
