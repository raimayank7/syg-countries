.中信 is a generic top-level domain (gTLD) run by CITIC Group Corporation, based in China. Unlike a country-code extension it is not tied to a country, so a name under it says nothing about where its owner lives. It was delegated on 2014-01-18.

The extension is an internationalised domain name: people type it as .中信, and the computers that route it use the ASCII form xn--fiq64b. See IDN and punycode for how the two forms are related.

Who runs .中信

The registry (the manager that IANA lists for it) is CITIC Group Corporation. It also runs .citic.

How to look up a .中信 domain

Registration data for a domain under .中信 is published by its registry. The WHOIS server is whois.gtld.zdns.cn; from a command line, whois -h whois.gtld.zdns.cn example.中信 asks it about a name. The RDAP service (the newer, structured replacement for WHOIS) has the base address https://rdap.zdnsgtld.com/xn--fiq64b; add domain/example.中信 to it to ask about one name. Many registries hide the personal details of the registrant of a name, so a lookup may show only the registrar, the dates and the status. See WHOIS and RDAP for how to read the answer.

Name servers and DNSSEC

IANA lists 8 name servers for .中信, 2 of them reachable over IPv6 as well as IPv4. The extension is signed with DNSSEC: IANA holds 1 DS record for it, using RSA/SHA-256. A signed extension lets a resolver check that an answer for a domain under it was not changed on the way. See the guide to DNSSEC and DS records.

Should you use .中信?

A generic extension carries no country signal, so it neither helps nor hurts a site in one particular country. The choice is mostly about how the name reads and how much trust visitors give it. Check the registry's rules before you pick one: some generic extensions are open to anyone, some are for members of a profession or community, and some are run by a company for its own brand and cannot be registered at all.

Common questions

How can I look up who a .中信 domain is registered to?
