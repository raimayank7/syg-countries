.بازار is a generic top-level domain (gTLD) run by CORE Association, based in Switzerland. Unlike a country-code extension it is not tied to a country, so a name under it says nothing about where its owner lives. It was delegated on 2014-02-18.

The extension is an internationalised domain name: people type it as .بازار, and the computers that route it use the ASCII form xn--mgbab2bd. See IDN and punycode for how the two forms are related.

Who runs .بازار

The registry (the manager that IANA lists for it) is CORE Association. It also runs .онлайн, .сайт. Its website is corenic.org; that is the place to read the rules for who may register a name, which documents are needed and what the extension costs through each registrar.

How to look up a .بازار domain

Registration data for a domain under .بازار is published by its registry. The WHOIS server is whois.nic.xn--mgbab2bd; from a command line, whois -h whois.nic.xn--mgbab2bd example.بازار asks it about a name. The RDAP service (the newer, structured replacement for WHOIS) has the base address https://rdap.nic.xn--mgbab2bd/; add domain/example.بازار to it to ask about one name. Many registries hide the personal details of the registrant of a name, so a lookup may show only the registrar, the dates and the status. See WHOIS and RDAP for how to read the answer.

Name servers and DNSSEC

IANA lists 4 name servers for .بازار, all reachable over IPv6 as well as IPv4. The extension is signed with DNSSEC: IANA holds 1 DS record for it, using RSA/SHA-512. A signed extension lets a resolver check that an answer for a domain under it was not changed on the way. See the guide to DNSSEC and DS records.

Should you use .بازار?

A generic extension carries no country signal, so it neither helps nor hurts a site in one particular country. The choice is mostly about how the name reads and how much trust visitors give it. Check the registry's rules on the website linked above before you pick one: some generic extensions are open to anyone, some are for members of a profession or community, and some are run by a company for its own brand and cannot be registered at all.

Common questions

Who runs .بازار?

.بازار is run by CORE Association, based in Switzerland.

Is .بازار a country-code extension?

No. .بازار is a generic top-level domain (gTLD), not tied to a country.

How can I look up who a .بازار domain is registered to?

Ask the WHOIS server whois.nic.xn--mgbab2bd or the RDAP service https://rdap.nic.xn--mgbab2bd/. Personal details are often hidden.

Does .بازار support DNSSEC?

Yes. The root zone holds a DS record for .بازار, so a resolver that validates DNSSEC can check names under it.
