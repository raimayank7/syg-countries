.مصر is a country-code top-level domain (ccTLD). It is written in the Arabic script (its internal form is xn--wgbh1c) and serves Egypt. It is run by National Telecommunication Regulatory Authority - NTRA, based in Egypt. It was delegated to this manager on 2010-05-05.

The extension is an internationalised domain name: people type it as .مصر, and the computers that route it use the ASCII form xn--wgbh1c. See IDN and punycode for how the two forms are related.

Who runs .مصر

The registry (the manager that IANA lists for it) is National Telecommunication Regulatory Authority - NTRA.

Name servers and DNSSEC

IANA lists 4 name servers for .مصر, all reachable over IPv4 only. The extension is signed with DNSSEC: IANA holds 2 DS records for it, using ECDSA P-256/SHA-256. A signed extension lets a resolver check that an answer for a domain under it was not changed on the way. See the guide to DNSSEC and DS records.

Should you use .مصر?

A country-code extension is a strong signal of the country it belongs to. Google says that country-code extensions are tied to a specific country and so tell search engines that a site is meant for it, while it treats a few vanity ones (such as .tv and .me) as generic. Registries differ in who may register: some are open to anyone, others require a local presence, a local company or documents. Read the rules on the registry's website before you choose a name you cannot use.
