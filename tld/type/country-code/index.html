Country-code domain extensions (ccTLDs)

313 listed.

A country-code extension (ccTLD) is a TLD assigned to a country or territory: .in for India, .uk for the United Kingdom, .de for Germany. Most use the two letters of the international country-code list (ISO 3166), and a few international ones are written in the local script. Each is run by a registry that sets its own rules. Some accept anyone in the world; others ask for a local address or business. Because search engines use them as a country signal, they are the natural choice for a site that serves one country.

There are 309 active country-code extensions; 61 are written in a non-Latin script. The registries are listed with their organisation names as IANA records them.
