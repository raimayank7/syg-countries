How to check if a port is open

"Is the port open?" can mean two things: is a program on this computer listening on it, or can another computer reach it across the network? They are checked differently.

1. What is listening on my computer

  • Windows: in a command window, netstat -ano lists connections and the process id of each; look for LISTENING lines. tasklist tells which program has that id.
  • Linux: ss -tulpn shows TCP and UDP listeners and the program names (use sudo to see all).
  • Mac: lsof -iTCP -sTCP:LISTEN -n -P.

2. Can another computer connect?

  • Windows PowerShell: Test-NetConnection example.com -Port 443 shows TcpTestSucceeded: True or False.
  • Linux and Mac: nc -zv example.com 443 reports "succeeded" or "refused".

Reading the result

Connection succeeded: something is listening and the path is open. Connection refused: the machine answered, but nothing listens on that port. Timed out: no answer, usually because a firewall or router drops the packets, or the machine is off. UDP is harder: a UDP service often does not answer a probe, so silence does not prove the port is closed.

Test your own home or office from outside

A test from inside your network can succeed even if the router blocks the port from the outside. To test from outside, run the command from another network, such as a mobile hotspot. Only test systems you own or have permission to test: scanning other people's systems can be against the rules of your internet provider and the law.
