What is a network port?

An IP address gets a packet of data to the right computer. A port number gets it to the right program on that computer. It is a number from 0 to 65535 written after the address, as in 192.0.2.10:443. A web server listens on port 443 for secure connections; a mail server on 25; a database on its own number. One computer can run many services at once because each uses a different port.

The three ranges

  • 0 to 1023, well-known ports: the main internet services. 697 of these numbers have a registry entry.
  • 1024 to 49151, registered ports: services registered by vendors and projects; 5,428 numbers have an entry.
  • 49152 to 65535, dynamic ports: not registered; used for the temporary source ports that your computer picks for each outgoing connection. 0 numbers carry an entry.

Your side of a connection

When your browser connects to a site, it connects to port 443 on the server, and your own computer uses a temporary high port as the other end. That is why a firewall that allows replies is needed to let traffic flow in a connection that you started.
