What is this port for? Port numbers explained

Type a port number or a service name, such as 443 or ssh, to see what it is registered for and what it is used for.

The most asked-about ports

PortNameUsed for
20ftp-dataFTP uses two connections.
21ftpThe control port of FTP, the old File Transfer Protocol.
22sshSecure Shell.
25smtpThe port on which mail servers pass email to each other with SMTP.
53domainThe Domain Name System turns names such as example.
80http, www, www-httpHTTP, the protocol of the web in its plain, unencrypted form.
110pop3POP3, the Post Office Protocol: a mail program downloads messages from the server, usually removing them from the server afterwards.
143imapIMAP, the Internet Message Access Protocol: a mail program reads and manages messages that stay on the server, so several devices see the same mailbox.
443httpsHTTPS: the web protocol over TLS, so that the connection between browser and site is encrypted.
445microsoft-dsSMB over TCP (listed by IANA as Microsoft-DS): Windows file and printer sharing, and the same protocol on Samba servers and many devices.
587submissionMessage submission: mail programs send outgoing email to their server here, normally after logging in and switching to encrypted mode with STARTTLS.
993imapsIMAP over TLS: the encrypted version of IMAP, where the connection is encrypted from the start.
3306mysqlMySQL (and MariaDB) listen here by default.
3389ms-wbt-serverThe Remote Desktop Protocol of Windows (IANA: MS WBT Server): it shows and controls a Windows desktop from another computer.
5432postgresqlPostgreSQL listens here by default.
8080http-altAn alternative port for HTTP, used by proxies, test servers and web tools that cannot or should not use port 80.

The official list of ports is kept by IANA. This site turns it into pages you can read: the registered name and protocols, who registered the port, and for 62 well-known ports a plain note on what the service does and what to watch. If you are new to the subject, start with what a port is; to look at your own computer or router, read how to check if a port is open.

Data: IANA registry, November 2026. Independent site, not connected with IANA.
