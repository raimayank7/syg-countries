How to use this page

The groups sort the best-known ports by what they are for, such as email, web, remote access, databases and directory services. Pick the group that matches the service you are asking about, and open a port from its table for the name the IANA registry uses, who registered it, how to check whether it is open on your own machine and what to watch. A port number alone does not tell you what is running on it: a program can use any port, so treat the group as the usual use and check the program that is actually listening.
