Network services ports: 14 well-known port numbers

These are the best-known ports for the group "Network services". For each, the table gives the name the IANA registry uses and a plain description of what the service does. Open a port for its registrant, how to check it and what to watch. Ports that carry passwords or private data in plain text have an encrypted twin in most cases, mentioned in the notes. The notes are general good practice, not an assessment of any system. In general: run only the services you need, keep them up to date, keep databases, file sharing and remote administration off the public internet, and prefer the encrypted version of a service when there is one.

PortNameUsed for
53domainThe Domain Name System turns names such as example.com into addresses. Queries usually use UDP; TCP is used for large answers and for copying zones between servers.
67bootpsThe server side of DHCP (and BOOTP): the service that hands out IP addresses and settings to devices when they join a local network.
68bootpcThe client side of DHCP: a device listens here for the address and settings that the DHCP server on port 67 offers.
111sunrpcThe "portmapper" of Sun RPC: it tells a client which port a remote procedure service, such as NFS, is listening on.
119nntpNNTP, the Network News Transfer Protocol, which carries Usenet newsgroups between servers and to news readers.
123ntpThe Network Time Protocol keeps computer clocks in step with accurate time sources. It uses UDP.
135epmapThe Microsoft RPC endpoint mapper (listed by IANA as DCE endpoint resolution): Windows services ask it which port a given RPC service uses.
161snmpSNMP, the Simple Network Management Protocol, with which monitoring systems ask routers, switches and printers for their status. It uses UDP.
162snmptrapSNMP traps: devices send alerts to a monitoring system on this port when something happens.
179bgpBGP, the Border Gateway Protocol: routers of different networks use it to tell each other which addresses they can reach. It holds the routing of the Internet together.
514shell, syslogIANA lists two uses: UDP 514 for syslog, where devices send log messages to a log server, and TCP 514 for "shell" (rsh), an old remote command service.
515printerThe line printer daemon (LPD), an older way for computers to send print jobs to a network printer or print server.
631ipp, ippsIPP, the Internet Printing Protocol, used by CUPS on Linux and macOS and by modern network printers.
853domain-sDNS over TLS: a device sends its DNS questions to a resolver inside an encrypted connection, so that others on the path cannot read them.

Data: IANA Service Name and Transport Protocol Port Number Registry, read November 2026. Notes on well-known ports are our own. Independent site, not connected with IANA.
