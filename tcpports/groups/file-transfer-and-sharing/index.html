File transfer and sharing ports: 10 well-known port numbers

These are the best-known ports for the group "File transfer and sharing". For each, the table gives the name the IANA registry uses and a plain description of what the service does. Open a port for its registrant, how to check it and what to watch. Ports that carry passwords or private data in plain text have an encrypted twin in most cases, mentioned in the notes. The notes are general good practice, not an assessment of any system. In general: run only the services you need, keep them up to date, keep databases, file sharing and remote administration off the public internet, and prefer the encrypted version of a service when there is one.

The file transfer and sharing ports in numbers

The group has 10 ports with notes here, listed from 20 to 2049. By range, 9 in the 0-1023 range, 1 in the 2000-2999 range. The IANA registry holds 25 entries for them, split by transport protocol as TCP 11, UDP 11, SCTP 3. The numbers are taken from the registry file and describe registrations: a port in this group can be used by other programs, and a service can run on a port other than its registered one.

PortNameUsed for
20ftp-dataFTP uses two connections. Commands go to port 21; in the usual "active" mode the server opens the data connection from port 20 back to the client.
21ftpThe control port of FTP, the old File Transfer Protocol. Clients connect here, log in, and give commands to list, upload and download files.
69tftpTrivial File Transfer Protocol, a very small file transfer protocol with no login, used for network booting and loading firmware onto devices.
137netbios-nsNetBIOS name service: the way older Windows networks announced and looked up computer names, before DNS took over that job.
138netbios-dgmNetBIOS datagram service: connectionless messages of old Windows networks, such as browsing for shared computers.
139netbios-ssnNetBIOS session service: the older way for Windows file and printer sharing to run, before it moved to port 445.
445microsoft-dsSMB over TCP (listed by IANA as Microsoft-DS): Windows file and printer sharing, and the same protocol on Samba servers and many devices.
548afpovertcpAFP over TCP, the Apple Filing Protocol used for file sharing between Macs in older versions of macOS.
873rsyncrsync, a program and protocol for copying and synchronising files efficiently by sending only the differences.
2049shilp, nfsNFS, the Network File System, with which Unix and Linux computers use folders on another machine as if they were local.

Data: IANA Service Name and Transport Protocol Port Number Registry, read November 2026. Notes on well-known ports are our own. Independent site, not connected with IANA.
