Calls and chat ports: 2 well-known port numbers

These are the best-known ports for the group "Calls and chat". For each, the table gives the name the IANA registry uses and a plain description of what the service does. Open a port for its registrant, how to check it and what to watch. Ports that carry passwords or private data in plain text have an encrypted twin in most cases, mentioned in the notes. The notes are general good practice, not an assessment of any system. In general: run only the services you need, keep them up to date, keep databases, file sharing and remote administration off the public internet, and prefer the encrypted version of a service when there is one.

PortNameUsed for
5060sipSIP, the Session Initiation Protocol, which sets up voice and video calls on internet telephony systems. The encrypted version uses 5061.
5222xmpp-clientXMPP client connections: chat programs connect here to an XMPP (Jabber) server. Server-to-server traffic uses 5269.

Data: IANA Service Name and Transport Protocol Port Number Registry, read November 2026. Notes on well-known ports are our own. Independent site, not connected with IANA.
