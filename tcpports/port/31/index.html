Port 31: msg-auth

31
Service name
msg-auth
Protocols
TCP/UDP
Description
MSG Authentication

Port 31 is registered with IANA for the service name msg-auth over TCP and UDP. The registry describes it as "MSG Authentication".

How to check port 31

To see whether something on your own computer is listening: on Windows run netstat -ano in a command window and look for :31; on Linux run ss -tulpn; on a Mac run lsof -iTCP -sTCP:LISTEN -n -P. To test whether a server accepts connections on it: in Windows PowerShell, Test-NetConnection example.com -Port 31; on Linux or Mac, nc -zv example.com 31. A refused or timed-out connection means nothing answered on that port, or a firewall dropped the connection. Test only your own systems or ones you have permission to test.

Common questions

What is port 31 used for?

The IANA registry lists it for msg-auth: MSG Authentication.

Is port 31 TCP or UDP?

The registry has entries for TCP, UDP.

Should I open port 31 on my router?

Only if you run the service on purpose and need people outside to reach it. Open the smallest set of ports, to the machine that needs it, and keep the software updated.
