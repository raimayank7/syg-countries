Port 68: bootpc

68
Service name
bootpc
Protocols
TCP/UDP
Description
Bootstrap Protocol Client

Port 68 is registered with IANA for the service name bootpc over TCP and UDP. The registry describes it as "Bootstrap Protocol Client".

What port 68 is used for

The client side of DHCP: a device listens here for the address and settings that the DHCP server on port 67 offers.

What to watch

Local network traffic only; there is no reason to allow it in from the internet. Closing every port that you do not need is the most reliable protection: if you do not run the service, nothing should be listening here, and a firewall should not let connections in from outside.

How to check port 68

To see whether something on your own computer is listening: on Windows run netstat -ano in a command window and look for :68; on Linux run ss -tulpn; on a Mac run lsof -iTCP -sTCP:LISTEN -n -P. To test whether a server accepts connections on it: in Windows PowerShell, Test-NetConnection example.com -Port 68; on Linux or Mac, nc -zv example.com 68. A refused or timed-out connection means nothing answered on that port, or a firewall dropped the connection. Test only your own systems or ones you have permission to test.

Common questions

What is port 68 used for?

The client side of DHCP: a device listens here for the address and settings that the DHCP server on port 67 offers.

Is port 68 TCP or UDP?

The registry has entries for TCP, UDP.

Should I open port 68 on my router?

Only if you run the service on purpose and need people outside to reach it. Open the smallest set of ports, to the machine that needs it, and keep the software updated. Local network traffic only; there is no reason to allow it in from the internet.
