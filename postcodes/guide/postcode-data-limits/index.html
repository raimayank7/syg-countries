About our postal code data: limits

The codes on this site come from GeoNames, a community-built geographic database that collects postal code data from national postal services where licences allow it. Understanding its limits helps you use it well.

Countries with partial codes

  • GeoNames holds only the first digits of the full Chilean postal codes (for copyright reasons).
  • GeoNames holds only the first digits of the full Chinese postal codes (those ending in 00).
  • GeoNames holds only the first letters of the full Irish postal codes (the routing key), for copyright reasons.
  • GeoNames holds only the first letters of the full Maltese postal codes, for copyright reasons.
  • The Argentine file holds the first five positions of the postal code.
  • For Brazil only major postal codes are held: those ending in -000 and the main code of each municipality.
  • For Canada the data holds only the first part of the code (the forward sortation area, three characters).
  • For the Netherlands the data holds only the four digits, not the two letters that follow.
  • For the United Kingdom the data holds only the first part of the code (the outward code).

Positions and names

Map positions are estimates; for many countries they were derived by matching the place name with the GeoNames gazetteer and the numeric neighbourhood of codes. Place names are as GeoNames holds them, often in the local language and sometimes transliterated.

Gaps and age

Postal systems change codes when they reorganise; the data set is not updated every day. A code listed here can be out of date, and a new one may be missing. For anything important, confirm with the postal service.

The United States and India

For ZIP codes see the ZIP code site, which uses a US government shape file for areas; for India see PIN codes.
