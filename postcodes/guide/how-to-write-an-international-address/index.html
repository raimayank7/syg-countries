How to write an address for international mail

Mail that goes abroad passes through the sorting systems of several countries. A few habits make the difference between a letter that arrives and one that is sent back.

The basic rules

  1. Write the destination country last, on a line of its own, clearly and in full. Most postal services ask for it in capital letters; writing it in English or in the language of the country you are sending from helps the sorters on the way.
  2. Follow the local order for the lines above it. In some countries the postal code comes before the town (for example, "3750-011 Alcafaz"), in others after it. Copy the address as the recipient gave it, line by line.
  3. Use the postal code in the local format: look the country up on this site to see how it is written (digits, letters, spaces or a hyphen), and copy the exact pattern.
  4. Keep it plain. Do not add decorations or put the postal code in a different order than the recipient does. Write the name of the recipient on the first line and keep a blank margin around the address on a parcel.
  5. Write the sender's address too, on the back or in the corner, so the item can be returned.

Find the postal code format

Open the formats page or the page of the country. The formats shown are as GeoNames records them; if you are unsure, ask the recipient to send their address as it appears on their own mail.

Before you send

For parcels, customs forms and rules differ by country, and so does what you may send. Ask your own postal service for the current rules; this site does not give postal or customs advice.
