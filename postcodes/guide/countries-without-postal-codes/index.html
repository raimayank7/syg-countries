Countries without postal codes

Not every country has a postal code. In the GeoNames country list, 51 of 252 countries and territories have no postal code format recorded. They are: Afghanistan, Angola, Antarctica, Antigua and Barbuda, Aruba, Bahamas, Belize, Benin, Bolivia, Bonaire, Saint Eustatius and Saba , Botswana, Bouvet Island, Burkina Faso, Burundi, Cameroon, Central African Republic, Chad, Comoros, Cook Islands, Curacao, Dominica, Equatorial Guinea, Eritrea, Fiji, Gambia, Grenada, Ivory Coast, Jamaica, Libya, Mali, Mauritania, Netherlands Antilles, Qatar, Republic of the Congo, Rwanda, Sao Tome and Principe, Seychelles, Sierra Leone, Sint Maarten, Solomon Islands, South Sudan, Suriname, Syria, Togo, Tokelau, Tonga, Tuvalu, United States Minor Outlying Islands, Vanuatu, Yemen, Zimbabwe.

Why some have none

Postal codes are most useful where mail is delivered to street addresses in large volumes. In small countries with few addresses, or where mail is collected from post office boxes, the post office can sort by town name alone. Some have not introduced a system, some are introducing one slowly, and in some the system exists but covers only the capital or a few cities.

What to write instead

  • Write the full address as known locally: the person, the PO box or street, the town and the country.
  • If the address uses a PO box number, that number replaces the street.
  • Do not invent a code or write 00000 to satisfy an online form. If a form insists, check whether the country has a code at all; otherwise use the form's "no postal code" option if it has one, or the code of the nearest town that the postal service gives you.
  • Ask the person you are writing to for the exact form their post office uses.

The list changes: some of these countries are working on codes, and the data here is that of November 2026.
