Postal codes of Malawi: format, regions and look-up

491 codes in the GeoNames data set.

The postal code data set holds 491 codes for Malawi, covering 480 places in 3 regions. Real examples from the data: 209100 (Dedza Township), 209101 (Tambala), 209102 (Chauma).

A postal code in Malawi is written as ######: six digits. (In the format, # stands for a digit and @ for a letter.) A pattern that accepts it is ^(\d{6})$.

About Malawi in the data

GeoNames lists Malawi as a country in Africa, with Lilongwe as its capital, an area of 118,480 square kilometres and about 22,216,120 inhabitants. Its neighbours are Tanzania, Mozambique, Zambia. The data set holds 491 codes, which is 4.1 for each 1,000 square kilometres (population per code: about 45,247). A country with more codes per area usually has finer postal districts, so a code points to a smaller delivery area.
