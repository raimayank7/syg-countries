Postal codes of Mongolia: format, regions and look-up

354 codes in the GeoNames data set.

The postal code data set holds 354 codes for Mongolia, covering 277 places in 21 regions. Real examples from the data: 65230 (Horgo), 65190 (Tsetserleg), 65200 (Jargalant).

A postal code in Mongolia is written as #####: five digits. (In the format, # stands for a digit and @ for a letter.) A pattern that accepts it is ^(\d{5})$.

About Mongolia in the data

GeoNames lists Mongolia as a country in Asia, with Ulaanbaatar as its capital, an area of 1,565,000 square kilometres and about 3,568,978 inhabitants. Its neighbours are China, Russia. The data set holds 354 codes, which is 0.2 for each 1,000 square kilometres (population per code: about 10,082). A country with more codes per area usually has finer postal districts, so a code points to a smaller delivery area.
