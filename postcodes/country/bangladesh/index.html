Postal codes of Bangladesh: format, regions and look-up

1,349 codes in the GeoNames data set.

The postal code data set holds 1,349 codes for Bangladesh, covering 1,312 places in 7 regions. Real examples from the data: 1000 (Dhaka GPO), 1100 (Dhaka Sadar HO), 1203 (Wari TSO).

A postal code in Bangladesh is written as ####: four digits. (In the format, # stands for a digit and @ for a letter.) A pattern that accepts it is ^(\d{4})$.

About Bangladesh in the data

GeoNames lists Bangladesh as a country in Asia, with Dhaka as its capital, an area of 144,000 square kilometres and about 175,686,899 inhabitants. Its neighbours are Myanmar, India. The data set holds 1,349 codes, which is 9.4 for each 1,000 square kilometres (population per code: about 130,235). A country with more codes per area usually has finer postal districts, so a code points to a smaller delivery area.

Regions with the most codes

Dhaka Division (375 codes); Chittagong (336 codes); Khulna Division (167 codes); Rājshāhi Division (134 codes); Sylhet Division (128 codes); Barisal Division (115 codes); Rangpur Division (94 codes)
