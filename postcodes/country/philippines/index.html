Postal codes of Philippines: format, regions and look-up

2,190 codes in the GeoNames data set.

The postal code data set holds 2,190 codes for the Philippines, covering 2,055 places in 17 regions. Real examples from the data: 2900 (Laoag City), 2901 (San Nicolas), 2902 (Paoay).

A postal code in the Philippines is written as ####: four digits. (In the format, # stands for a digit and @ for a letter.) A pattern that accepts it is ^(\d{4})$.

About Philippines in the data

GeoNames lists Philippines as a country in Asia, with Manila as its capital, an area of 300,000 square kilometres and about 116,786,962 inhabitants. The data set holds 2,190 codes, which is 7.3 for each 1,000 square kilometres (population per code: about 53,327). A country with more codes per area usually has finer postal districts, so a code points to a smaller delivery area.

The data set holds 2,190 codes for Philippines. The number is that of the data set, which may not include every code in use.
