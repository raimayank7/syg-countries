Postal codes of French Guiana: format, regions and look-up

77 codes in the GeoNames data set.

The postal code data set holds 77 codes for French Guiana, covering 22 places in 1 regions. Real examples from the data: 97300 (Cayenne), 97305 CEDEX (Cayenne), 97306 CEDEX (Cayenne).

A postal code in French Guiana is written as #####: five digits. (In the format, # stands for a digit and @ for a letter.) A pattern that accepts it is ^((97|98)3\d{2})$.

About French Guiana in the data

GeoNames lists French Guiana as a country in South America, with Cayenne as its capital, an area of 91,000 square kilometres and about 195,506 inhabitants. Its neighbours are Suriname, Brazil. The data set holds 77 codes, which is 0.8 for each 1,000 square kilometres (population per code: about 2,539). A country with more codes per area usually has finer postal districts, so a code points to a smaller delivery area.
