Postal codes of Latvia: format, regions and look-up

697 codes in the GeoNames data set.

The postal code data set holds 697 codes for Latvia, covering 5,114 places in 44 regions. Real examples from the data: LV-5101 (Aizkraukles stacija), LV-5134 (Jaunjelgavas), LV-5111 (Daudzese).

A postal code in Latvia is written as LV-####: the fixed text "LV", then a hyphen, then four digits. (In the format, # stands for a digit and @ for a letter.) A pattern that accepts it is ^(?:LV)*(\d{4})$.

About Latvia in the data

GeoNames lists Latvia as a country in Europe, with Riga as its capital, an area of 64,589 square kilometres and about 1,847,785 inhabitants. Its neighbours are Lithuania, Estonia, Belarus, Russia. The data set holds 697 codes, which is 10.8 for each 1,000 square kilometres (population per code: about 2,651). A country with more codes per area usually has finer postal districts, so a code points to a smaller delivery area.

Common questions

What does a postal code of Latvia look like?

It is written the fixed text "LV", then a hyphen, then four digits, for example LV-4141.

How many postal codes does Latvia have?

The data set holds 697 codes for Latvia. The number is that of the data set, which may not include every code in use.
