Postal codes of Australia: format, regions and look-up

3,170 codes in the GeoNames data set.

The postal code data set holds 3,170 codes for Australia, covering 16,245 places in 8 regions. Real examples from the data: 2620 (Top Naas), 2540 (Jervis Bay), 2611 (Molonglo).

A postal code in Australia is written as ####: four digits. (In the format, # stands for a digit and @ for a letter.) A pattern that accepts it is ^(\d{4})$.

About Australia in the data

GeoNames lists Australia as a country in Oceania, with Canberra as its capital, an area of 7,686,850 square kilometres and about 27,614,411 inhabitants. The data set holds 3,170 codes, which is 0.4 for each 1,000 square kilometres (population per code: about 8,711). A country with more codes per area usually has finer postal districts, so a code points to a smaller delivery area.

Regions with the most codes

New South Wales (922 codes); Victoria (749 codes); Western Australia (503 codes); Queensland (461 codes); South Australia (350 codes); Tasmania (120 codes); Northern Territory (51 codes); Australian Capital Territory (30 codes)

Common questions

What does a postal code of Australia look like?

It is written four digits, for example 3808.

How many postal codes does Australia have?

The data set holds 3,170 codes for Australia. The number is that of the data set, which may not include every code in use.

How do I find the postal code of a place in Australia?
