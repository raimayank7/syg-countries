Postal codes of Algeria: format, regions and look-up

3,162 codes in the GeoNames data set.

The postal code data set holds 3,162 codes for Algeria, covering 14,043 places in 48 regions. Real examples from the data: 01000 (Ouled Ali), 01001 (Azzekour), 01002 (Adrar Sidi Med Belekbir).

A postal code in Algeria is written as #####: five digits. (In the format, # stands for a digit and @ for a letter.) A pattern that accepts it is ^(\d{5})$.

About Algeria in the data

GeoNames lists Algeria as a country in Africa, with Algiers as its capital, an area of 2,381,740 square kilometres and about 47,435,312 inhabitants. Its neighbours are Niger, Western Sahara, Libya, Mauritania, Tunisia, Morocco, Mali. The data set holds 3,162 codes, which is 1.3 for each 1,000 square kilometres (population per code: about 15,002). A country with more codes per area usually has finer postal districts, so a code points to a smaller delivery area.
