Postal codes of Lithuania: format, regions and look-up

2,023 codes in the GeoNames data set.

The postal code data set holds 2,023 codes for Lithuania, covering 15,191 places in 10 regions. Real examples from the data: 62001 (Alytus), 62014 (Alytus), 63001 (Alytus).

A postal code in Lithuania is written as LT-#####: the fixed text "LT", then a hyphen, then five digits. (In the format, # stands for a digit and @ for a letter.) A pattern that accepts it is ^(?:LT)*(\d{5})$.

About Lithuania in the data

GeoNames lists Lithuania as a country in Europe, with Vilnius as its capital, an area of 65,200 square kilometres and about 2,888,774 inhabitants. Its neighbours are Poland, Belarus, Russia, Latvia. The data set holds 2,023 codes, which is 31.0 for each 1,000 square kilometres (population per code: about 1,428). A country with more codes per area usually has finer postal districts, so a code points to a smaller delivery area.

Common questions

What does a postal code of Lithuania look like?

It is written the fixed text "LT", then a hyphen, then five digits, for example 09201.

How many postal codes does Lithuania have?

The data set holds 2,023 codes for Lithuania. The number is that of the data set, which may not include every code in use.
