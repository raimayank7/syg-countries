Postal codes of Colombia: format, regions and look-up

3,681 codes in the GeoNames data set.

The postal code data set holds 3,681 codes for Colombia, covering 1,051 places in 33 regions. Real examples from the data: 910001 (Leticia), 910007 (Leticia), 910008 (Leticia).

A postal code in Colombia is written as ######: six digits. (In the format, # stands for a digit and @ for a letter.) A pattern that accepts it is ^(\d{6})$.

About Colombia in the data

GeoNames lists Colombia as a country in South America, with Bogota as its capital, an area of 1,138,910 square kilometres and about 53,425,635 inhabitants. Its neighbours are Ecuador, Peru, Panama, Brazil, Venezuela. The data set holds 3,681 codes, which is 3.2 for each 1,000 square kilometres (population per code: about 14,514). A country with more codes per area usually has finer postal districts, so a code points to a smaller delivery area.
