Postal codes of Indonesia: format, regions and look-up

8,266 codes in the GeoNames data set.

The postal code data set holds 8,266 codes for Indonesia, covering 61,924 places in 34 regions. Real examples from the data: 23891 (Kuala Bakti), 23892 (Salur Lasengalu), 23893 (Lhok Dalam).

A postal code in Indonesia is written as #####: five digits. (In the format, # stands for a digit and @ for a letter.) A pattern that accepts it is ^(\d{5})$.

About Indonesia in the data

GeoNames lists Indonesia as a country in Asia, with Jakarta as its capital, an area of 1,919,440 square kilometres and about 285,721,236 inhabitants. Its neighbours are Papua New Guinea, Timor Leste, Malaysia. The data set holds 8,266 codes, which is 4.3 for each 1,000 square kilometres (population per code: about 34,566). A country with more codes per area usually has finer postal districts, so a code points to a smaller delivery area.

Common questions

What does a postal code of Indonesia look like?

It is written five digits, for example 55293.

How many postal codes does Indonesia have?

The data set holds 8,266 codes for Indonesia. The number is that of the data set, which may not include every code in use.
