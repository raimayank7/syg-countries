Postal codes of Paraguay: format, regions and look-up

2,887 codes in the GeoNames data set.

The postal code data set holds 2,887 codes for Paraguay, covering 5,060 places in 18 regions. Real examples from the data: 100101 (11 a 13 Acaray), 100102 (11 a 13 Acaray), 100103 (11 a 13 Acaray).

A postal code in Paraguay is written as ######: six digits. (In the format, # stands for a digit and @ for a letter.) A pattern that accepts it is ^(\d{6})$.

About Paraguay in the data

GeoNames lists Paraguay as a country in South America, with Asuncion as its capital, an area of 406,750 square kilometres and about 7,013,078 inhabitants. Its neighbours are Bolivia, Brazil, Argentina. The data set holds 2,887 codes, which is 7.1 for each 1,000 square kilometres (population per code: about 2,429). A country with more codes per area usually has finer postal districts, so a code points to a smaller delivery area.
