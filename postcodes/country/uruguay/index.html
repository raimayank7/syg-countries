Postal codes of Uruguay: format, regions and look-up

122 codes in the GeoNames data set.

The postal code data set holds 122 codes for Uruguay, covering 1,799 places in 19 regions. Real examples from the data: 40200 (Limite Contestado), 50200 (Sarandi De Yacuy), 55000 (Baltasar Brum).

A postal code in Uruguay is written as #####: five digits. (In the format, # stands for a digit and @ for a letter.) A pattern that accepts it is ^(\d{5})$.

About Uruguay in the data

GeoNames lists Uruguay as a country in South America, with Montevideo as its capital, an area of 176,220 square kilometres and about 3,384,688 inhabitants. Its neighbours are Brazil, Argentina. The data set holds 122 codes, which is 0.7 for each 1,000 square kilometres (population per code: about 27,743). A country with more codes per area usually has finer postal districts, so a code points to a smaller delivery area.
