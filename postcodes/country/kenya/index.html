Postal codes of Kenya: format, regions and look-up

877 codes in the GeoNames data set.

The postal code data set holds 877 codes for Kenya, covering 890 places in 47 regions. Real examples from the data: 00100 (Nairobi Gpo), 00101 (Jamia), 00102 (State Law Office-Sheria HSE).

A postal code in Kenya is written as #####: five digits. (In the format, # stands for a digit and @ for a letter.) A pattern that accepts it is ^(\d{5})$.

About Kenya in the data

GeoNames lists Kenya as a country in Africa, with Nairobi as its capital, an area of 582,650 square kilometres and about 57,532,493 inhabitants. Its neighbours are Ethiopia, Tanzania, South Sudan, Somalia, Uganda. The data set holds 877 codes, which is 1.5 for each 1,000 square kilometres (population per code: about 65,601). A country with more codes per area usually has finer postal districts, so a code points to a smaller delivery area.

What does a postal code of Kenya look like?

The data set holds 877 codes for Kenya. The number is that of the data set, which may not include every code in use.
