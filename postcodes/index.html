Format, regions and a look-up for 121 countries. For the United States use ZIP codes; for India, PIN codes.

What you will find here

The data covers 845,830 postal codes. Each country has a page that shows how its postal code is written (digits, letters, spaces), which regions have the most codes, and a look-up. Regions with enough codes have pages of their own, with the places and the range of codes. For countries that only publish the first part of the code (such as the United Kingdom or Canada), the page says so.

To understand postal codes, read what a postal code is or compare countries on the formats page. If you are writing to someone abroad, see how to write an international address.
