Postal codes of Mostaganem, Algeria

50 codes, 27000 to 27049.

The GeoNames data lists 50 postal codes in Mostaganem, Algeria, covering 387 named places. In code order they run from 27000 to 27049.

The places with the most codes are Bellevue (2), Kharouba Village (1), Douar Aizeb (1), Mostaganem Bordji Amar (1), Meziania (1), Mostaganem Rp (1). Postal codes in Algeria are written five digits.
