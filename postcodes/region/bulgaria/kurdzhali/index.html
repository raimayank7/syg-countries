Postal codes of Кърджали / Kurdzhali, Bulgaria

312 codes, 2786 to 9961.

The GeoNames data lists 312 postal codes in Кърджали / Kurdzhali, Bulgaria, covering 470 named places and 7 sub-areas. In code order they run from 2786 to 9961.

The places with the most codes are Дедино / Dedino (1), Червена скала / Chervena skala (1), Ардино / Ardino (1), Търна / Turna (1), Богатино / Bogatino (1), Главник / Glavnik (1). The sub-areas with most codes are Кърджали / Kurdzhali (118), Крумовград / Krumovgrad (79), Кирково / Kirkovo (73), Ардино / Ardino (52). Postal codes in Bulgaria are written four digits.

Taken together, the map positions of these codes lie between latitude 41.27 and 44.11 and longitude 22.63 and 27.15, around a centre at about 41.57, 25.39 (see it on OpenStreetMap). The positions are estimates, so use them to get your bearings, not for navigation.
