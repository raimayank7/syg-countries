Postal code formats compared: digits, letters and none at all

How 252 countries and territories write their postal codes, from the GeoNames country list.

Of the 252 places in the GeoNames list, 201 have a postal code format and 51 have none recorded. Among those with a format, 186 use digits only: 70 use five digits, 33 use four and 21 use six. The most common single shape is "#####", used by 70. The others mix digits and letters, add a space or a hyphen, or are written in two parts.

Use the table to compare. A country with no format may have no postal code system at all, or may use codes only in some areas; see countries without postal codes. In the pattern, # stands for a digit and @ for a letter.

How to use this page

The table groups countries by the pattern of their postal codes, such as five digits or a mix of letters and digits. This helps when you build or fill in an address form: the same pattern appears in many countries, and the pattern is more reliable than the length of the field. A pattern describes the shape of a valid code and does not prove that the code exists; for that you need the postal service's own lookup. Countries without a pattern in the list either have no postal codes or have codes that the source does not cover.
