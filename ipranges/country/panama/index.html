IP address ranges in Panama

2,188,800

IPv4 addresses first allocated to organisations in Panama.

The five regional registries list 2,188,800 IPv4 addresses (2.2 million) in 186 allocation records for Panama, which is 0.06% of all allocated IPv4 addresses and 0.05% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 72nd of 239 countries and regions by IPv4 addresses. It also holds 86 IPv6 allocation records.

With a population of about 4,571,189 (GeoNames) that is about 47.88 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

LACNIC listed 1,708,288 addresses (78.0%). RIPE NCC listed 477,440 addresses (21.8%). APNIC listed 2,560 addresses (0.1%). ARIN listed 512 addresses (0.0%).

Common questions

How many IP addresses does Panama have?

The registries list 2,188,800 IPv4 addresses in 186 allocation records for Panama and 86 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Panama?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
