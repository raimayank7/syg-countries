IP address ranges in Guatemala

654,848

IPv4 addresses first allocated to organisations in Guatemala.

The five regional registries list 654,848 IPv4 addresses (655 thousand) in 154 allocation records for Guatemala, which is 0.02% of all allocated IPv4 addresses and 0.02% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 104th of 239 countries and regions by IPv4 addresses. It also holds 83 IPv6 allocation records.

With a population of about 18,687,881 (GeoNames) that is about 3.50 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

LACNIC listed 654,848 addresses (100.0%).

Common questions

How many IP addresses does Guatemala have?

The registries list 654,848 IPv4 addresses in 154 allocation records for Guatemala and 83 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Guatemala?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
