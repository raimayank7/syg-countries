IP address ranges in Luxembourg

1,848,320

IPv4 addresses first allocated to organisations in Luxembourg.

The five regional registries list 1,848,320 IPv4 addresses (1.8 million) in 552 allocation records for Luxembourg, which is 0.05% of all allocated IPv4 addresses and 0.04% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 76th of 239 countries and regions by IPv4 addresses. It also holds 108 IPv6 allocation records.

With a population of about 686,970 (GeoNames) that is about 269.05 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 1,847,552 addresses (100.0%). APNIC listed 512 addresses (0.0%). ARIN listed 256 addresses (0.0%).

Common questions

How many IP addresses does Luxembourg have?

The registries list 1,848,320 IPv4 addresses in 552 allocation records for Luxembourg and 108 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Luxembourg?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
