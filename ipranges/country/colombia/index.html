IP address ranges in Colombia

17,523,712

IPv4 addresses first allocated to organisations in Colombia.

The five regional registries list 17,523,712 IPv4 addresses (17.5 million) in 651 allocation records for Colombia, which is 0.48% of all allocated IPv4 addresses and 0.41% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 26th of 239 countries and regions by IPv4 addresses. It also holds 765 IPv6 allocation records.

With a population of about 53,425,635 (GeoNames) that is about 32.80 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

LACNIC listed 17,519,616 addresses (100.0%). RIPE NCC listed 4,096 addresses (0.0%).

The largest single block

The largest block is 181.240.0.0/12 with 1,048,576 addresses, first allocated on 2012-12-03 by LACNIC.

Common questions

How many IP addresses does Colombia have?

The registries list 17,523,712 IPv4 addresses in 651 allocation records for Colombia and 765 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Colombia?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
