IP address ranges in Slovakia

2,684,928

IPv4 addresses first allocated to organisations in Slovakia.

The five regional registries list 2,684,928 IPv4 addresses (2.7 million) in 441 allocation records for Slovakia, which is 0.07% of all allocated IPv4 addresses and 0.06% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 66th of 239 countries and regions by IPv4 addresses. It also holds 151 IPv6 allocation records.

With a population of about 5,413,813 (GeoNames) that is about 49.59 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 2,684,928 addresses (100.0%).

The largest block is 78.98.0.0/15 with 131,072 addresses, first allocated on 2007-05-02 by RIPE NCC.

Common questions

How many IP addresses does Slovakia have?

The registries list 2,684,928 IPv4 addresses in 441 allocation records for Slovakia and 151 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Slovakia?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
