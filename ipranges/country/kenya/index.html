IP address ranges in Kenya

6,264,320

IPv4 addresses first allocated to organisations in Kenya.

The five regional registries list 6,264,320 IPv4 addresses (6.3 million) in 407 allocation records for Kenya, which is 0.17% of all allocated IPv4 addresses and 0.15% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 53rd of 239 countries and regions by IPv4 addresses. It also holds 182 IPv6 allocation records.

With a population of about 57,532,493 (GeoNames) that is about 10.89 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

AFRINIC listed 6,264,320 addresses (100.0%).

The largest block is 105.48.0.0/12 with 1,048,576 addresses, first allocated on 2014-01-30 by AFRINIC.

Common questions

How many IP addresses does Kenya have?

The registries list 6,264,320 IPv4 addresses in 407 allocation records for Kenya and 182 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Kenya?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
