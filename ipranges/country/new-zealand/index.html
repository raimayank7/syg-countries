IP address ranges in New Zealand

6,530,560

IPv4 addresses first allocated to organisations in New Zealand.

The five regional registries list 6,530,560 IPv4 addresses (6.5 million) in 1,463 allocation records for New Zealand, which is 0.18% of all allocated IPv4 addresses and 0.15% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 51st of 239 countries and regions by IPv4 addresses. It also holds 438 IPv6 allocation records.

With a population of about 5,324,700 (GeoNames) that is about 122.65 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

APNIC listed 6,523,648 addresses (99.9%). RIPE NCC listed 6,912 addresses (0.1%).

The largest single block

The largest block is 49.224.0.0/14 with 262,144 addresses, first allocated on 2010-11-24 by APNIC.

Common questions

How many IP addresses does New Zealand have?

The registries list 6,530,560 IPv4 addresses in 1,463 allocation records for New Zealand and 438 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for New Zealand?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
