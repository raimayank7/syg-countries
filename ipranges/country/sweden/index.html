IP address ranges in Sweden

31,433,504

IPv4 addresses first allocated to organisations in Sweden.

The five regional registries list 31,433,504 IPv4 addresses (31.4 million) in 2,121 allocation records for Sweden, which is 0.85% of all allocated IPv4 addresses and 0.73% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 17th of 239 countries and regions by IPv4 addresses. It also holds 861 IPv6 allocation records.

With a population of about 10,596,620 (GeoNames) that is about 296.64 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 31,418,912 addresses (100.0%). APNIC listed 9,984 addresses (0.0%). ARIN listed 4,608 addresses (0.0%).

The largest single block

The largest block is 78.64.0.0/12 with 1,048,576 addresses, first allocated on 2007-03-09 by RIPE NCC.

Common questions

How many IP addresses does Sweden have?

The registries list 31,433,504 IPv4 addresses in 2,121 allocation records for Sweden and 861 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Sweden?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
