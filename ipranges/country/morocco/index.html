IP address ranges in Morocco

12,274,176

IPv4 addresses first allocated to organisations in Morocco.

The five regional registries list 12,274,176 IPv4 addresses (12.3 million) in 78 allocation records for Morocco, which is 0.33% of all allocated IPv4 addresses and 0.29% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 33rd of 239 countries and regions by IPv4 addresses. It also holds 28 IPv6 allocation records.

With a population of about 38,430,770 (GeoNames) that is about 31.94 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

AFRINIC listed 12,274,176 addresses (100.0%).

The largest block is 105.128.0.0/11 with 2,097,152 addresses, first allocated on 2011-06-02 by AFRINIC.

Common questions

How many IP addresses does Morocco have?

The registries list 12,274,176 IPv4 addresses in 78 allocation records for Morocco and 28 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Morocco?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
