IP address ranges in Hong Kong

15,999,296

IPv4 addresses first allocated to organisations in Hong Kong.

The five regional registries list 15,999,296 IPv4 addresses (16.0 million) in 3,434 allocation records for Hong Kong, which is 0.43% of all allocated IPv4 addresses and 0.37% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 29th of 239 countries and regions by IPv4 addresses. It also holds 950 IPv6 allocation records.

With a population of about 7,498,900 (GeoNames) that is about 213.36 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

APNIC listed 14,596,160 addresses (91.2%). RIPE NCC listed 1,399,552 addresses (8.7%). ARIN listed 3,584 addresses (0.0%).

The largest single block

The largest block is 63.216.0.0/13 with 524,288 addresses, first allocated on 1999-12-09 by APNIC.

Common questions

How many IP addresses does Hong Kong have?

The registries list 15,999,296 IPv4 addresses in 3,434 allocation records for Hong Kong and 950 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Hong Kong?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
