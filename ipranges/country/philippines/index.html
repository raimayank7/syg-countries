IP address ranges in Philippines

6,268,480

IPv4 addresses first allocated to organisations in Philippines.

The five regional registries list 6,268,480 IPv4 addresses (6.3 million) in 922 allocation records for Philippines, which is 0.17% of all allocated IPv4 addresses and 0.15% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 52nd of 239 countries and regions by IPv4 addresses. It also holds 400 IPv6 allocation records.

With a population of about 116,786,962 (GeoNames) that is about 5.37 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

APNIC listed 6,263,616 addresses (99.9%). ARIN listed 4,864 addresses (0.1%).

The largest single block

The largest block is 49.144.0.0/13 with 524,288 addresses, first allocated on 2010-11-22 by APNIC.

Common questions

How many IP addresses does Philippines have?

The registries list 6,268,480 IPv4 addresses in 922 allocation records for Philippines and 400 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Philippines?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
