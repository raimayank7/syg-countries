IP address ranges in Canada

67,451,392

IPv4 addresses first allocated to organisations in Canada.

The five regional registries list 67,451,392 IPv4 addresses (67.5 million) in 9,341 allocation records for Canada, which is 1.83% of all allocated IPv4 addresses and 1.57% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 9th of 239 countries and regions by IPv4 addresses. It also holds 1,150 IPv6 allocation records.

With a population of about 41,651,653 (GeoNames) that is about 161.94 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

ARIN listed 67,106,560 addresses (99.5%). RIPE NCC listed 327,168 addresses (0.5%). APNIC listed 17,664 addresses (0.0%).

The largest single block

The largest block is 99.224.0.0/11 with 2,097,152 addresses, first allocated on 2007-03-12 by ARIN.

Common questions

How many IP addresses does Canada have?

The registries list 67,451,392 IPv4 addresses in 9,341 allocation records for Canada and 1,150 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Canada?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
