IP address ranges in Portugal

6,692,896

IPv4 addresses first allocated to organisations in Portugal.

The five regional registries list 6,692,896 IPv4 addresses (6.7 million) in 441 allocation records for Portugal, which is 0.18% of all allocated IPv4 addresses and 0.16% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 50th of 239 countries and regions by IPv4 addresses. It also holds 122 IPv6 allocation records.

With a population of about 10,804,871 (GeoNames) that is about 61.94 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 6,692,896 addresses (100.0%).

Common questions

How many IP addresses does Portugal have?

The registries list 6,692,896 IPv4 addresses in 441 allocation records for Portugal and 122 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Portugal?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
