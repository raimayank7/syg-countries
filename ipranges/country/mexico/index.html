IP address ranges in Mexico

28,968,704

IPv4 addresses first allocated to organisations in Mexico.

The five regional registries list 28,968,704 IPv4 addresses (29.0 million) in 1,400 allocation records for Mexico, which is 0.79% of all allocated IPv4 addresses and 0.67% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 18th of 239 countries and regions by IPv4 addresses. It also holds 619 IPv6 allocation records.

With a population of about 131,946,900 (GeoNames) that is about 21.95 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

LACNIC listed 28,965,632 addresses (100.0%). ARIN listed 3,072 addresses (0.0%).

The largest single block

The largest block is 187.192.0.0/11 with 2,097,152 addresses, first allocated on 2011-06-06 by LACNIC.

Common questions

How many IP addresses does Mexico have?

The registries list 28,968,704 IPv4 addresses in 1,400 allocation records for Mexico and 619 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Mexico?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
