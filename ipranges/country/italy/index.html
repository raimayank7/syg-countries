IP address ranges in Italy

54,099,584

IPv4 addresses first allocated to organisations in Italy.

The five regional registries list 54,099,584 IPv4 addresses (54.1 million) in 3,750 allocation records for Italy, which is 1.47% of all allocated IPv4 addresses and 1.26% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 10th of 239 countries and regions by IPv4 addresses. It also holds 1,069 IPv6 allocation records.

With a population of about 58,915,656 (GeoNames) that is about 91.83 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 54,028,672 addresses (99.9%). ARIN listed 68,352 addresses (0.1%). APNIC listed 2,560 addresses (0.0%).

The largest single block

The largest block is 151.3.0.0/16, 151.4.0.0/14, 151.8.0.0/13 with 5,046,272 addresses, first allocated on 1991-05-13 by RIPE NCC.

Common questions

How many IP addresses does Italy have?

The registries list 54,099,584 IPv4 addresses in 3,750 allocation records for Italy and 1,069 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Italy?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
