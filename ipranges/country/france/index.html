IP address ranges in France

81,587,280

IPv4 addresses first allocated to organisations in France.

The five regional registries list 81,587,280 IPv4 addresses (81.6 million) in 4,626 allocation records for France, which is 2.21% of all allocated IPv4 addresses and 1.90% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 7th of 239 countries and regions by IPv4 addresses. It also holds 1,415 IPv6 allocation records.

With a population of about 68,720,337 (GeoNames) that is about 118.72 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 81,556,048 addresses (100.0%). ARIN listed 18,944 addresses (0.0%). APNIC listed 12,288 addresses (0.0%).

Common questions

How many IP addresses does France have?

The registries list 81,587,280 IPv4 addresses in 4,626 allocation records for France and 1,415 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for France?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
