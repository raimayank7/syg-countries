IP address ranges in Pakistan

5,620,480

IPv4 addresses first allocated to organisations in Pakistan.

The five regional registries list 5,620,480 IPv4 addresses (5.6 million) in 829 allocation records for Pakistan, which is 0.15% of all allocated IPv4 addresses and 0.13% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 56th of 239 countries and regions by IPv4 addresses. It also holds 355 IPv6 allocation records.

With a population of about 255,219,554 (GeoNames) that is about 2.20 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

APNIC listed 5,619,968 addresses (100.0%). RIPE NCC listed 512 addresses (0.0%).

The largest single block

The largest block is 39.32.0.0/11 with 2,097,152 addresses, first allocated on 2011-03-28 by APNIC.

Common questions

How many IP addresses does Pakistan have?

The registries list 5,620,480 IPv4 addresses in 829 allocation records for Pakistan and 355 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Pakistan?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
