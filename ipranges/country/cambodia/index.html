IP address ranges in Cambodia

440,832

IPv4 addresses first allocated to organisations in Cambodia.

The five regional registries list 440,832 IPv4 addresses (441 thousand) in 283 allocation records for Cambodia, which is 0.01% of all allocated IPv4 addresses and 0.01% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 119th of 239 countries and regions by IPv4 addresses. It also holds 92 IPv6 allocation records.

With a population of about 17,847,982 (GeoNames) that is about 2.47 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

APNIC listed 440,832 addresses (100.0%).

Common questions

How many IP addresses does Cambodia have?

The registries list 440,832 IPv4 addresses in 283 allocation records for Cambodia and 92 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Cambodia?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
