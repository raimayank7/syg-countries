IP address ranges in Vietnam

16,502,784

IPv4 addresses first allocated to organisations in Vietnam.

The five regional registries list 16,502,784 IPv4 addresses (16.5 million) in 1,666 allocation records for Vietnam, which is 0.45% of all allocated IPv4 addresses and 0.38% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 28th of 239 countries and regions by IPv4 addresses. It also holds 972 IPv6 allocation records.

With a population of about 101,598,527 (GeoNames) that is about 16.24 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

APNIC listed 16,499,712 addresses (100.0%). ARIN listed 1,536 addresses (0.0%). RIPE NCC listed 1,536 addresses (0.0%).

Common questions

How many IP addresses does Vietnam have?

The registries list 16,502,784 IPv4 addresses in 1,666 allocation records for Vietnam and 972 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Vietnam?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
