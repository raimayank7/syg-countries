IP address ranges in Guam

218,624

IPv4 addresses first allocated to organisations in Guam.

The five regional registries list 218,624 IPv4 addresses (219 thousand) in 29 allocation records for Guam, which is 0.01% of all allocated IPv4 addresses and 0.01% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 139th of 239 countries and regions by IPv4 addresses. It also holds 11 IPv6 allocation records.

With a population of about 168,999 (GeoNames) that is about 129.36 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

APNIC listed 152,832 addresses (69.9%). ARIN listed 65,792 addresses (30.1%).

The largest single block

The largest block is 168.123.0.0/16 with 65,536 addresses, first allocated on 1994-04-19 by ARIN.

Common questions

How many IP addresses does Guam have?

The registries list 218,624 IPv4 addresses in 29 allocation records for Guam and 11 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Guam?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
