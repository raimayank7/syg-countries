IP address ranges in Czechia

9,557,952

IPv4 addresses first allocated to organisations in Czechia.

The five regional registries list 9,557,952 IPv4 addresses (9.6 million) in 1,793 allocation records for Czechia, which is 0.26% of all allocated IPv4 addresses and 0.22% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 40th of 239 countries and regions by IPv4 addresses. It also holds 679 IPv6 allocation records.

With a population of about 10,886,878 (GeoNames) that is about 87.79 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 9,162,688 addresses (95.9%). ARIN listed 395,264 addresses (4.1%).

The largest single block

The largest block is 88.100.0.0/14 with 262,144 addresses, first allocated on 2005-10-04 by RIPE NCC.

Common questions

How many IP addresses does Czechia have?

The registries list 9,557,952 IPv4 addresses in 1,793 allocation records for Czechia and 679 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Czechia?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
