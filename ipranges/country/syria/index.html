IP address ranges in Syria

1,278,720

IPv4 addresses first allocated to organisations in Syria.

The five regional registries list 1,278,720 IPv4 addresses (1.3 million) in 206 allocation records for Syria, which is 0.03% of all allocated IPv4 addresses and 0.03% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 87th of 239 countries and regions by IPv4 addresses. It also holds 35 IPv6 allocation records.

With a population of about 25,620,427 (GeoNames) that is about 4.99 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 1,278,720 addresses (100.0%).

The largest single block

The largest block is 5.0.0.0/16 with 65,536 addresses, first allocated on 2012-04-23 by RIPE NCC.

Common questions

How many IP addresses does Syria have?

The registries list 1,278,720 IPv4 addresses in 206 allocation records for Syria and 35 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Syria?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
