IP address ranges in Argentina

19,433,216

IPv4 addresses first allocated to organisations in Argentina.

The five regional registries list 19,433,216 IPv4 addresses (19.4 million) in 1,934 allocation records for Argentina, which is 0.53% of all allocated IPv4 addresses and 0.45% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 24th of 239 countries and regions by IPv4 addresses. It also holds 1,168 IPv6 allocation records.

With a population of about 45,851,378 (GeoNames) that is about 42.38 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

LACNIC listed 19,433,216 addresses (100.0%).

Common questions

How many IP addresses does Argentina have?

The registries list 19,433,216 IPv4 addresses in 1,934 allocation records for Argentina and 1,168 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Argentina?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
