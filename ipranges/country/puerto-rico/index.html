IP address ranges in Puerto Rico

875,264

IPv4 addresses first allocated to organisations in Puerto Rico.

The five regional registries list 875,264 IPv4 addresses (875 thousand) in 271 allocation records for Puerto Rico, which is 0.02% of all allocated IPv4 addresses and 0.02% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 95th of 239 countries and regions by IPv4 addresses. It also holds 73 IPv6 allocation records.

With a population of about 3,184,835 (GeoNames) that is about 27.48 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

ARIN listed 773,376 addresses (88.4%). RIPE NCC listed 101,888 addresses (11.6%).

The largest single block

The largest block is 66.50.0.0/16 with 65,536 addresses, first allocated on 2000-11-29 by ARIN.

Common questions

How many IP addresses does Puerto Rico have?

The registries list 875,264 IPv4 addresses in 271 allocation records for Puerto Rico and 73 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Puerto Rico?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
