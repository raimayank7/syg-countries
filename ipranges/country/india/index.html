IP address ranges in India

42,042,368

IPv4 addresses first allocated to organisations in India.

The five regional registries list 42,042,368 IPv4 addresses (42.0 million) in 9,345 allocation records for India, which is 1.14% of all allocated IPv4 addresses and 0.98% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 14th of 239 countries and regions by IPv4 addresses. It also holds 2,948 IPv6 allocation records.

With a population of about 1,463,865,525 (GeoNames) that is about 2.87 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

APNIC listed 41,822,208 addresses (99.5%). RIPE NCC listed 220,160 addresses (0.5%).

The largest single block

The largest block is 117.192.0.0/10 with 4,194,304 addresses, first allocated on 2007-08-01 by APNIC.

Common questions

How many IP addresses does India have?

The registries list 42,042,368 IPv4 addresses in 9,345 allocation records for India and 2,948 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for India?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
