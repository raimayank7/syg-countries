IP address ranges in Brazil

79,322,368

IPv4 addresses first allocated to organisations in Brazil.

The five regional registries list 79,322,368 IPv4 addresses (79.3 million) in 13,103 allocation records for Brazil, which is 2.15% of all allocated IPv4 addresses and 1.85% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 8th of 239 countries and regions by IPv4 addresses. It also holds 8,970 IPv6 allocation records.

With a population of about 212,812,405 (GeoNames) that is about 37.27 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

LACNIC listed 79,318,272 addresses (100.0%). RIPE NCC listed 4,096 addresses (0.0%).

The largest single block

The largest block is 152.240.0.0/13 with 524,288 addresses, first allocated on 2014-04-24 by LACNIC.

Common questions

How many IP addresses does Brazil have?

The registries list 79,322,368 IPv4 addresses in 13,103 allocation records for Brazil and 8,970 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Brazil?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
