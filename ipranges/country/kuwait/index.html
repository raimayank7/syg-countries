IP address ranges in Kuwait

1,903,360

IPv4 addresses first allocated to organisations in Kuwait.

The five regional registries list 1,903,360 IPv4 addresses (1.9 million) in 137 allocation records for Kuwait, which is 0.05% of all allocated IPv4 addresses and 0.04% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 74th of 239 countries and regions by IPv4 addresses. It also holds 35 IPv6 allocation records.

With a population of about 4,865,298 (GeoNames) that is about 39.12 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 1,903,360 addresses (100.0%).

The largest single block

The largest block is 37.36.0.0/14 with 262,144 addresses, first allocated on 2012-01-03 by RIPE NCC.

Common questions

How many IP addresses does Kuwait have?

The registries list 1,903,360 IPv4 addresses in 137 allocation records for Kuwait and 35 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Kuwait?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
