IP address ranges in Taiwan

35,741,952

IPv4 addresses first allocated to organisations in Taiwan.

The five regional registries list 35,741,952 IPv4 addresses (35.7 million) in 1,084 allocation records for Taiwan, which is 0.97% of all allocated IPv4 addresses and 0.83% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 15th of 239 countries and regions by IPv4 addresses. It also holds 325 IPv6 allocation records.

With a population of about 23,451,837 (GeoNames) that is about 152.41 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

APNIC listed 35,734,272 addresses (100.0%). RIPE NCC listed 5,632 addresses (0.0%). ARIN listed 2,048 addresses (0.0%).

Common questions

How many IP addresses does Taiwan have?

The registries list 35,741,952 IPv4 addresses in 1,084 allocation records for Taiwan and 325 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Taiwan?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
