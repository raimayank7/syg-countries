IP address ranges in Albania

505,920

IPv4 addresses first allocated to organisations in Albania.

The five regional registries list 505,920 IPv4 addresses (506 thousand) in 243 allocation records for Albania, which is 0.01% of all allocated IPv4 addresses and 0.01% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 114th of 239 countries and regions by IPv4 addresses. It also holds 101 IPv6 allocation records.

With a population of about 2,349,580 (GeoNames) that is about 21.53 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 505,408 addresses (99.9%). APNIC listed 512 addresses (0.1%).

The largest single block

The largest block is 46.99.0.0/16 with 65,536 addresses, first allocated on 2010-06-08 by RIPE NCC.

Common questions

How many IP addresses does Albania have?

The registries list 505,920 IPv4 addresses in 243 allocation records for Albania and 101 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Albania?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
