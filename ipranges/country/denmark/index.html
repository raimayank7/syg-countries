IP address ranges in Denmark

12,007,712

IPv4 addresses first allocated to organisations in Denmark.

The five regional registries list 12,007,712 IPv4 addresses (12.0 million) in 1,522 allocation records for Denmark, which is 0.33% of all allocated IPv4 addresses and 0.28% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 34th of 239 countries and regions by IPv4 addresses. It also holds 411 IPv6 allocation records.

With a population of about 6,009,169 (GeoNames) that is about 199.82 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 12,007,200 addresses (100.0%). APNIC listed 512 addresses (0.0%).

The largest block is 87.48.0.0/13 with 524,288 addresses, first allocated on 2005-05-20 by RIPE NCC.

Common questions

How many IP addresses does Denmark have?

The registries list 12,007,712 IPv4 addresses in 1,522 allocation records for Denmark and 411 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Denmark?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
