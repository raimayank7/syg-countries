IP address ranges in Peru

3,250,688

IPv4 addresses first allocated to organisations in Peru.

The five regional registries list 3,250,688 IPv4 addresses (3.3 million) in 270 allocation records for Peru, which is 0.09% of all allocated IPv4 addresses and 0.08% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 62nd of 239 countries and regions by IPv4 addresses. It also holds 229 IPv6 allocation records.

With a population of about 34,576,665 (GeoNames) that is about 9.40 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

LACNIC listed 3,250,432 addresses (100.0%). RIPE NCC listed 256 addresses (0.0%).

Common questions

How many IP addresses does Peru have?

The registries list 3,250,688 IPv4 addresses in 270 allocation records for Peru and 229 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Peru?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
