IP address ranges in Ireland

10,011,712

IPv4 addresses first allocated to organisations in Ireland.

The five regional registries list 10,011,712 IPv4 addresses (10.0 million) in 736 allocation records for Ireland, which is 0.27% of all allocated IPv4 addresses and 0.23% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 38th of 239 countries and regions by IPv4 addresses. It also holds 214 IPv6 allocation records.

With a population of about 5,484,367 (GeoNames) that is about 182.55 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 10,011,200 addresses (100.0%). ARIN listed 512 addresses (0.0%).

The largest single block

The largest block is 57.207.0.0/16, 57.208.0.0/12 with 1,114,112 addresses, first allocated on 1993-06-21 by RIPE NCC.

Common questions

How many IP addresses does Ireland have?

The registries list 10,011,712 IPv4 addresses in 736 allocation records for Ireland and 214 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Ireland?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
