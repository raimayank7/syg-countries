IP address ranges in China

342,985,984

IPv4 addresses first allocated to organisations in China.

The five regional registries list 342,985,984 IPv4 addresses (343.0 million) in 8,816 allocation records for China, which is 9.30% of all allocated IPv4 addresses and 7.99% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 2nd of 239 countries and regions by IPv4 addresses. It also holds 2,066 IPv6 allocation records.

With a population of about 1,406,585,000 (GeoNames) that is about 24.38 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

APNIC listed 342,941,440 addresses (100.0%). RIPE NCC listed 44,288 addresses (0.0%). ARIN listed 256 addresses (0.0%).

The largest single block

The largest block is 36.128.0.0/10 with 4,194,304 addresses, first allocated on 2011-01-24 by APNIC.

Common questions

How many IP addresses does China have?

The registries list 342,985,984 IPv4 addresses in 8,816 allocation records for China and 2,066 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for China?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
