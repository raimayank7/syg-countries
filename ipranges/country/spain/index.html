IP address ranges in Spain

31,941,248

IPv4 addresses first allocated to organisations in Spain.

The five regional registries list 31,941,248 IPv4 addresses (31.9 million) in 3,798 allocation records for Spain, which is 0.87% of all allocated IPv4 addresses and 0.74% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 16th of 239 countries and regions by IPv4 addresses. It also holds 886 IPv6 allocation records.

With a population of about 49,355,143 (GeoNames) that is about 64.72 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 31,938,688 addresses (100.0%). APNIC listed 2,048 addresses (0.0%). ARIN listed 512 addresses (0.0%).

The largest single block

The largest block is 88.0.0.0/11 with 2,097,152 addresses, first allocated on 2005-07-13 by RIPE NCC.

Common questions

How many IP addresses does Spain have?

The registries list 31,941,248 IPv4 addresses in 3,798 allocation records for Spain and 886 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Spain?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
