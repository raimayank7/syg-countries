IP address ranges in Iraq

452,928

IPv4 addresses first allocated to organisations in Iraq.

The five regional registries list 452,928 IPv4 addresses (453 thousand) in 344 allocation records for Iraq, which is 0.01% of all allocated IPv4 addresses and 0.01% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 117th of 239 countries and regions by IPv4 addresses. It also holds 118 IPv6 allocation records.

With a population of about 47,020,774 (GeoNames) that is about 0.96 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 452,928 addresses (100.0%).

Common questions

How many IP addresses does Iraq have?

The registries list 452,928 IPv4 addresses in 344 allocation records for Iraq and 118 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Iraq?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
