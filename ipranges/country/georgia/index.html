IP address ranges in Georgia

1,306,432

IPv4 addresses first allocated to organisations in Georgia.

The five regional registries list 1,306,432 IPv4 addresses (1.3 million) in 335 allocation records for Georgia, which is 0.04% of all allocated IPv4 addresses and 0.03% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 85th of 239 countries and regions by IPv4 addresses. It also holds 82 IPv6 allocation records.

With a population of about 3,935,766 (GeoNames) that is about 33.19 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 1,306,432 addresses (100.0%).

The largest block is 31.146.0.0/16 with 65,536 addresses, first allocated on 2011-02-10 by RIPE NCC.

Common questions

How many IP addresses does Georgia have?

The registries list 1,306,432 IPv4 addresses in 335 allocation records for Georgia and 82 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Georgia?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
