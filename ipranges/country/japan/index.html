IP address ranges in Japan

188,721,984

IPv4 addresses first allocated to organisations in Japan.

The five regional registries list 188,721,984 IPv4 addresses (188.7 million) in 4,806 allocation records for Japan, which is 5.12% of all allocated IPv4 addresses and 4.39% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 3rd of 239 countries and regions by IPv4 addresses. It also holds 788 IPv6 allocation records.

With a population of about 123,366,734 (GeoNames) that is about 152.98 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

APNIC listed 188,591,360 addresses (99.9%). ARIN listed 88,576 addresses (0.0%). RIPE NCC listed 42,048 addresses (0.0%).

The largest single block

The largest block is 133.0.0.0/8 with 16,777,216 addresses, first allocated on 1997-03-01 by APNIC.

Common questions

How many IP addresses does Japan have?

The registries list 188,721,984 IPv4 addresses in 4,806 allocation records for Japan and 788 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Japan?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
