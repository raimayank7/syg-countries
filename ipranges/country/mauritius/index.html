IP address ranges in Mauritius

3,698,944

IPv4 addresses first allocated to organisations in Mauritius.

The five regional registries list 3,698,944 IPv4 addresses (3.7 million) in 107 allocation records for Mauritius, which is 0.10% of all allocated IPv4 addresses and 0.09% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 60th of 239 countries and regions by IPv4 addresses. It also holds 33 IPv6 allocation records.

With a population of about 1,243,741 (GeoNames) that is about 297.40 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

AFRINIC listed 3,695,872 addresses (99.9%). APNIC listed 2,048 addresses (0.1%). RIPE NCC listed 1,024 addresses (0.0%).

The largest single block

The largest block is 41.160.0.0/12 with 1,048,576 addresses, first allocated on 2007-02-22 by AFRINIC.

Common questions

How many IP addresses does Mauritius have?

The registries list 3,698,944 IPv4 addresses in 107 allocation records for Mauritius and 33 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Mauritius?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
