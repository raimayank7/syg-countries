IP address ranges in Chile

9,634,816

IPv4 addresses first allocated to organisations in Chile.

The five regional registries list 9,634,816 IPv4 addresses (9.6 million) in 818 allocation records for Chile, which is 0.26% of all allocated IPv4 addresses and 0.22% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 39th of 239 countries and regions by IPv4 addresses. It also holds 337 IPv6 allocation records.

With a population of about 19,859,921 (GeoNames) that is about 48.51 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

LACNIC listed 9,634,816 addresses (100.0%).

Common questions

How many IP addresses does Chile have?

The registries list 9,634,816 IPv4 addresses in 818 allocation records for Chile and 337 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Chile?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
