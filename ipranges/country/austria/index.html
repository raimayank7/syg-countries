IP address ranges in Austria

11,184,480

IPv4 addresses first allocated to organisations in Austria.

The five regional registries list 11,184,480 IPv4 addresses (11.2 million) in 2,067 allocation records for Austria, which is 0.30% of all allocated IPv4 addresses and 0.26% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 36th of 239 countries and regions by IPv4 addresses. It also holds 601 IPv6 allocation records.

With a population of about 9,208,163 (GeoNames) that is about 121.46 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 11,184,480 addresses (100.0%).

The largest block is 77.116.0.0/14 with 262,144 addresses, first allocated on 2007-01-10 by RIPE NCC.

Common questions

How many IP addresses does Austria have?

The registries list 11,184,480 IPv4 addresses in 2,067 allocation records for Austria and 601 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Austria?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
