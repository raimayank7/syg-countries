IP address ranges in Singapore

28,961,344

IPv4 addresses first allocated to organisations in Singapore.

The five regional registries list 28,961,344 IPv4 addresses (29.0 million) in 1,907 allocation records for Singapore, which is 0.79% of all allocated IPv4 addresses and 0.67% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 19th of 239 countries and regions by IPv4 addresses. It also holds 526 IPv6 allocation records.

With a population of about 6,111,175 (GeoNames) that is about 473.91 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

APNIC listed 28,747,072 addresses (99.3%). RIPE NCC listed 132,608 addresses (0.5%). ARIN listed 81,664 addresses (0.3%).

The largest block is 43.0.0.0/9 with 8,388,608 addresses, first allocated on 1989-02-21 by APNIC.

Common questions

How many IP addresses does Singapore have?

The registries list 28,961,344 IPv4 addresses in 1,907 allocation records for Singapore and 526 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Singapore?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
