IP address ranges in Romania

7,867,008

IPv4 addresses first allocated to organisations in Romania.

The five regional registries list 7,867,008 IPv4 addresses (7.9 million) in 2,860 allocation records for Romania, which is 0.21% of all allocated IPv4 addresses and 0.18% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 46th of 239 countries and regions by IPv4 addresses. It also holds 270 IPv6 allocation records.

With a population of about 19,020,271 (GeoNames) that is about 41.36 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 7,860,864 addresses (99.9%). ARIN listed 6,144 addresses (0.1%).

The largest single block

The largest block is 86.120.0.0/13 with 524,288 addresses, first allocated on 2005-03-16 by RIPE NCC.

Common questions

How many IP addresses does Romania have?

The registries list 7,867,008 IPv4 addresses in 2,860 allocation records for Romania and 270 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Romania?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
