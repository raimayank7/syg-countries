IP address ranges in Malta

675,200

IPv4 addresses first allocated to organisations in Malta.

The five regional registries list 675,200 IPv4 addresses (675 thousand) in 121 allocation records for Malta, which is 0.02% of all allocated IPv4 addresses and 0.02% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 101st of 239 countries and regions by IPv4 addresses. It also holds 26 IPv6 allocation records.

With a population of about 579,704 (GeoNames) that is about 116.47 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 674,176 addresses (99.8%). APNIC listed 1,024 addresses (0.2%).

The largest single block

The largest block is 46.11.0.0/16 with 65,536 addresses, first allocated on 2010-09-14 by RIPE NCC.

Common questions

How many IP addresses does Malta have?

The registries list 675,200 IPv4 addresses in 121 allocation records for Malta and 26 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Malta?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
