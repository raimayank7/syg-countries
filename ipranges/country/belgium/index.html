IP address ranges in Belgium

12,302,720

IPv4 addresses first allocated to organisations in Belgium.

The five regional registries list 12,302,720 IPv4 addresses (12.3 million) in 965 allocation records for Belgium, which is 0.33% of all allocated IPv4 addresses and 0.29% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 32nd of 239 countries and regions by IPv4 addresses. It also holds 326 IPv6 allocation records.

With a population of about 11,941,781 (GeoNames) that is about 103.02 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 12,234,880 addresses (99.4%). ARIN listed 67,840 addresses (0.6%).

The largest single block

The largest block is 109.128.0.0/12 with 1,048,576 addresses, first allocated on 2009-07-27 by RIPE NCC.

Common questions

How many IP addresses does Belgium have?

The registries list 12,302,720 IPv4 addresses in 965 allocation records for Belgium and 326 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Belgium?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
