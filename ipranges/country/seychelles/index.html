IP address ranges in Seychelles

9,013,760

IPv4 addresses first allocated to organisations in Seychelles.

The five regional registries list 9,013,760 IPv4 addresses (9.0 million) in 881 allocation records for Seychelles, which is 0.24% of all allocated IPv4 addresses and 0.21% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 42nd of 239 countries and regions by IPv4 addresses. It also holds 728 IPv6 allocation records.

With a population of about 122,730 (GeoNames) that is about 7344.38 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

AFRINIC listed 7,987,200 addresses (88.6%). RIPE NCC listed 1,009,152 addresses (11.2%). APNIC listed 17,408 addresses (0.2%).

The largest single block

Common questions

How many IP addresses does Seychelles have?

The registries list 9,013,760 IPv4 addresses in 881 allocation records for Seychelles and 728 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Seychelles?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
