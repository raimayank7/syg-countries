IP address ranges in Dominican Republic

1,623,296

IPv4 addresses first allocated to organisations in Dominican Republic.

The five regional registries list 1,623,296 IPv4 addresses (1.6 million) in 167 allocation records for Dominican Republic, which is 0.04% of all allocated IPv4 addresses and 0.04% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 81st of 239 countries and regions by IPv4 addresses. It also holds 218 IPv6 allocation records.

With a population of about 11,520,487 (GeoNames) that is about 14.09 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

LACNIC listed 1,622,272 addresses (99.9%). ARIN listed 1,024 addresses (0.1%).

The largest single block

The largest block is 152.166.0.0/15 with 131,072 addresses, first allocated on 2014-05-28 by LACNIC.

Common questions

How many IP addresses does Dominican Republic have?

The registries list 1,623,296 IPv4 addresses in 167 allocation records for Dominican Republic and 218 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Dominican Republic?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
