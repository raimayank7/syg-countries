IP address ranges in Ecuador

2,728,448

IPv4 addresses first allocated to organisations in Ecuador.

The five regional registries list 2,728,448 IPv4 addresses (2.7 million) in 438 allocation records for Ecuador, which is 0.07% of all allocated IPv4 addresses and 0.06% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 64th of 239 countries and regions by IPv4 addresses. It also holds 285 IPv6 allocation records.

With a population of about 18,289,896 (GeoNames) that is about 14.92 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

LACNIC listed 2,728,448 addresses (100.0%).

The largest block is 186.68.0.0/15 with 131,072 addresses, first allocated on 2009-04-27 by LACNIC.

Common questions

How many IP addresses does Ecuador have?

The registries list 2,728,448 IPv4 addresses in 438 allocation records for Ecuador and 285 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Ecuador?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
