IP address ranges in Uzbekistan

336,128

IPv4 addresses first allocated to organisations in Uzbekistan.

The five regional registries list 336,128 IPv4 addresses (336 thousand) in 225 allocation records for Uzbekistan, which is 0.01% of all allocated IPv4 addresses and 0.01% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 129th of 239 countries and regions by IPv4 addresses. It also holds 49 IPv6 allocation records.

With a population of about 37,053,428 (GeoNames) that is about 0.91 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 336,128 addresses (100.0%).

Common questions

How many IP addresses does Uzbekistan have?

The registries list 336,128 IPv4 addresses in 225 allocation records for Uzbekistan and 49 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Uzbekistan?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
