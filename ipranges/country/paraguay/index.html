IP address ranges in Paraguay

1,153,536

IPv4 addresses first allocated to organisations in Paraguay.

The five regional registries list 1,153,536 IPv4 addresses (1.2 million) in 152 allocation records for Paraguay, which is 0.03% of all allocated IPv4 addresses and 0.03% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 90th of 239 countries and regions by IPv4 addresses. It also holds 110 IPv6 allocation records.

With a population of about 7,013,078 (GeoNames) that is about 16.45 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

LACNIC listed 1,153,536 addresses (100.0%).

Common questions

How many IP addresses does Paraguay have?

The registries list 1,153,536 IPv4 addresses in 152 allocation records for Paraguay and 110 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Paraguay?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
