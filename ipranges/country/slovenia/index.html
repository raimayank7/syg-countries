IP address ranges in Slovenia

2,684,928

IPv4 addresses first allocated to organisations in Slovenia.

The five regional registries list 2,684,928 IPv4 addresses (2.7 million) in 547 allocation records for Slovenia, which is 0.07% of all allocated IPv4 addresses and 0.06% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 65th of 239 countries and regions by IPv4 addresses. It also holds 149 IPv6 allocation records.

With a population of about 2,130,986 (GeoNames) that is about 125.99 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 2,684,416 addresses (100.0%). APNIC listed 512 addresses (0.0%).

Common questions

How many IP addresses does Slovenia have?

The registries list 2,684,928 IPv4 addresses in 547 allocation records for Slovenia and 149 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Slovenia?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
