IP address ranges in Poland

20,044,232

IPv4 addresses first allocated to organisations in Poland.

The five regional registries list 20,044,232 IPv4 addresses (20.0 million) in 4,303 allocation records for Poland, which is 0.54% of all allocated IPv4 addresses and 0.47% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 23rd of 239 countries and regions by IPv4 addresses. It also holds 986 IPv6 allocation records.

With a population of about 36,435,861 (GeoNames) that is about 55.01 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 20,043,720 addresses (100.0%). APNIC listed 512 addresses (0.0%).

The largest block is 83.0.0.0/11 with 2,097,152 addresses, first allocated on 2003-12-03 by RIPE NCC.

Common questions

How many IP addresses does Poland have?

The registries list 20,044,232 IPv4 addresses in 4,303 allocation records for Poland and 986 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Poland?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
