IP address ranges in Angola

1,294,080

IPv4 addresses first allocated to organisations in Angola.

The five regional registries list 1,294,080 IPv4 addresses (1.3 million) in 159 allocation records for Angola, which is 0.04% of all allocated IPv4 addresses and 0.03% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 86th of 239 countries and regions by IPv4 addresses. It also holds 43 IPv6 allocation records.

With a population of about 39,040,039 (GeoNames) that is about 3.31 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

AFRINIC listed 1,293,056 addresses (99.9%). RIPE NCC listed 1,024 addresses (0.1%).

The largest single block

The largest block is 105.168.0.0/13 with 524,288 addresses, first allocated on 2012-12-13 by AFRINIC.

Common questions

How many IP addresses does Angola have?

The registries list 1,294,080 IPv4 addresses in 159 allocation records for Angola and 43 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Angola?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
