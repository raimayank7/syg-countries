IP address ranges in Thailand

8,931,328

IPv4 addresses first allocated to organisations in Thailand.

The five regional registries list 8,931,328 IPv4 addresses (8.9 million) in 1,199 allocation records for Thailand, which is 0.24% of all allocated IPv4 addresses and 0.21% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 43rd of 239 countries and regions by IPv4 addresses. It also holds 241 IPv6 allocation records.

With a population of about 71,619,863 (GeoNames) that is about 12.47 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

APNIC listed 8,918,784 addresses (99.9%). ARIN listed 12,288 addresses (0.1%). RIPE NCC listed 256 addresses (0.0%).

The largest single block

The largest block is 171.96.0.0/13 with 524,288 addresses, first allocated on 2011-03-07 by APNIC.

Common questions

How many IP addresses does Thailand have?

The registries list 8,931,328 IPv4 addresses in 1,199 allocation records for Thailand and 241 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Thailand?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
