IP address ranges in Venezuela

6,700,544

IPv4 addresses first allocated to organisations in Venezuela.

The five regional registries list 6,700,544 IPv4 addresses (6.7 million) in 260 allocation records for Venezuela, which is 0.18% of all allocated IPv4 addresses and 0.16% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 49th of 239 countries and regions by IPv4 addresses. It also holds 244 IPv6 allocation records.

With a population of about 28,516,896 (GeoNames) that is about 23.50 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

LACNIC listed 6,700,544 addresses (100.0%).

Common questions

How many IP addresses does Venezuela have?

The registries list 6,700,544 IPv4 addresses in 260 allocation records for Venezuela and 244 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Venezuela?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
