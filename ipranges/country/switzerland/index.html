IP address ranges in Switzerland

23,288,176

IPv4 addresses first allocated to organisations in Switzerland.

The five regional registries list 23,288,176 IPv4 addresses (23.3 million) in 2,895 allocation records for Switzerland, which is 0.63% of all allocated IPv4 addresses and 0.54% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 22nd of 239 countries and regions by IPv4 addresses. It also holds 877 IPv6 allocation records.

With a population of about 9,092,436 (GeoNames) that is about 256.13 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

RIPE NCC listed 23,279,216 addresses (100.0%). ARIN listed 7,168 addresses (0.0%). APNIC listed 1,792 addresses (0.0%).

The largest block is 85.0.0.0/13 with 524,288 addresses, first allocated on 2005-01-25 by RIPE NCC.

Common questions

How many IP addresses does Switzerland have?

The registries list 23,288,176 IPv4 addresses in 2,895 allocation records for Switzerland and 877 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Switzerland?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
