IP address ranges in Curacao

197,632

IPv4 addresses first allocated to organisations in Curacao.

The five regional registries list 197,632 IPv4 addresses (198 thousand) in 51 allocation records for Curacao, which is 0.01% of all allocated IPv4 addresses and 0.00% of the 4,294,967,296 IPv4 addresses that exist in total, which puts it 141st of 239 countries and regions by IPv4 addresses. It also holds 21 IPv6 allocation records.

With a population of about 156,263 (GeoNames) that is about 126.47 IPv4 addresses for every 100 people in the country’s allocations. This is a measure of allocation, not of use: addresses are shared by many people through routers and mobile networks, and a large share of any country’s addresses sits with companies that serve users elsewhere.

Which registry listed them

LACNIC listed 184,832 addresses (93.5%). RIPE NCC listed 12,800 addresses (6.5%).

Common questions

How many IP addresses does Curacao have?

The registries list 197,632 IPv4 addresses in 51 allocation records for Curacao and 21 IPv6 records.

Does this show where an address is used?

No. It shows the country of the organisation that first received the block. Blocks are rented, sold and used across borders.

Where can I get the list of ranges for Curacao?

Each page links a plain text file of the IPv4 ranges in CIDR form and one of IPv6 prefixes. Check the date of the file before you rely on it for a firewall rule: allocations change and the country of allocation is not the country of use.
