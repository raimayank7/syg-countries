The five regional internet registries

Internet address blocks are handed out in five regions by five non-profit registries. Each publishes a statistics file with every block it has allocated. This site reads all five. The table shows the sums in the files at the time of reading.

How to use this page

Each of the five registries serves a region of the world and keeps its own statistics file. The table adds up the IPv4 addresses each has allocated and the addresses it still lists as available. IANA, which sits above them, handed the last free IPv4 blocks to the registries in 2011; since then each registry has been working through its remaining pool or recycling returned space, so the available figure can be small. Open a registry page for its countries. The totals here are sums of the published files at the date they were read.
