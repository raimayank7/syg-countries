Who hands out IP addresses?

Internet addresses are handed out in layers. At the top, IANA (part of ICANN) keeps the global pool and gives large blocks to the five regional internet registries: APNIC, ARIN, RIPE NCC, LACNIC and AFRINIC. Each registry gives smaller blocks to local registries and providers (internet service providers, large companies, universities) in its region. Providers then give addresses to customers, usually on loan: when you stop paying, the address goes back.

What the files record

Each registry publishes a daily "delegated extended" file with one line per block: registry, country code, type (IPv4 or IPv6), start address, size, the date of allocation, and status. This site reads those files. At the time of reading they held 262,651 IPv4 records and 71,130 IPv6 records with a country code and the status "allocated" or "assigned".

Allocated and assigned

"Allocated" usually means a block given to a provider to hand on; "assigned" a block given to an end organisation for its own use. This site counts both.

Who is behind a block?

The statistics files do not name the organisation, only an opaque identifier. To see who holds a block you query the registries' WHOIS or RDAP service, which is a different tool from this site.
