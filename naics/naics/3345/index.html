How the code is read

A NAICS code builds up one level at a time, and each extra digit narrows the activity. Reading 3345 from the left:

How is 3345 different from 3341?

3345 is Navigational, Measuring, Electromedical, and Control Instruments Manufacturing, while 3341 is Computer and Peripheral Equipment Manufacturing. Compare their descriptions: they are separate codes because the Census treats the two activities as different.

Is this the code to put on a form?
