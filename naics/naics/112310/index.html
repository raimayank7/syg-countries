NAICS 112310: Chicken Egg Production

National industry, 2022 NAICS.

112310 is the NAICS national industry Chicken Egg Production in the 2022 edition of the classification. It is filed under 11 Agriculture, Forestry, Fishing and Hunting › 112 Animal Production and Aquaculture › 1123 Poultry and Egg Production. In the code order it is number 36 of the 1,012 six-digit industries.

Its five-digit parent, 11231 Chicken Egg Production, holds only this one industry, so the two codes carry the same title and the same meaning.

What the Census says

This industry comprises establishments primarily engaged in raising chickens for egg production. The eggs produced may be for use as table eggs or hatching eggs.

To read that description in everyday terms, the main activity this code covers is raising chickens for egg production.

The description opens with "This industry", the wording the Census uses for a class whose definition is shared by the United States, Canada and Mexico.

The Census entry also carries a Cross-References note that sends some related activities to other codes. The workbook keeps only its heading, so read the full entry for 112310 on census.gov for the exact exclusions.

How the code is read

A NAICS code builds up one level at a time, and each extra digit narrows the activity. Reading 112310 from the left:

  • 11 is the sector Agriculture, Forestry, Fishing and Hunting
  • 112 is the subsector Animal Production and Aquaculture
  • 1123 is the industry group Poultry and Egg Production
  • 11231 is the five-digit industry Chicken Egg Production
  • 112310 is the national industry Chicken Egg Production

Businesses and products indexed here

The Census index file points 7 terms to 112310, from "Chicken egg production" to "Started pullet production". That is below the median of 13 terms for a six-digit industry that has any. The entries are listed below as the Census writes them, so they show what the code is used for in practice: Chicken egg production; Chicken eggs (table, hatching) production; Cull hen production; Egg production, chicken; Eggs, chicken (table, hatching) production; Layer-type chicken production; Started pullet production.

Neighbouring national industries

Chicken Egg Production sits in the industry group 1123 Poultry and Egg Production, which has 5 national industries in all. The others are: 112320 Broilers and Other Meat Type Chicken Production, 112330 Turkey Production, 112340 Poultry Hatcheries, 112390 Other Poultry Production.

How it differs from the codes next to it

If two neighbouring codes seem to fit, compare their descriptions. For 112310 the main activity here is raising chickens for egg production. The nearest codes in the same industry group say:

  • 112320 Broilers and Other Meat Type Chicken Production: main activity is raising broilers, fryers, roasters, and other meat type chickens
  • 112330 Turkey Production: main activity is raising turkeys for meat or egg production
  • 112340 Poultry Hatcheries: main activity is hatching poultry of any kind

The industry group around it

One level up is the industry group 1123 Poultry and Egg Production. The Census describes it this way: This industry group comprises establishments primarily engaged in breeding, hatching, and raising poultry for meat or egg

What is NAICS code 112310?

What does NAICS 112310 include?

Which sector is 112310 in?

How is 112310 different from 112320?

Is this the code to put on a form?

Not by itself. A form asks for the code of the main activity, in the NAICS year it names. Read the description above and the codes beside it, and follow the instructions of the agency that asks.
