NAICS 325520: Adhesive Manufacturing

National industry, 2022 NAICS.

325520 is the NAICS national industry Adhesive Manufacturing in the 2022 edition of the classification. It is filed under 31-33 Manufacturing › 325 Chemical Manufacturing › 3255 Paint, Coating, and Adhesive Manufacturing. In the code order it is number 252 of the 1,012 six-digit industries.

Its five-digit parent, 32552 Adhesive Manufacturing, holds only this one industry, so the two codes carry the same title and the same meaning.

What the Census says

This industry comprises establishments primarily engaged in manufacturing adhesives, glues, and caulking compounds.

To read that description in everyday terms, the main activity this code covers is manufacturing adhesives, glues, and caulking compounds.

The description opens with "This industry", the wording the Census uses for a class whose definition is shared by the United States, Canada and Mexico.

The Census entry also carries a Cross-References note that sends some related activities to other codes. The workbook keeps only its heading, so read the full entry for 325520 on census.gov for the exact exclusions.

How the code is read

A NAICS code builds up one level at a time, and each extra digit narrows the activity. Reading 325520 from the left:

  • 31-33 is the sector Manufacturing
  • 325 is the subsector Chemical Manufacturing
  • 3255 is the industry group Paint, Coating, and Adhesive Manufacturing
  • 32552 is the five-digit industry Adhesive Manufacturing
  • 325520 is the national industry Adhesive Manufacturing

Businesses and products indexed here

The Census index file points 16 terms to 325520, from "Adhesives (except asphalt, dental, gypsum base) manufacturing" to "Tile adhesives manufacturing". That is above the median of 13 terms for a six-digit industry that has any. 5 of the entries carry an "except" qualifier, which marks a boundary with another code: Adhesives (except asphalt, dental, gypsum base) manufacturing; Caulking compounds (except gypsum base) manufacturing; Construction adhesives (except asphalt, gypsum base) manufacturing; Glues (except dental) manufacturing; Joint compounds (except gypsum base) manufacturing.

Is this the code to put on a form?

Not by itself. A form asks for the code of the main activity, in the NAICS year it names. Read the description above and the codes beside it, and follow the instructions of the agency that asks.
