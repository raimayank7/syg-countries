NAICS 611630: Language Schools

National industry, 2022 NAICS.

611630 is the NAICS national industry Language Schools in the 2022 edition of the classification. It is filed under 61 Educational Services › 611 Educational Services › 6116 Other Schools and Instruction. In the code order it is number 856 of the 1,012 six-digit industries.

Its five-digit parent, 61163 Language Schools, holds only this one industry, so the two codes carry the same title and the same meaning.

What the Census says

This industry comprises establishments primarily engaged in offering foreign language instruction (including sign language). These establishments are designed to offer language instruction ranging from conversational skills for personal enrichment to intensive training courses for career or educational opportunities.

To read that description in everyday terms, the main activity this code covers is offering foreign language instruction (including sign language).

The description opens with "This industry", the wording the Census uses for a class whose definition is shared by the United States, Canada and Mexico.

The Census entry also carries a Cross-References note that sends some related activities to other codes. The workbook keeps only its heading, so read the full entry for 611630 on census.gov for the exact exclusions.

How the code is read

A NAICS code builds up one level at a time, and each extra digit narrows the activity. Reading 611630 from the left:

  • 61 is the sector Educational Services
  • 611 is the subsector Educational Services
  • 6116 is the industry group Other Schools and Instruction
  • 61163 is the five-digit industry Language Schools
  • 611630 is the national industry Language Schools

Businesses and products indexed here

The Census index file points 6 terms to 611630, from "Foreign language schools" to "Sign language schools". That is below the median of 13 terms for a six-digit industry that has any. The entries are listed below as the Census writes them, so they show what the code is used for in practice: Foreign language schools; Language schools; Schools, language; Second language instruction; Sign language instruction; Sign language schools.

How it differs from the codes next to it
