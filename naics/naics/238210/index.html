NAICS 238210: Electrical Contractors and Other Wiring Installation Contractors

National industry, 2022 NAICS.

238210 is the NAICS national industry Electrical Contractors and Other Wiring Installation Contractors in the 2022 edition of the classification. It is filed under 23 Construction › 238 Specialty Trade Contractors › 2382 Building Equipment Contractors. In the code order it is number 120 of the 1,012 six-digit industries.

Its five-digit parent, 23821 Electrical Contractors and Other Wiring Installation Contractors, holds only this one industry, so the two codes carry the same title and the same meaning.

What the Census says

This industry comprises establishments primarily engaged in installing and servicing electrical wiring and equipment. Contractors included in this industry may include both the parts and labor when performing work. These contractors may perform new work, additions, alterations, maintenance, and repairs.

Put simply, the class is meant for establishments whose main work is installing and servicing electrical wiring and equipment.

The description opens with "This industry", the wording the Census uses for a class whose definition is shared by the United States, Canada and Mexico.

The Census entry also carries a Cross-References note that sends some related activities to other codes. The workbook keeps only its heading, so read the full entry for 238210 on census.gov for the exact exclusions.

How the code is read

A NAICS code builds up one level at a time, and each extra digit narrows the activity. Reading 238210 from the left:

How it differs from the codes next to it

If two neighbouring codes seem to fit, compare their descriptions. For 238210 the main activity here is installing and servicing electrical wiring and equipment. The nearest codes in the same industry group say:

  • 238220 Plumbing, Heating, and Air-Conditioning Contractors: main activity is installing and servicing plumbing, heating, and air-conditioning equipment

How is 238210 different from 238220?

238210 is Electrical Contractors and Other Wiring Installation Contractors, while 238220 is Plumbing, Heating, and Air-Conditioning Contractors. Compare their descriptions: they are separate codes because the Census treats the two activities as different.

Is this the code to put on a form?

Not by itself. A form asks for the code of the main activity, in the NAICS year it names. Read the description above and the codes beside it, and follow the instructions of the agency that asks.
