NAICS 713990: All Other Amusement and Recreation Industries

National industry, 2022 NAICS.

713990 is the NAICS national industry All Other Amusement and Recreation Industries in the 2022 edition of the classification. It is filed under 71 Arts, Entertainment, and Recreation › 713 Amusement, Gambling, and Recreation Industries › 7139 Other Amusement and Recreation Industries. In the code order it is number 924 of the 1,012 six-digit industries.

Its five-digit parent, 71399 All Other Amusement and Recreation Industries, holds only this one industry, so the two codes carry the same title and the same meaning.

What the Census says

This industry comprises establishments (except amusement parks and arcades; gambling industries; golf courses and country clubs; skiing facilities; marinas; fitness and recreational sports centers; and bowling centers) primarily engaged in providing recreational and amusement services.

To read that description in everyday terms, the main activity this code covers is providing recreational and amusement services.

The description opens with "This industry", the wording the Census uses for a class whose definition is shared by the United States, Canada and Mexico.

The Census entry also carries a Cross-References note that sends some related activities to other codes. The workbook keeps only its heading, so read the full entry for 713990 on census.gov for the exact exclusions.

Common questions

What does NAICS 713990 include?

How is 713990 different from 713910?

Is this the code to put on a form?

Not by itself. A form asks for the code of the main activity, in the NAICS year it names. Read the description above and the codes beside it, and follow the instructions of the agency that asks.
