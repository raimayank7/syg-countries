NAICS 325180: Other Basic Inorganic Chemical Manufacturing

National industry, 2022 NAICS.

325180 is the NAICS national industry Other Basic Inorganic Chemical Manufacturing in the 2022 edition of the classification. It is filed under 31-33 Manufacturing › 325 Chemical Manufacturing › 3251 Basic Chemical Manufacturing. In the code order it is number 235 of the 1,012 six-digit industries.

Its five-digit parent, 32518 Other Basic Inorganic Chemical Manufacturing, holds only this one industry, so the two codes carry the same title and the same meaning.

What the Census says

This industry comprises establishments primarily engaged in manufacturing basic inorganic chemicals (except industrial gases and synthetic dyes and pigments).

Illustrative Examples:

Alkalies manufacturing Aluminum compounds, not specified elsewhere by process, manufacturing Carbides (e.g., baron, calcium, silicon, tungsten) manufacturing Carbon black manufacturing Chlorine manufacturing Hydrochloric acid manufacturing Potassium inorganic compounds, not specified elsewhere by process, manufacturing Radioactive isotopes manufacturing Sulfides and sulfites manufacturing Sulfuric acid manufacturing

Put simply, the class is meant for establishments whose main work is manufacturing basic inorganic chemicals (except industrial gases and synthetic dyes and pigments).

The description opens with "This industry", the wording the Census uses for a class whose definition is shared by the United States, Canada and Mexico.

The Census entry also carries a Cross-References note that sends some related activities to other codes. The workbook keeps only its heading, so read the full entry for 325180 on census.gov for the exact exclusions.

How is 325180 different from 325110?

Is this the code to put on a form?

Not by itself. A form asks for the code of the main activity, in the NAICS year it names. Read the description above and the codes beside it, and follow the instructions of the agency that asks.
