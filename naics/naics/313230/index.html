NAICS 313230: Nonwoven Fabric Mills

National industry, 2022 NAICS.

313230 is the NAICS national industry Nonwoven Fabric Mills in the 2022 edition of the classification. It is filed under 31-33 Manufacturing › 313 Textile Mills › 3132 Fabric Mills. In the code order it is number 184 of the 1,012 six-digit industries.

Its five-digit parent, 31323 Nonwoven Fabric Mills, holds only this one industry, so the two codes carry the same title and the same meaning.

What the Census says

This industry comprises establishments primarily engaged in manufacturing nonwoven fabrics and felts. Processes used include bonding and/or interlocking fibers by mechanical, chemical, thermal, or solvent means, or by combinations thereof.

In plain words: a business belongs here when its main activity is manufacturing nonwoven fabrics and felts.

The description opens with "This industry", the wording the Census uses for a class whose definition is shared by the United States, Canada and Mexico.

How the code is read

A NAICS code builds up one level at a time, and each extra digit narrows the activity. Reading 313230 from the left:

  • 313 is the subsector Textile Mills
  • 3132 is the industry group Fabric Mills
  • 31323 is the five-digit industry Nonwoven Fabric Mills

Neighbouring national industries

Nonwoven Fabric Mills sits in the industry group 3132 Fabric Mills, which has 4 national industries in all. The others are: 313210 Broadwoven Fabric Mills, 313220 Narrow Fabric Mills and Schiffli Machine Embroidery, 313240 Knit Fabric Mills.

How it differs from the codes next to it

How is 313230 different from 313210?

Is this the code to put on a form?

Not by itself. A form asks for the code of the main activity, in the NAICS year it names. Read the description above and the codes beside it, and follow the instructions of the agency that asks.
