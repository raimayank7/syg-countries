NAICS 812990: All Other Personal Services

National industry, 2022 NAICS.

812990 is the NAICS national industry All Other Personal Services in the 2022 edition of the classification. It is filed under 81 Other Services (except Public Administration) › 812 Personal and Laundry Services › 8129 Other Personal Services. In the code order it is number 969 of the 1,012 six-digit industries.

Its five-digit parent, 81299 All Other Personal Services, holds only this one industry, so the two codes carry the same title and the same meaning.

What the Census says

This industry comprises establishments primarily engaged in providing personal services (except personal care services, death care services, drycleaning and laundry services, pet care services, photofinishing services, or parking space and/or valet parking services).

Illustrative Examples:

Bail bonding or bondsperson services Shoeshine services Coin- or card-operated personal services machine (e.g., blood pressure, locker, photographic, scale, shoeshine) concession operators Social escort services Consumer buying services Wedding planning services Dating services Personal fitness training services

To read that description in everyday terms, the main activity this code covers is providing personal services (except personal care services, death care services, drycleaning and laundry services, pet care services, photofinishing services, or parking space and/or valet parking services).

The description opens with "This industry", the wording the Census uses for a class whose definition is shared by the United States, Canada and Mexico.

The Census entry also carries a Cross-References note that sends some related activities to other codes. The workbook keeps only its heading, so read the full entry for 812990 on census.gov for the exact exclusions.

How the code is read

A NAICS code builds up one level at a time, and each extra digit narrows the activity. Reading 812990 from the left:

  • 81 is the sector Other Services (except Public Administration)
  • 812 is the subsector Personal and Laundry Services
  • 8129 is the industry group Other Personal Services
  • 81299 is the five-digit industry All Other Personal Services
  • 812990 is the national industry All Other Personal Services

What is NAICS code 812990?

What does NAICS 812990 include?

How is 812990 different from 812910?

812990 is All Other Personal Services, while 812910 is Pet Care (except Veterinary) Services. Compare their descriptions: they are separate codes because the Census treats the two activities as different.

Is this the code to put on a form?

Not by itself. A form asks for the code of the main activity, in the NAICS year it names. Read the description above and the codes beside it, and follow the instructions of the agency that asks.
