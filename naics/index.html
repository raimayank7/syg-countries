How to use this page

NAICS is the code that the United States, Canada and Mexico use to describe what a business does, so the same code can appear on tax forms, grant applications and statistics. This site lets you search the 2022 list by activity or by index term, browse by sector, and read what each code includes and excludes. Pick the code from the main activity of the business, check its description, and look at the neighbouring codes if two seem to fit. For legal or tax purposes follow the instructions of the agency that asks for the code.
