What you will find here

An HS code is the number that customs authorities use to identify goods in trade. This site presents the US version, the HTS, in plain pages: the 96 chapters, 1,228 headings and 5,612 subheadings, each with its tariff lines, general duty rates and units. If you are new, start with what an HS code is and how to find the right code.
